# Playwright の取り込みとログイン状態の利用、wiki 0.30.0 の公開

2026-11-18。作業開始は 11 月 17 日。これは検証した実行結果をまとめた記録であり、会話履歴の原文ではない。

- 実装の PR: https://github.com/to884/info-hive-wiki/pull/89
- 試験・設計・記録とサブモジュールの参照を更新する親の PR: https://github.com/to884/info-hive-dev/pull/174
- リリース: https://github.com/to884/info-hive-wiki/releases/tag/v0.30.0
- 注釈付きタグの参照先: `8cdbb7508f26dfa0b943472e6590597ed154c0ac`

HTTP 401 / 403 または雑音除去後の本文が空白を除いて 500 文字未満のときに、Playwright の経路へ切り替える。Windows の OS 既定の Chrome / Edge へ公式拡張で接続し、利用者が許可した、対象 URL に一致する表示済みタブを読む。普段のログイン状態を利用し、読み込み済みの本文内の同一 origin の画像も保存する。Cookie / プロファイルは書き出さず、既存タブを移動せず、新しいタブも作らない。

`--browser-only` で HTTP と再開を飛ばせる。`--browser-session isolated` では独立したブラウザで取得する。変換・翻訳・raw の検査は従来の処理を共用する。既存タブの接続には Node.js 20 以上、npm、公式拡張が必要で、内部実装への依存を `playwright-core@1.66.0-alpha-2026-11-09` に固定した。未対応の既定ブラウザでは停止し、Windows 以外ではブラウザの明示が必要である。別 origin や未読込の画像などは未取得とする。

Claude が利用上限のため、利用者の指定で Astra が設計・実装・公開用の切り出しを敵対的レビューした。修正後に未解決の重大・中程度の指摘はなかった。並行中の翻訳修正（子 #87、親 #171）は今回の差分から除いた。

切り出し後の関連 Python 試験は 321 件中 319 成功、既存条件の 2 件スキップ。Node の契約試験は 10 ケース成功。独立 Chromium の実機 7 ケースと、ローカルの HttpOnly Cookie が必要な本文・画像を普段の Edge から取得する試験が成功した。後続の内部修正は単体・IPC の試験で確認した。プラグイン自身の CI 手順も手元で完走した。

子の 4 ジョブと親の 17 ジョブがすべて成功してから、子 #89 をマージした。Windows / Python 3.14 の閲覧試験の静的ページの読み込みが一度タイムアウトしたが、試験条件を変えず、失敗したジョブだけを再実行して成功した。CI 対象の子の head とマージコミットの差分は空だった。

Claude Code と Codex の一時設定で公開カタログから 0.30.0 を導入し、変更した全 15 ファイルがタグとバイト単位・SHA-256 で一致した。Codex はスキルと 7 個の MCP ツールを認識し、統計と日本語検索が動き、試験用 wiki を変更しなかった。導入先のヘルプも正常終了した。通常の設定は操作せず、一時設定は削除した。モデルの推論は呼んでいない。

詳細な検証結果と両ホストの照合結果は `docs/research/wiki-playwright-release-0.30.0-2026-11-17/`、設計と Astra のレビュー記録は `docs/plans/wiki-ingest-playwright-2026-11-17.md` と `docs/agent-runs/2026-11-17-wiki-ingest-playwright/astra-review.md` にある。

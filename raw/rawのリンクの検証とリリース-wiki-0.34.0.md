## 動作

共通の raw 解決は、全候補のリンク・途中の道・ディレクトリの内容を検査してから、版と身元を照合する。拒否、曖昧さ、検査不能、不一致、版や範囲の未確認を区別して残し、既存の参照を直さない。CLI の `--raw-root` と MCP の `raw_root` から、利用者が知っている現在の根を渡せる。

字幕の検査は、無関係な原本の問題を警告とし、動画や訂正の根拠が依存する欠陥を停止の理由にする。待っている子ディレクトリも降りる直前に再検査する。セッション保存後は最終の source と同じ session_id で解決してから読み取り専用にする。

## 残る範囲

rawの書き手全体の版情報と根の記録、過去の根の発見・upgrade、書き込みの部品と全取り込み経路の移行は段階3以降である。今の根の指定だけで過去の根まで検査したことにはならない。既存ページの版未検証や途中の未検査も警告に残す。指定した根と祖先のリンク、守る木の外のragの原本の例外を保つ。完全な同時置換の防止とbind mountの検出は保証しない。

## 製品の決まり（測るときもこれを使う）

確信度とページの判定は、製品のコードを通して測り、同じ決まりを測る側で作り直さない。

- **行の確信度:** `rag_ocr_confidence.line_records` の `confidence`。文字の確率と、終わりの記号の確率の最小値である。本文が空の行（読めなかった行）は 0 になる。
- **低い:** `rag_review.is_low` のとおり、`confidence_min < threshold`（等号は低くない）。
- **ページの確信度:** `rag_pdf.confidence_min` のとおり、そのページのすべての行の確信度の最小値。行のないページは 1.0。確信度が不明（`None`）のページは、低いとも高いとも扱わない。
- **確信度の低いページ:** 確信度が閾値より低い行が 1 つ以上あるページ（ADR-0025 の「ページ」）。
- **OCR の経路:** `rag_pdf.extract_pages` を、`ocr_mode` を `always`、`ocr_dpi` を既定の 150 にして呼ぶ。OCR は、rag の OCR の環境の `rag_ocr.py --worker` を `OcrClient` で動かす。行の記録は、`OcrStore` が保存した `confidence.lines` から読む。
- **製品の版:** rag 0.6.0 の候補（`feat/pdfminer-body-ocr-store`）、`OCR_CONFIDENCE_REVISION` は `confidence-v1`。

## 試料

### 合成の PDF

- **原稿:** リポジトリの `docs/adr/` の ADR から作る。ファイル名の順に並べ、最初の 13 個を使う。1 つ目は試しの原稿（下の「試しの原稿」）とし、2〜13 個目の 12 個を測る原稿とする。各 ADR の本文から、Markdown の記号（見出しの `#`、表の `|`、強調、リンクの URL、コードの囲み）を除き、空白を詰めて、先頭の 1,520 文字を取る。フォントにない文字は、描く前に除く。
- **組み方:** A4、縦長、余白 20 mm、横書き。1 行 40 文字、1 ページ 38 行、文字の大きさ 10.5 pt、行の送り 18 pt。フォントは、原稿の番号 i（0 から）について、i を 4 で割った余りが 0 か 1 なら MS ゴシック、2 か 3 なら MS 明朝とする（選ぶ側と確かめる側の両方に、2 つのフォントが入る）。
- **正解:** 描いた各行の文字と、描いた位置から求めた行の箱。
- **画像:** 描いた PDF を pypdfium2 で画像にし、次の 5 つを作る。どれも 1 つの強さだけで、条件を満たすように調整しない。強さは、事務のスキャンでよくある程度として決めた。

  | 名前 | 作り方 |
  | --- | --- |
  | `clean` | 150 dpi で描く |
  | `lowres` | 100 dpi で描く（製品が 150 dpi で描き直すときに引き伸ばされる） |
  | `blur` | 150 dpi で描き、ガウスぼかし（半径 1.0 ピクセル） |
  | `noise` | 150 dpi で描き、ガウス雑音（標準偏差 20、0〜255 の濃さ。乱数の種は原稿の番号） |
  | `skew` | 150 dpi で描き、反時計回りに 1.0 度回す（はみ出した所は白） |

  各画像を、同じ大きさ（A4）のページ全面に貼った、画像だけの PDF にする。製品は、この PDF を 150 dpi で描き直して OCR する。`skew` の正解の箱は、行の箱の 4 隅を同じ角度で回し、それを囲む箱にする。
- **数:** 1 つの原稿から 5 ページ。測る原稿は 12 個なので 60 ページ（選ぶ資料 30、確かめる資料 30）。

## 行の対応

OCR の行の箱と、正解の行の箱を、次のように対応させる。

- **つながり:** OCR の行 O と正解の行 G は、重なりの面積が、O と G の小さい方の面積の半分以上のとき、つながる。
- **対応:** つながりでできるまとまり（連結成分）を 1 つの対応とする。1 対 1 でない対応（OCR が 2 行を 1 行に読んだ、1 行を 2 つに分けた）も、1 つの対応として数え、その数を報告に書く。
- **対応の本文:** 正解の行も OCR の行も、読む順に並べてつなぐ。横書きは上から下、同じ高さは左から右。縦書き（OCR の `vertical`、pdfminer の `LTTextLineVertical`）は右から左、同じ列は上から下。
- **対応の確信度:** 対応に入る OCR の行の確信度の最小値。
- **誤り:** 正規化した正解と OCR の本文の編集距離（Levenshtein、文字の単位）が 1 以上。
- **読み落とした行:** OCR の行とつながらない正解の行。確信度がないので (a) と (b) には入れず、数を報告に書く。参考として、読み落とした行を「閾値より低くない誤り」として (b) に入れた値も書く（合否には使わない）。
- **正解のない行:** 正解の行とつながらない OCR の行。公開の PDF では、画像の図の中の文字など、文字の層にない文字を読んだ行である。(a) と (b) には入れず、数と確信度の分布を報告に書く。ページの判定（c）には入る。

## 比べ方（正規化）

正解と OCR の本文の両方に、次の順で当てる。

1. Unicode の NFKC。
2. 空白（Python の `str.isspace` が真の文字）を除く。
3. 見た目の同じ記号をそろえる。

   | そろえる先 | 元の文字 |
   | --- | --- |
   | `-` | U+2010、U+2011、U+2012、U+2013、U+2014、U+2015、U+2212、U+FF0D |
   | `~` | U+301C、U+FF5E |
   | `'` | U+2018、U+2019、U+201A、U+201B |
   | `"` | U+201C、U+201D、U+201E、U+201F |
   | `・` | U+FF65、U+00B7 |

## 数えるもの

閾値 t ごとに、資料の側（選ぶ、確かめる）と種類（合成、公開）ごとに数える。

- **(a) 低い行の誤りの割合:** 確信度が t より低い対応のうち、誤りの対応の割合。
- **(b) 誤りのうち低い行の割合:** 誤りの対応のうち、確信度が t より低い対応の割合。
- **(c) 低いページの割合:** OCR したページのうち、確信度の低いページの割合。確信度が不明なページは、分母にも分子にも入れず、数を書く。

参考として、文字の誤りの割合（編集距離の合計 ÷ 正解の文字数）、画像の種類ごと（合成）と PDF ごと（公開）の (a)〜(c)、Wilson の 95% の区間も書く。

## 閾値の選び方（選ぶ資料だけを使う）

候補は 0.01 から 0.99 まで 0.01 おきの 99 個とする。

1. 余裕 m を 0.05 として、合成と公開のそれぞれで、(a) ≥ 0.5 + m、(b) ≥ 0.8 + m、(c) ≤ 0.2 − m をすべて満たす候補を集める。両方で満たす候補（共通部分）があれば、その中央値を選ぶ（数が偶数なら、小さい方）。
2. 1 で候補がなければ、m を 0 にして同じことをする。選んだら、余裕のない閾値であることを報告に書く。
3. 2 でも候補がなければ、ここで止める。確かめる資料は測らない。ADR の「満たさないとき」のとおり、確信度の数え方か、確認の単位を見直す。

中央値にするのは、(b) の境目ちょうどの閾値を選ぶと、確かめる資料での小さなぶれで (b) を外すためである。

選んだ閾値、候補の集まり、選ぶ資料での (a)〜(c) を記録してコミットしてから、確かめる資料を測る。

## 合否（確かめる資料で、1 回だけ）

選んだ閾値で、合成と公開のそれぞれについて、次をすべて満たせば合格とする。

- (a) ≥ 0.5、(b) ≥ 0.8、(c) ≤ 0.2（ADR-0025 の基準のまま）。
- 数が足りている: 閾値より低い対応が 20 以上、誤りの対応が 20 以上、OCR したページが 20 以上。足りなければ「判断できない」とし、合格にしない。

合格しなければ、ADR の「満たさないとき」のとおり見直す。見直したあとに確かめ直すときは、今回の確かめる資料を使わず、新しい原稿と新しい PDF で確かめる資料を作り直す。

## 測る前に分かっている難しさ

ページは、閾値より低い行が 1 つでもあれば低くなる。1 ページが 38〜40 行のとき、誤りのないページが (c) の 2 割に収まるには、正しく読めた行が閾値より低くなる割合が、1 行あたり約 0.56%（1 − 0.8^(1/40)）以下でなければならない。また、誤りのある行を含むページが 2 割を超えると、(b) と (c) を同時に満たすのは難しくなる。

合成の資料は 5 つの画像のうち 4 つを劣化させているので、劣化した画像で誤りが多ければ、合成の (c) は満たせない。その結果は、ページごとの確認がスキャンの PDF では重すぎることを示すものとして扱い、画像の配分を測ったあとに変えて合わせない。

## 取得の範囲

HTTP 401 / 403、または雑音除去後に空白を除いた本文が 500 文字未満なら、Playwright の経路に切り替える。Windows の `system` は、元 URL のプロトコルについて OS の既定の Chrome または Edge の実行ファイルを取得する。既定の `existing` は、公式拡張で利用者が許可した、URL が一致する表示済みタブの DOM と、本文内の読み込み済みの同一 origin の画像を読む。Cookie / プロファイルの書き出し、新しいタブの作成、既存タブの移動は行わない。

`--browser-only` は HTTP と再開を飛ばすが、既存 raw の無条件上書きはしない。`--browser-session isolated` は独立したブラウザで取得する。既存の変換・翻訳・raw 検査は共用し、取得方式と DOM のハッシュを保存する。

接続には Node.js 20 以上、npm、公式 Playwright 拡張が必要で、内部実装への依存を `playwright-core@1.66.0-alpha-2026-11-09` に固定した。対象ページの描画完了は利用者がブラウザで確認する。別 origin や未読込などの画像は未取得とし、匿名では取り直さない。未対応の OS 既定ブラウザでは止まり、Windows 以外ではブラウザの明示が必要である。

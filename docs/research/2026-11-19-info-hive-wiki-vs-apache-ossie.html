Apache Ossie

現行は記事から根拠をたどる。Ossie は実体の関係や集計の意味を定義する。定義ファイルの差し替えでは、既存のグラフを引き継げない。

件数は同じ。経路は変わった。

SemaSynth の同じ63ページで、定義ファイルだけを差し替えた試験。

導入で増えること・引き継ぐこと

実体の定義
現行記事の種類・設定から、型と ID を付ける。
Apache Ossie提供元と製品コードの組で識別するなど、用途に合わせたルールを定義できる。
出典と履歴
現行同じ関係でも、引用・確信度・状態・時期・訂正を区別して保存する。
Apache Ossie根拠を引き継ぐには、主張と根拠を別々に表す対応付けが要る。
問い合わせと表示
現行隣接、関係一覧、最短経路、ページごとの関係表を使える。
Apache Ossie集計の意味を外部と共有できる。既存の経路探索と閲覧には互換実装が要る。
仕様と公開ツールの検証範囲
  • Ossie の公式検証器は、独立したマッピング文書の参照先と列名を検査できた。試験した変換器のパーサーは、その独立文書の読み込みを拒否した。
  • 制約・導出・集計を実行する範囲は評価器によって異なる。Ossie の集計用の結合経路と、wiki の最短経路探索はそれぞれ別の問い合わせ。
  • 確認した版は info-hive-wiki 0.35.1 と Ossie 0.3.0.dev0（0f458de）。差し替え試験には公式の Flights 定義 4d82209 を使った。

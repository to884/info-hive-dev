# browse の記事のページの Fluent 2（段 F2）と wiki 0.19.0 のリリースの記録

閲覧（`/wiki:browse`）の記事のページの部品（本文、メタ欄、関係表、被リンク、診断）を Fluent 2 のデザインにし、wiki 0.19.0 として出した記録である。設計は `docs/plans/wiki-browse-fluent2-2026-11-14.md` の 5 節（段 F2）にある。レビュー、対応、画面、ブラウザごとの結果の原本は `docs/agent-runs/2026-11-15-wiki-browse-fluent2-f2/` にある。このページは、作業の記録から書いた。見た目の決まりと、F2 で分かったことは [[browseのデザインシステム]] にまとめてある。

## 経緯

1. 中核（`wiki_browse_core.py`）のメタ欄、関係表、被リンク、診断に Fluent の class を足し、`style.css` の記事の規則を、試作（`poc/browse-fluent2/`）を下敷きにして書き換えた。Markdown の出力には class を足していない。
2. 試験を足した。`test_browse.py` は記事のページの class を確かめる。`findability.test.mjs` は、書体、配置、下線、表の形を計算された値で確かめ、記事のページの部品のコントラストを測り、幅 320〜1000 で `#_main` の右端を越える要素がないこと、関係表をキーボードで横に送れることを確かめる。
3. 試験が、試作の `#_main a:active`（`colorBrandForegroundLinkPressed`）を落とした。暗い配色で地との比が 3.85:1 になる。押下でもホバーの色のままにした。
4. Sol の実装のレビューは 1 回目で「条件付きで採用可」、分類 A は 0 件だった。残った B と C は試験の確かめ方で、配色ごとに測れた部品を数える、読むだけの行のすべてでポインターと押下の前後の地を比べる、長い題名や要約や診断を材料に足す、と直した。壊した CSS を足して、直した確かめが落ちることを確かめた。
5. レビューのあとで画面を撮って試作と見比べ、試作にない見た目（本文の表の全周の線、見出しのセルの地、`pre` の枠、関係表の見出しの太字、h4 の余白）を外した。関係表のセルを `word-break: normal` にしていたので、「ソース/の例」のように語の途中で折れていた。設計（セルの中で語を折らない）と試作に従い、`keep-all` に戻した。
6. ブラウザで流した。Chromium（静的とサーバー）と WebKit（静的）は失敗 0 だった。Firefox（静的）は F2 の確かめがすべて通り、F1 の検索の後読みの 3 件（`file://` の要求を `page.on("request")` と `page.route` で見る試験）が落ちた。3 つのブラウザで両方の方式を流すと 40 分の上限を超えたので、Firefox と WebKit は静的だけにした。
7. 版は 0.19.0 にした。作業の途中で to884/info-hive-wiki#61 が 0.18.1 として入ったので、作者の「#61 を待つ」の指示で、子のブランチに main を取り込み（force push はしない）、CHANGELOG の 0.19.0 を 0.18.1 の上に置いた。
8. 作者の「自動マージを入れる」の指示で、`gh pr merge 63 --auto --merge` を実行した。子のリポジトリは CI を必須にしていないので、GitHub は待たずにその場でマージした（マージコミット `cdc5b1f`）。そのとき `python-windows (3.12)` が走っていた。あとで通った。
9. 注釈付きのタグ `v0.19.0`（本文は「v0.19.0: 閲覧の記事のページの部品を Fluent 2 にした（段 F2）」）を `cdc5b1f` に付けて push し、GitHub リリース `v0.19.0` を作った。本文は CHANGELOG の 0.19.0 の節である。
10. 使い捨ての設定でマーケットプレイスから入れ、0.19.0 が入ることを確かめた。v0.18.1 から v0.19.0 までに変わった 4 つのファイルの SHA-256 が、すべてタグの中身と一致した。入ったスクリプトで使い捨ての Wiki を書き出し、記事のページにメタ欄の `fui-Table`、関係表の `table-scroll`、被リンクの `fui-List`、3 つの `fui-Subtitle2` の見出しが出ることを確かめた。

## 親の CI

親の PR（to884/info-hive-dev#118）の `mcp (ubuntu-latest)` が、`tests/wiki/test_web_raw_agent.py` で落ちた。0.18.1 が変えた `references/web-raw.md` の文に、親の試験が追いついていないためで、F2 とは関係しない。試験の直しは、0.18.1 の親の PR（to884/info-hive-dev#115）にある。0.18.1 を含む参照を親に持ち込んだのが #118 が最初だったので、#118 で表に出た。#115 が入ってから #118 を載せ直す。

## 残したこと

- Firefox の `file://` の検索の後読みの 3 件は、試験の道具の制約とみて、範囲の外とした。確かめてはいない。
- Edge と Chrome での確かめはしていない。

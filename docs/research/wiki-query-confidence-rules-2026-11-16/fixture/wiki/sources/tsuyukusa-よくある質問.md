# Tsuyukusa よくある質問

[[tsuyukusa]] の公式サイトの「よくある質問」のページの要約である。原本には、発行日も、対象の版も書かれていない。

## 無料プラン

無料プランでは、1 つのアカウントで端末を 3 台まで使える。4 台目の端末を登録すると、いちばん長く同期していない端末の登録を外すよう求められる。

## サポート

問い合わせは、管理画面のフォームから受け付ける。電話での受け付けはしていない。

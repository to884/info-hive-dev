# 公開版への通常保存と承認済み変更の再試行

[本番有効化の条件](2026-11-19-wiki-production-readiness.md) の③を実装した。共通の書く段で、公開版を使う wiki の通常の `ingest`・`query`・`learn` を次の公開版に保存する。原本は従来の raw ルートに置き、その場所と指紋を使って検証する。

## 保存と復旧

下書きを作る前に `wiki_apply.py view --wiki <wiki>` で読む版を確定する。その `release_id` を `begin` に指定し、ページ・索引・ログの差分を承認する。公開候補は最新版のマニフェストから組み立て、共通ロックの内側で基準を照合してから日誌を作る。公開前に互換グラフも作り直す。Ossie の `WikiArticle` に新しい記事内容を追加し、形式化済みの主張・根拠・履歴を保持する。同じ内容への復元は既存の記事 ID を共用し、公開版に封印した更新前後の指紋から経過をたどれる。新しい意味出力の公式検証はこの保存では実行しない。

別の保存が先に確定すると、保存対象と根拠の版が同じ場合に限り、同じ承認で最新の公開版に当て直す。ロックの待ち時間を超えた場合や、対象・根拠・定義が変わった場合は保留する。承認済みの計画と下書きは wiki 内に記録してあるため、元の作業フォルダーが消えても同じ `plan_id` と `plan_sha256` で再試行できる。日誌が残っている場合は先に復旧し、公開済みなら完了記録、公開履歴、封印した結果を照合して同じ公開版 ID を返す。

```powershell
python "<wiki_apply.py>" pending --wiki "<WIKI_ROOT>"
uv run --with pyyaml==6.0.3 python "<wiki_apply.py>" retry --wiki "<WIKI_ROOT>" --plan-id "<plan_id>" --expect-sha256 "<plan_sha256>"
```

## 隔離試験

[初回公開の検証](2026-11-19-wiki-cutover-integrity.md) と同じ公開195記事・212ファイル、原本160件（20,706,000バイト）の合成 wiki を使った。各操作が使う CLI で原本を保存し、検索結果から query の根拠を確定し、learn の経験を capture した。

| 試験 | 確認した結果 |
| --- | --- |
| 同じ基準版から4プロセスで保存 | 初回に3件を公開し、競合で保留した1件は同じ承認で再試行して公開した。 |
| ロック待ちと強制終了 | ロック待ちで保留した1件と、承認の記録後・公開日誌の記録後・公開ポインター更新後に強制終了した3件を、下書きの場所を外して再試行した。 |
| 欠落と重複 | 8件を記事・索引・ログ・SQLite の記事行で照合し、いずれも1件ずつだった。先頭を切り替えたあとも、指定した旧版から従来の引用を取得できた。 |
| グラフと意味出力 | SQLite の互換グラフで型付きの関係と根拠が1件入ったことを確かめた。Ossie の既存674行を保持し、記事版10行を追加した。 |
| 競合と原本の保護 | 同一ページと根拠の両方で食い違いを検出した。異なる raw ルートを使う後続編集は通り、原本の指紋が外部で変わると保留した。壊れた候補を隔離したあとの同じ承認の同時再試行も、公開は一度だけだった。 |

新規4件と既存42件のテストが通った。同規模の試験1件は全体で約302秒かかった。原本を含む隔離環境の生成と強制終了の試行を含んだ時間である。Opus の初回レビューに基づき、公開版が参照する原本の範囲を検査し、共通ロック内で新しい raw ルートを記録するようにした。再レビューでは重大な指摘はなかった。

SemaSynth wiki へのアクセスは指紋照合の読み取りに限った。開始時と終了時に照合した83ファイルのうち2ファイルに差分があった。変更元は未確認で、復元操作は行っていない。

本番の有効化と、公開後の変更を保持してライブへ戻す条件④はこの試験の対象外とした。故障注入にはプロセスの強制終了を使った。

## 再現

リポジトリのルートから実行する。試験は Windows の一時ディレクトリに合成 wiki を作り、外部 DB や API キーを使わない。

```powershell
$env:INFO_HIVE_PUBLIC_SAVE_REPORT = Join-Path $env:TEMP 'info-hive-public-save-results.json'
uv run --offline --with pyyaml==6.0.3 python -B -X utf8 -m unittest tests/wiki/test_wiki_public_save.py -v
```

# 旧指示で難度を較正した転記比較

条件5の合否、未決定の扱い、所属・正規化・採点器、正式評価画像・正解、および100万配置の上限を固定する。前回の合成画像では失敗が出なかった。[実例の診断](../../research/adr-0025-condition5-reference-audit-rootcause-v9-2026-11-19.md)にある細い閉じ記号、枠端の句点、短い縦列を目安に、合成画像の局所的な濃度、にじみ、地色のむらを段階的に強める。450 DPIの元画像と固定150 DPIの両方を使い、枠あり・なしを提示する。

## 旧指示だけでの較正

難度1〜4を各1原稿で測る。原稿ごとに8行、細い閉じ記号4行（0、1、2、2個）、枠端の句点1行、短い縦列3行。条件・作成時の正解・配布画像のSHAを読取前に固定する。Sol・Astraが旧指示だけを新規セッションで読み、最初の既知二票が一致しない行に限って、原稿ごとに事前割付したモデルの新規セッションで第三読する。正規化後に既知の二票が一致したものを確定する。第三読後に、2記号の行で確定した脱落が1行以上、未決定が1行以上、全文正解が2行以上の全てを満たした最低の難度を採用する。満たさない場合は、別の本文・IDの較正用画像で、事前定義した予備難度3〜6を一度だけ試す。予備でも満たさなければ結果を判定不能とする。

## 新しい画像での比較

選んだ設定で新規の合成原稿4種・各8行を作る。較正用とは本文・画像ID・画像ハッシュが異なり、同じ種類と個数を含む。撮像条件と読む手順は較正と同じ。比較画像、正解、較正結果のSHA、割付を読取前に固定する。Sol・Astraは旧・新とも同じ16画像・32IDを同じ順に新しい別セッションで受け取る。新指示だけに「提出前に連続記号の位置と個数を見直す。」を追加する。第三読の規則も両群で共通。試行の代替は前回と同じく送信・操作・形式失敗に限り1回。未決定は有効な票とする。

全32行の未決定数、既知→未決定、逆方向を数え、双方確定の同じ行で記号脱落、全文字の不足、余分な記号・全文字、全文一致を比較する。原稿別・失敗型別・モデル別の集計も残す。字数は正規化後の字種別の個数差、順序は全文一致で測る。読める票が減った場合や、過剰と脱落の間に差が出た場合もそのまま示す。較正は難度の選定に限る。比較の旧指示で失敗が出なかった項目の改善は判定不能。条件5の合否と統計的な非劣性を推定しない。

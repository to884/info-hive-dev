# 2 回目のレビュー

1 回目（review-sol-1.md）の指摘を受けて、測定の要約のスクリプト 3 つを直した（git diff HEAD~1 -- docs/research）。

- 広い抽出式（ANY）：前の名前「確からしさ」は回答の意味でしか使っていないので広く読む。新しい名前は、回答を指すと分かる形（確信度（confidence）、（確信度: 、回答の確信度）だけを読む。飾りのない「確信度: 中」は、エッジの値と見分けられないので数えない。
- 名前の記録（mark_names）：決まった 1 行と結論のそばの印に使った名前を残し、新しい名前が守られたかを数えられるようにした。

この直しで指摘の原因が取り除けたか、新しい数え漏れや誤検出を生んでいないかを見てほしい。版はリリースのときに決める。

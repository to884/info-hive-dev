## 判定

**条件付きで採用可**。英語の原文をそのまま残す元の事故（`keep`、訳者名だけ、部分的な写し、他の文字体系の写し）は、確認の記録なしでは確実に止まります。一方で、中国語の原文を一字も変えずに残した raw は、エラーも警告も出ずに `completed: true`、`state: checked` で完了します。これは設計が掲げる「原文に近いまとまりを確認する」に反するので、直すことが採用の条件です。確信度は中〜高です。

## 致命的・重大な欠陥

### 1. 【重大・確認済み】中国語を訳さずにそのまま残しても、警告なしで完了する

- **主張**: 漢字だけの出力は、それ自体では候補になりません。漢字の照合が動くのは、原文の文の単位が仮名を含まず漢字 8 字以上のときだけです。次の場合は検出されません。
  - 短い見出し、リストの項目、表のセル、短い文
  - 原文の文に仮名が 1 字でも含まれる
  - 言い換え、または簡体字から繁体字への変換をした

- **再現**: 一時ディレクトリで `RawCheckCase` を流用し、`check --finish --json`（`--accept-warnings` なし）を実行しました。原文と raw は同一で、`translated_by` だけを入れています。結果は、どれも `code=0 completed=True state=checked errors=[] warnings=[]` でした。

### 2. 【重大・確認済み（本文の読み取り）】`done` の受理の条件に「警告が空」と「保持が 0」がない

- **主張**: 親が `done` の報告で確かめるのは、`completed`、`ok`、`pending_reviews: 0`、`state` だけです。`check.warnings == []` や `reviewed_passages == 0` は確かめません。

## 崩れる前提

- **「外国語はかな・漢字以外の文字体系として現れる」**: 中国語では崩れます（欠陥 1）。漢字を共有するので、仮名のないことが唯一の手がかりですが、使われていません。
- **「保持の警告は親が読む」**: 次の場合は、記録を書いた者と受理する者が同じになります。設計の安全性は、確認者が別にいることに頼っていますが、その独立性はありません。
  - Codex（W1〜W8 を常に自分で行う。`references/codex.md:31`）
  - `wiki:web-raw` がない Claude Code（W8 の「自分で W1〜W8 を行っているとき」）

  元の事故は、モデルが「原文の再現性」を正当な理由と自分で判断して起きました。同じ判断は、`proper_name` と理由を書けば機械では止まりません。虚偽の分類への防御は範囲外という説明は理解しますが、自己承認の経路で「親の確認」と書くのは実態と合いません。
- **「試験は必ず `-m unittest` で動く」**: `TranslationReviewContractTest` は `if __name__ == "__main__": unittest.main()`（`tests/wiki/test_wiki_web_check.py:2342-2346`）の後ろにあります。`python tests/wiki/test_wiki_web_check.py TranslationReviewContractTest` で直接実行すると、クラスが定義される前に main が走り、エラーになりました。CI と記録は `-m unittest` なので、実際には動いています。
- **「確認の記録が対象の範囲を固定する」**: ID は位置・原文・訳文・対象に結び付いています。ただし、`ui_text` などで同じブロックに日本語を求める規則は、`proper_name`、`identifier`、`bibliography` を選べば外れます。

- プラグインの HEAD は `baf1ef7` で、作業ツリーに変更はありません。差分の検出、確認の記録、`completed` の実装は、`round4.patch` の内容と一致しました。

## 崩せなかった点

- `keep` で翻訳必須の判定を解除できない。`needs_translation` の欠落や真偽値以外の型は、例外で止まる。
- `--accept-warnings` だけでは `translation_review_required` を解除できない。`--translation-review` を付けない限り、記録は適用されない。
- 確認の記録の検査。次の記録は、どれもエラーとして止まりました。
  - ファイルがない
  - `translation_review` が真偽値
  - ハッシュがない、または古い（原文、raw のどちらでも）
  - 不明な ID、重複した ID
  - `text` が対象の一部だけ
  - 決まった値以外の `kind`
  - 空白だけの理由
  - 一部の対象だけを記録した（残りは未解決のまま）
- 表で同じ値のセルは、別の ID になる。
- ハッシュとパースが同じバイト列を使い、どこか 1 バイトでも変われば記録全体が無効になる。
- `completed` は `--finish` で写しが消えたときだけ真になる。保持の警告がある限り、`--accept-warnings` なしでは完了しない。

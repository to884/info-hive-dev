`/wiki:overview <ページ>` で、指定したページから図を中心とする概要を作れるようになりました。元の記事を変えず、概要と SVG をサイドカーにまとめて保存します。

- `/wiki:browse` は最初の h1 の直後に概要を表示します。新しい概要は開き、古い概要は警告付きで折りたたみます。
- 概要は検索、見出し一覧、被リンク、ページ数、グラフに加えません。閲覧時に生成や修復を行いません。
- SVG は画像として配信し、Mermaid は既存の隔離処理を使います。静的版では Mermaid のコードを表示します。
- 元の記事をリンクとして読まなかった場合は、不在に読み替えず、`remove --orphan` での削除を拒みます。
- Claude Code と Codex の両プラグインで利用できます。Codex は `$wiki:info-hive overview <ページ>` から共通の手順を呼びます。

設計と実装のレビュー、Windows/Linux の CI、5ブラウザでの表示・キーボード操作・配色・CSP、MCP と Codex の導入を確認しています。

## 崩れる前提

- **検索結果の関連性は、読み手が同じ範囲で判定できる。** 同じ製品・版を扱うページと、質問された項目を扱うページが混在すると崩れます。
- **追加ページを読めば、再検索の例外を適用できるか決まる。** 読後も「関係する」の範囲が未定義で、例外の成否が残ります。

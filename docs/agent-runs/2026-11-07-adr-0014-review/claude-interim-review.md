# Claude による暫定の敵対的レビュー（ADR-0014 と rag 0.5.0 の実装）

AGENTS.md の規則では、設計と実装が終わるたびに GPT-6.1 Sol に敵対的レビューを頼む。2026年11月8日、Codex の認証が通らず（`api.openai.com/v1/responses` が 401 Unauthorized）、Sol のレビューを受けられなかった。その代わりに、Claude（Opus 5.5）のサブエージェントに、同じ観点で敵対的レビューを頼んだ。**これは規則の Sol のレビューに代わるものではない。** Sol のレビューは、認証が戻ってから設計と実装に分けて頼む。

- 対象: ADR-0014 の草案、rag の `6a760b9..27eed9e`、`tests/rag/test_extraction.py`
- 判定: 条件付きで不合格（致命的な欠陥なし、重大な欠陥 2 件）

## 指摘と対応

| 重大度 | 指摘 | 確かめ方 | 対応 |
| --- | --- | --- | --- |
| 重大 | 方針が変わった索引を、埋め込みの前に空にしていた。新しいモデルの埋め込みが失敗する（モデルの取得の失敗など）と、設定を戻しても前の索引が使えない | レビュアーが試験で再現した | 最初のバッチの埋め込みが済んでから空にする。試験 `test_failed_embedding_after_model_change_keeps_the_old_index` |
| 重大 | `previous-index.json` に載っていれば、取り込み直し済みや置き換え済みの文書でも「使用中」とみなし、抽出の結果を消さなかった。空にしたあとで置き換えられた版の結果も消さなかった。0.4.0 の置き場所の結果を、古い版を消すときに消さなくなっていた | レビュアーが試験で再現した | 使用中とみなすのは、取り込み直しを待つ文書（`status` の `reingest`）だけにした。取り込みのたびに一覧から外れた文書の結果を消す。古い版を消すときに 0.4.0 の置き場所の結果も消す。試験 `test_reingested_then_replaced_version_cache_is_removed`、`test_version_replaced_after_reset_is_dropped_and_its_cache_removed` |
| 前提 | 0.4.0 の結果を今の指紋だけで探すので、モデルを変えたあとは見つからない | コードの推論 | `policy.json` のモデルに替えた指紋が一致すれば、その指紋の `generation` も探す。試験 `test_extraction_from_0_4_0_is_reused_after_a_model_change` |
| 前提 | 2 回続けて設定を変えると、一覧の場所とソースのページが後勝ちで減る | コードの推論 | 和をとる。取り込み直した文書には、空にする前の出典を `citations` に戻す。試験 `test_two_changes_in_a_row_keep_every_source_page` |
| 軽微 | `data_dir` を変えても `reingest_required` が `false` | コードの推論 | `true` にする。試験 `test_data_dir_change_needs_reingest` |
| 軽微 | 索引の行の削除が失敗すると、抽出の結果の後始末も飛ぶ | コードの推論 | 別の `try` に分けた |
| 軽微 | 同じ内容が 2 か所にあり片方だけ取り込み直すと、もう片方の場所は一覧から消える | コードの推論 | 直さない。内容が同じなので検索の結果は変わらない |
| 軽微 | 一覧の項目の場所のうち 1 か所に別の版を取り込むと、ほかの場所に元の版が残っていても要再確認の印を付ける | コードの推論 | 直さない。印が多すぎる側の誤りで、確認すれば外せる |
| 軽微 | `configure` は設定の保存の前にワーカーを止める | 既存の順序 | 直さない（0.4.0 からの順序で、ADR-0014 の範囲の外） |
| 軽微 | `ocr_mode` が `off` でも `ocr_dpi` を変えると指紋が変わる | コードの推論 | 直さない。入れ直しが要ると正しく伝える |

## 崩せなかった点（レビュアーの記述の要約）

- ロックの順序（取り込みは wiki の `write.lock` のあとに文書のロック、後始末は待たない）で、待ち合いは作れなかった。
- 空にする途中で止まっても、次の取り込みでもう一度空にでき、一覧は失われない。
- 指紋の違う 0.4.0 の結果を移すことはない。
- 版の更新（`old_ids`、要再確認の印、ハードリンクの別名）に退行は見つからなかった。
- `configure` の範囲の外の値は、保存の前に拒まれる。

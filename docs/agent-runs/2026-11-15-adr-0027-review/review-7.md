## 致命的・重大な欠陥

### 1. 【重大・A】留保の定義では、必須の照合項目を満たせない

**反例：** raw の `L123` に `上限は15件` があり、正しい数値を決められない場合、規定の形式で次を書く。

```markdown
上限は15〔留保 L123-1〕件とされるが、聞き違いの疑いがある。

## 字幕の訂正と留保

- L123-1: 字幕 `15` は留保
```

この定義には、**訂正した語も、根拠の種類と場所も存在しない**。しかし、L112 の照合は留保を除外せず、次を要求する。

- (2) 種類と場所が決まった形であること。
- (4) **すべての印**について、訂正した語が印の直前の本文の末尾と一致すること。

定義どおりの留保を拒否するか、留保だけ検査を変えるかが決まっていない。欠落値を空文字列として末尾照合すれば、本文との対応検査が常に成立してしまう。関連ページの留保にも、L105 が同じ「訂正した語」の照合を要求する。

**根拠：** [ADR-0027 L102：留保の定義](/C:/Works/info-hive-dev/.claude/worktrees/adr-0027-corrections/docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:102)、[L105：関連ページ](/C:/Works/info-hive-dev/.claude/worktrees/adr-0027-corrections/docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:105)、[L112：機械の照合](/C:/Works/info-hive-dev/.claude/worktrees/adr-0027-corrections/docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:112)。

**照合結果：仕様内の欠落。** 特殊な名前や時機を必要とせず、訂正できない語と、利用者が退けた訂正で発生するため A とした。未実装の検査器が実際に拒否したという主張ではない。

## 崩れる前提

| 暗黙の前提 | 崩れる条件 |
| --- | --- |
| 訂正と留保を、同じ項目で照合できる | 留保には訂正した語と根拠欄がない |

## 見落としと軽微な問題

1. **【軽微・B】通常の Markdown 表記が末尾照合で不一致になる。**  
   定義の訂正した語が `C++` の場合、本文の `` `C++`〔訂正 L123-1〕 `` や `[[cpp|C++]]〔訂正 L123-1〕` は、表示上は訂正語の直後に印がある。しかし、印の直前の原文はバッククォートや `]]` で終わり、`C++` とは一致しない。単なる境界の曖昧さは解消したが、書式付きの語を誤りとする制限が生じている。原文への末尾比較で再現済み。  
   **根拠：** [ADR-0027 L101](/C:/Works/info-hive-dev/.claude/worktrees/adr-0027-corrections/docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:101)、[既存の wikilink 規約 L56](/C:/Works/info-hive-dev/info-hive-wiki/skills/info-hive/references/page-conventions.md:56)。**照合結果：既存の表記との不整合。**

2. **【軽微・C】コードスパンの端にあるバッククォートの扱いが欠ける。**  
   字幕の語が「バッククォート＋`code`＋バッククォート」なら、最長の並びは1文字なので、規定の囲みは2文字になる。そのまま連結すると次になる。

   ````text

   ````

   同梱の `wiki_pages.new_parser()` は、これを内容が `code` のコードスパンとして読み、保存対象だった両端のバッククォートを失う。片側だけにバッククォートがある例では、コードスパンにならなかった。囲みの長さだけでは、逐語の表示と読み取りを定めきれていない。発生頻度は未検証。

3. **【軽微・D】同じ出現への二重採番を、列挙された検査では検出できない。**  
   `L123` に `15` が一度だけある状態で、別々の要約ページに `L123-1` と `L123-2` を定義し、双方を「最初の `15` を `50` に訂正、根拠 `model`」とする。両方の字幕位置と本文末尾は一致し、識別子が異なるため、同一識別子の定義不一致にも当たらない。

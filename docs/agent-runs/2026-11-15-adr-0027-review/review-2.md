## 判定

**却下。確信度：高。** 同一性判定にトラックの可変な別名が残っており、字幕が変わっていなくても別版になる反例がある。前回の重複判定の指摘は、原因を変えて残っている。

## 致命的・重大な欠陥

### 1. 【重大】同じ字幕でも、`-orig` の出現・消失で別資料版になる

**主張：** トラックの分類は名前への依存を外したが、同一性判定は名前に依存したままである。

**反例：**

1. 元の自動字幕の言語を `yue`、`translationLanguages` に `yue` が含まれない応答を考える。
2. `isTranslatable=true` なら、固定版の yt-dlp は同じ字幕 URL を `yue-orig` と `yue` に登録する。ADR のまとめ方では `caption_track="yue-orig"` になる。
3. 同じ字幕について `isTranslatable` が偽または欠落した応答では、`yue` だけが登録される。今回は `caption_track="yue"` になる。
4. 動画 ID と json3 のバイト列が同じでも、比較する三つ組が変わり、`different` と判定して別版の作成を問い合わせる。

指定された比較規則をローカルで再現し、同じ SHA-256 に対して `different` になることを確認した。**分類のためには同じトラックと認めた別名を、同一性のためには異なる識別子として扱っている。**

**根拠：** [ADR-0027 のトラックのまとめ方](./docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:53)、[保存する名前](./docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:70)、[同一性判定](./docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:76)。固定版の `_video.py` L4070–4083 では、`-orig` の追加だけが `isTranslatable` の条件下にあり、裸の言語コードへの追加はその外にある。[yt-dlp 2026.08.19 のソース](https://raw.githubusercontent.com/yt-dlp/yt-dlp/2026.08.19/yt_dlp/extractor/youtube/_video.py)

**発生の度合い：** 上記の二つのメタデータを与えれば、規則どおりの実装で必ず踏む。実動画で属性が取得間に切り替わる頻度は確かめられず、その発生は推測である。作為的な fixture による反例と、日常的な発生の実証は区別する。

## 崩れる前提

| 暗黙の前提 | 崩れる条件 |
| --- | --- |
| まとめたあとの名前は、取得間でも同じトラックを表す | 同じ字幕に対する `-orig` の有無が変わる。上記の重大指摘 |
| 同じ資料を再投入するとき、以前と同じスラッグを選ぶ | 題名変更や利用者の命名変更で別スラッグになる。判定対象が「そのスラッグの raw」だけなので、同一の三つ組でも `absent` になる |
| 字幕が同じなら要約の根拠は変わらない | 題名・チャプターが、固有名詞や数値の確認材料として変わる。[L86](./docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:86) はそれらを確認に使う一方、[L100](./docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:100) は根拠が変わらないと説明している。古いメタデータを残す決定は明示済みだが、この説明までは成立しない |

## 見落としと軽微な問題

- **【軽微】スラッグを変えた再投入は、重複判定を通過する。** 同じ動画・トラック・json3 を `a` として保存後、`b` を指定すると、[L77](./docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:77) の規則では `absent` になり、同じ資料の raw を追加できる。既存の取り込み手順は後段で wiki を調べるため、モデルが重複ページを防ぐ余地はあるが、スクリプトによる判定の保証は同一スラッグ内に限られる。
- **【軽微】同じ秒の根拠位置は一意にならない。** 並び順は決まったが、例えば `tStartMs=123400` と `123900` の行は両方 `[02:03]` になる。[L87](./docs/adr/0027-youtube-captions-via-pinned-yt-dlp.md:87) の時刻だけの引用では、どちらの行かを区別できない。該当箇所を探せなくなるほどの欠陥ではない。

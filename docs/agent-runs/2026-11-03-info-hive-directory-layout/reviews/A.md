## 自分の結論の見直し

結論を一部改めます。

1. **Foam のルートを作業領域の内側に移します。** 元の案では、`.foam`、`.vscode`、`.info-hive/workspace.json` をプロジェクトルートに置いていました。B、C、D はこれらを `<project-id>/` の中に置いています。こうすると次の利点があります。

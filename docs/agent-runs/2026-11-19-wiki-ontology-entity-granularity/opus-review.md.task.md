- docs/plans/wiki-ontology-entity-granularity-2026-11-19.md
- docs/plans/wiki-ontology-feature-experience-2026-11-19.md

確認する観点:
- 種類・個別の対象・記事の根拠を区別できているか。
- 1記事から複数対象、複数記事から同一対象を扱える要件か。同名の自動統合を前提にしていないか。
- 再分類を記事の種類の付け替えと混同していないか。

- 主たる提供案に、今回の変更と食い違う利用体験の約束が残っていないか。

これは要件と利用体験の設計であり、実装の完成や保存スキーマの決定を求める依頼ではない。未決定と明記した詳細を、未決定という理由だけで欠陥としない。

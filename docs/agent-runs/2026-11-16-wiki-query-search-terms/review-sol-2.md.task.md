# 2 回目のレビュー

1 回目の指摘（`review-sol-1.md`）を受けて、次のように直した。直し方が指摘の原因を取り除いたか、新しい欠陥を生んでいないかを見てほしい。

1. 照合の数え漏れと誤検出: 回答から検索の説明の文を推し量る作りでは、言い回しの数だけ漏れる。そこで、問いごとに出てはならない外の語の正規表現（`questions.json` の `leak`）を置き、回答のどこかに出たかを主の判定にした。前の走査は、思わぬ漏れを見つける補助の走査にし、合否には使わない（`warning` の引用などは人が読んで外す）。言い回し（調べ、照合、一致）と、直後の箇条書きも読むようにした。
2. 取り込む候補の名前への混入: 回答のうち wiki の内容を述べない 2 つの部分（どう探したかの説明と、取り込むとよいソースの提案）を 1 つの決まりにまとめ、ソースは資料の種類と、質問文か wiki のページにある語で示し、自分の知識で題名、著者、URL を挙げないこととした。
3. CHANGELOG の言い過ぎ: 観測したこと（書いたこと、決まりを読んだうえだったこと）だけを書いた。

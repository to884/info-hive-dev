## 崩れる前提

- **「質問文にある語」を部分文字列比較で判定できるという前提。** 実際の Q13 に対して「『C』で検索しました」を渡すと検出されない。質問の `CI` や `sqlite-vec` に文字として存在するためであり、実装言語の候補として質問された語ではない。スクリプトは NFKC・大文字小文字の正規化後の部分文字列を比較している。根拠：`check_search_terms.py:26–27, 32, 41`、同調査ディレクトリの `questions.json` の Q13。結果は再現済み。

- **答えを含む取り込み候補を、エージェントが「答え」と認識するという前提。** 例えば「wiki にはありません。取り込む候補は『Rust で書かれた uv』という資料です」とすれば、検索説明用の字句制限は適用されない。一般則の「外の知識で答えを添えない」で禁止する読みは可能だが、候補名も答えに当たるという意味判断が再び必要になる。根拠：`commands/query.md:20, 29`、`query-confidence.md:17, 88`。**Sonnet が実際にこの経路を使うかは推測であり、今回再現していない。**

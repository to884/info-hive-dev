# ADR-0029 段階3のセッション取り込み

2026-11-18。親の `aed3325` とプラグインの `ab762b6` から、セッションの原本保存と lint をつないだ。設計は [段階3の最初の実装](../../plans/adr-0029-stage3-session-raw.md) にある。

## Opus の敵対的レビュー

[設計レビュー](design-opus.md) は Claude Opus 5.5 の high で実行した。判定は条件付きで採用可、確信度は中だった。

- 過去の根が現在の根の内側にあると、ディレクトリのリンクを検査から外す指摘を確認した。現在の根が候補を含む場合はそこを使い、過去の根を使うときは検査対象の道が狭まらない起点を選ぶ。以前の根をジャンクションまたはシンボリックリンクに置き換えた回帰テストを足した。
- `.wiki-cache/` 全体を削除できるという既存の案内と、過去の根を保管する要件が衝突していた。`raw-roots.d/` は設計どおりの位置に置き、検索キャッシュを消すときにも保管するようスキーマのひな形、upgrade と lint の手順を改めた。記録はローカルの絶対パスを含み、Git の既定の対象外に留めた。
- 別 OS のパスを持つ記録も lint の `links_unchecked` に理由を出す。記録を足す前に保存先、既存の原本、スラッグを確かめる順番を設計に明記した。
- 保存時の wiki の別名を渡さない場合、当時の wiki の親を基準とする相対参照を復元できないことがある。今回の記録は、解決候補を作るための基準ではなく、候補までの道を検査するための根として使う。

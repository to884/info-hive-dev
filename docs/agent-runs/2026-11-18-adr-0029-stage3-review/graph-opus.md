# ADR-0029 段階3のグラフと統合の検証

2026-11-19。親の `feature/adr-0029-stage3` と wiki の差分を退避し、親の `1a66519` と wiki 0.35.2 の `8b4d80c` を基点として載せ替えた。取り込み結果の新しい見出し・列名、YouTube の推奨設定、段階3の `raw_sha256` の手順を統合した。配布版は、過去の raw の根を登録するオプションと出力フィールドが増えるため、マイナーの 0.36.0 を準備した。

## Opus 5.5 のレビュー

[グラフ成果物の設計](../../plans/adr-0029-stage3-graph.md) のレビューは承認だった。指摘に基づき、wiki の根への直接出力、`..` の拒否、一時名の命名と片付け、SQLite の付随ファイルの境界、途中まで公開した際の診断を明記した。

実装の初回判定は差し戻しで、重大1件と軽微2件だった。修正後の判定は承認だった。

| 指摘 | 確認と対応 |
| --- | --- |
| 外の別名から wiki を通って別の場所へ出るパスでも、`--out` が通る | `--out` の指定が wiki の外に見える場合は、先頭から順に出力先の各項目が実際には wiki 内を指すか確かめる。wiki に入る別名を拒み、外部にファイルやディレクトリを作らないことを回帰試験で確かめた。 |
| 相対パスでのロック待ちが成果物の書き込み失敗と誤って表示される | ロックのパスを渡す前に絶対化した。別プロセスから相対パスで起動する試験で従来のロック競合の案内が返ることを確認した。 |
| 入力のエラーも書き込み失敗になり、成果物が使用中の場合の案内が消える | 入力処理と出力の失敗を別々に扱う。最初の置き換えを拒まれた場合は以前の成果物が残る旨を、途中の場合は更新済み・未更新の名前を出す。成果物を開いているプロセスがあれば閉じて再実行するよう案内する。 |

SQLite の一時ファイルは URI の `mode=rw` で開く。Windows の UNC は URI のパス部に入れる形にした。Windows のローカルパスで日本語・空白・`#`・`%` を試験した。実際の UNC 共有は検証していない。 [SQLite の URI ファイル名](https://www.sqlite.org/uri.html)

## 統合試験

- Windows、Python 3.12 で取り込み、lint、検索索引、リンクと閲覧の回帰を693件実行し、684件成功、9件スキップだった。
- Windows、Python 3.12 で MCP と閲覧サーバーの試験134件を実行し、131件成功、3件スキップだった。
- Windows、Python 3.12 でグラフと関連する frontmatter、重複スラッグ、読み取り箇所の目録を126件試験し、すべて成功した。Opus の指摘を反映した後、グラフの回帰と目録の41件を実行し、すべて成功した。
- WSL、Python 3.12 でグラフと MCP 起動ファイルの46件を実行し、すべて成功した。修正後のグラフの書き込み検査9件もすべて成功した。
- wiki 0.35.2 を載せ替えた前後で、段階3の Python ソースの差分がないことを確認した。0.36.0 の候補でグラフ、取り込み、サーバーファイルの目録を125件再実行し、すべて成功した。

## プラグインの CI

[最初の実行](https://github.com/to884/info-hive-wiki/actions/runs/44424529100) では、画像のリンクを置き換える旧仕様を期待していた試験と、評価ループの試験2本が失敗した。画像の試験は終了コード、拒否されたパスと理由、リンクと参照先の保持、raw の Markdown が公開されないことを検査する。評価ループの試験には記録先の wiki と、既存の CLI が要求する raw のディレクトリを用意し、保存された JSON と source ページの SHA-256 を突き合わせる。

修正後、Windows の Python 3.12 と 3.14 で `eval/scripts` の116件と評価ループの試験2本が成功した。WSL でも取得の27件と評価ループの試験2本が成功した。プラグインの文字コード検査は70ファイルで指摘なしだった。

Claude Opus 5.5 に修正した3本の試験をレビューしてもらい、承認を得た。Opus は Windows と WSL でも該当する試験を再実行した。[再実行した CI](https://github.com/to884/info-hive-wiki/actions/runs/44425749939) では Linux と Windows の各 Python 版で、画像取得と評価ループの試験が通った。親が参照する候補 `37cc69b` では、Windows で MCP 起動とグラフの48件もすべて成功した。

## 共通部品への移行の候補

グラフのほかに、セッション取り込みの決定ファイル（`.wiki-cache/session/`）、モデルの取得済みマーカー（`models/<モデル>/verified.json`）、概要ファイルの公開が、既存の検査や独自の経路で書かれている。今回のグラフ保護と分けて、根と片付けの規則を確認する対象に残した。

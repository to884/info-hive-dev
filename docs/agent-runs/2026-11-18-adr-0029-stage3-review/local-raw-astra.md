# ADR-0029 段階3のローカル原本と経験のレビュー

GPT-6.2 Astra が [設計](../../plans/adr-0029-stage3-local-raw.md) と実装を静的にレビューし、実装の修正後に再照合した。

## 設計レビュー

- POSIX の `rename` が既存の空ディレクトリを置き換えうると指摘された。同じ raw の根に保存する処理がロックを共有し、移動直前に保存先がないことを検査する。コピー中に保存先を含む枝を見つけた場合は公開前に止める。
- ディレクトリのハッシュは隠し項目と空ディレクトリを含まない。既存のディレクトリをハッシュだけで同じと判断せず、再開時は確認した保存済み原本を指定する。派生版はバイト列のハッシュが一致するときに再利用する。
- 過去の根を確認できず所属を決められない場合は、コピーと PDF の登録を始めない。コマンドとスキル単体の手順を同じ入口につなぎ、経験の旧応答キーも保つ。

## 実装レビューと再照合

| 指摘 | 修正と回帰試験 |
| --- | --- |
| コピー元の途中で記録済みの根に入ると、その下のリンク検査が抜ける | 各項目を根の綴りに照らし、保護対象では `entry_info` で経路を検査してから読む。 |
| 旧版の経験ページは作成日と再処理の日が違うと照合できない | 既存の日付、参照、改行を保ち、同じ内容のページに保存バイト列のハッシュを足す。更新直前にページを読み直し、比較に使ったバイト列が変わっていれば止める。 |
| 保護対象にある隠し PDF を登録できる一方、lint は参照を解けない | 保護対象の隠し PDF を登録前に拒む。守る木の外の隠し PDF は、lint でも外部原本として扱う。 |

再レビューでは3件の修正を確認し、追加の修正事項は挙がらなかった。

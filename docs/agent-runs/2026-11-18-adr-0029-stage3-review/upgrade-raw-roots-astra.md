# ADR-0029 段階3のアップグレード時の raw の根の登録

2026-11-19。GPT-6.2 Astra が [設計](../../plans/adr-0029-stage3-upgrade-raw-roots.md)、実装、修正後の差分をレビューした。

- ベース外にある wiki と raw の根は絶対パスでも指定できる。相対パスではベースディレクトリの別名を経由した綴りも記録する。
- 同じ組の記録は `given`、`resolved`、`writer` を照合して再利用する。途中で失敗した場合は記録済みの根を残し、再実行で残りを登録する。
- ロックの範囲を根の登録に限ると明記した。二つの登録が重なっても共通の組は1件、異なる組はそれぞれ残る。
- 過去の別名が変わっていれば、当時の実体のパスが分かり次第追加できる。ハッシュがない旧ページは lint で版未検証として報告する。

最終判定は承認。Windows の Python 3.12 の最終差分で37件がすべて成功した。Python 3.14 では関連269件のうち261件が成功して8件をスキップし、その後に追加した並行登録の試験も成功した。アップグレードの試験では実行環境のセットアップを差し替え、lint は CLI を実行した。

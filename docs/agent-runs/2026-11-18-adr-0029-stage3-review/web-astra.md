# ADR-0029 段階3の Web ページ取り込み

2026-11-18。Web 取得の Markdown、画像、作業用の写しを共通の書き込み検査に接続した。完成した raw の版は W8 で返し、W9 の実際の読み取りと source ページの `raw_sha256` に使う。 [実装の設計](../../plans/adr-0029-stage3-web-raw.md)

## GPT-6.2 Astra の敵対的レビュー

- 設計レビューでは、画像の退避中に強制終了した場合、W8 と W9 の間で版が変わる場合、警告の確認と受理の間で検査対象が変わる場合、確定後の片付けに失敗する場合が指摘された。
- 退避が残る場合は退避を保護して続行を止めた。通常の警告受理には `check_sha256`、本文の読み取りには `raw_sha256` を渡す。作業用の名前からの退避を確定の境界とし、後片付けだけ失敗した場合は残った場所を返す。
- 実装レビューで見つかった再開時の競合は、同じロックの中で原本の版と写しを調べ、再開の報告まで組み立てる形で修正した。退避名は現行版または旧版の末尾の形式で識別し、別のスラッグの退避による誤停止も修正した。
- 再レビューは承認だった。判定は静的確認に基づき、試験は実装担当が別に実行した。

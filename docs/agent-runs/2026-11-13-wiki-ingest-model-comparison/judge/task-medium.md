# 目的

英語の Web ページを日本語に訳した 3 つの版（A、B、C）を、原文と突き合わせて評価する。訳者は伏せてある。どの版がどの訳者かを推測しないこと。

ページは 1 つある。`medium/` に `original.md`（原文。長い記事から抜き出した 5 つの節）と、`A.md`、`B.md`、`C.md`（同じ 5 つの節の訳）がある。



# 訳の規則（訳者に与えた規則）

- 本文を段落ごとに日本語に訳す。段落を統合したり、要約したりしない。
- 見出しの文言は訳し、見出しの階層（`#` の数）は変えない。
- コードブロックの中身、URL、識別子（関数名、コマンド、設定のキー）、固有名詞の英語表記は変えない。製品名や人名をカタカナにしない。
- 表は、セルの文章を訳し、表の形を保つ。
- 本文に残った雑音（目次、著者の紹介の欄、タグやカテゴリのリンク、重複した題名の行など）は削ってよい。本文の内容は削らない。
- 画像の行の直後に `> 補足:` で始まる説明を付ける（説明の正確さはここでは評価しなくてよい。画像は見られない）。
- 原文にないことを訳者の知識で足さない。

# 評価してほしいこと

各ページの各版について、原文と段落ごとに突き合わせ、次を挙げる。

1. 意味の誤り（誤訳、主語や向きの取り違え、否定の取り違え、数値の誤り）。原文の該当箇所と訳文を短く引き、重大度（重大、中、軽微）を付ける。
2. 欠落（訳されていない文や句、消えたリンク）と、原文にない追加。
3. 規則の違反（コードブロックの中身の変更、識別子や固有名詞の英語表記の変更、見出しの階層の変更、表の形の変更、本文の内容の削除）。
4. 日本語としての読みやすさの問題（不自然な直訳、文体の不統一。例: です・ます調とである調の混在）。軽微として扱う。

最後に、3 版を比べた表を作る。列は「版」「意味の誤り（重大/中/軽微の件数）」「欠落・追加」「規則の違反」「読みやすさ（10 点満点）」「忠実さ（10 点満点）」「順位」とする。点数の根拠を 1〜2 文で書く。

確かめていないことは「推測」と明記する。指摘は必ず原文と訳文の両方で確かめてから書く。

# 出力

日本語の Markdown。見出しは `## medium`、`## まとめ` とする。

# 補足

- 図の下の説明文（「(Created by …)」のような作者の表記を含む行）は、原文では本文の段落である。説明文の内容を訳文から消したり、画像の alt に移したりしたら、その旨を指摘する（作者の表記だけを短くするのは雑音の整理として許す）。
- 抜き出しの都合で、節の境目の前後が欠けていることがある。抜き出しによる欠けは減点しない。

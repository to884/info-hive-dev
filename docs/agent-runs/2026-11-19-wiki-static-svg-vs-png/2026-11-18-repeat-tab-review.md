# 同一タブ測定と描画方針の敵対的レビュー

Claude Opus 5.5 は週次上限で実行できなかったため、GPT-6.2 Astra に読み取り専用のレビューを依頼した。

- 配色切り替え条件の待機後は 50 枚を表示しており、履歴往復条件の待機後は図のない記事を表示している。同じ表示負荷での方式比較に使う標本は 50 枚を表示した時点の値とし、別記事の待機後と元の記事へ戻った後の値を集計に併記した。
- 履歴復帰で元の文書が再生成される場合、文書内のキャッシュは引き継がれない。戻る前後の文書に識別子を付け、キャッシュの比較では同じ文書内の明→暗→明だけを測った。
- 可視範囲方式では最初に描いた枚数と、全図をスクロールし終えたときの枚数を個別に確かめた。各スロットの画像を別のチェックポイントでも数え、再利用時の配色、図のラベル、初回の画像 URL との一致も検査した。
- コミット余力低下で待機を中断しても、進行中のブラウザ処理は続き得る。標本の保存を始めると同時に測定専用ブラウザの停止を始め、集計では中断前に両端の標本がそろった周だけを残すようにした。
- ワーキングセットの合計はプロセス間で共有されたページを重複して含み得る。ピークは採った標本の最大値であり、監視の周期より短い区間では標本がない場合がある。最初の可視画像のデコード完了を画面への描画完了と区別した。

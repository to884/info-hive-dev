# wiki 0.23.2 の敵対的レビュー（2 回目）

1 回目（`review-1.md`、条件付きで採用可。重大 1）の指摘を直した。目的は `task-1.md` と同じで、差分は `wiki-diff-2.patch` と `tests-diff-2.patch` にある。直しが原因を断っているか、新しい穴ができていないかを崩してほしい。

## 直したこと

- 節をまるごと外す `_skip_lines` をやめた。「raw にない語」から外すのは、取り込みの手順が決めた行き先の値 `create`、`update`、`source_only` の字面（前後が英数字と `_` でないもの）だけにした（`_WORKFLOW_WORDS_RE`）。表に書いた主張の数値や語、`## 関係するページ` の下の本文は、これまでどおり目印の対象にする。
- 試験は、表の中の `999` と、`## 関係するページ` の下の `### 概要` の本文が挙がり、行き先の値が挙がらないことを確かめる。
- ADR-0027 は承認済みなので書き換えず、除外は `ingest-workflow.md` と CHANGELOG に書いた。

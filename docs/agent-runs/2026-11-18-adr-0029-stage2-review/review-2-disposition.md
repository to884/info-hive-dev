# 第2回の指摘と main の統合

Opus 5.5 high。採用可（軽微のみ）、確信度中。重大なし。第1回の重大3件は実測で閉鎖された。

残る指摘も、次のように対応した。

- 根に `..` があると保存後に止まる：セッションと YouTube の write の最初で検査し、保存や取得より前に拒む。新しい raw が残らない試験を追加した。
- 訂正の根拠の拒否を「見つからない」とした：不確かさを source ごとに保ち、根拠として使う時点で EvidenceUnavailable を返す。止める指摘にもリンクの拒否の理由が残る。根拠の実ハードリンクで試験した。
- url の1要素配列：session_id とともに値をそろえ、1要素はスカラーと同じにした。複数値は勝手に選ばず unknown とする。
- ファイルはあるが版・身元が違う：missing の状態は設計どおりに保ち、mismatches に候補と理由を持たせ、lint の文章でも物理的な欠落と区別する。
- raw_outside の説明：commands/lint.md に追記した。
- 根を明示しない lint の一覧と件数：links は知らせの全件数にそろえ、links_wiki / links_raw で未検査（null）を分けた。
- 外の原本の範囲の未確認：raw の根を省いた rag の原本は、scope_unverified を結果に保ち、lint の raw_paths_unchecked と字幕の raw_warnings に知らせる。
- 単独のファイルで FileIdInfo を要求する：識別子は、複数の一致候補を同じ実体にまとめるときだけ求める。1候補の通常のファイルは、識別子を取れなくても結果を変えない試験を追加した。ディレクトリの回る道筋の検査は残す。

並行して概要機能が0.32.0として公開されたため、プラグインの main `d761c62` と親の main `105fd0b` を取り込んだ。未pushのブランチなので rebase した。競合した lint は概要の検査と raw の検査を両方残し、SERVER_FILES には概要の依存と wiki_raw を両方含めた。CHANGELOG の節の自動の混合を直し、概要は0.32.0、今回の raw は0.33.0に分けた。

# RAG PoC の調査分担

実施日：2026年11月4日。
`research` スキルに従い、実行環境の調査と実資料の質問作成をサブエージェントに依頼した。
モデルは `gpt-6-luna`、reasoning effort は `medium`。

## 依頼した作業

1. Qdrant の Windows 公式バイナリ、local mode との差、Ruri の検索用接頭辞と配布形式を、一次資料で確認する。
2. 原本を変更せず、抽出済み JSONL の 60 ページから暫定の質問とページラベルを作る。
   作成した根拠文字列が各ページの抽出テキストに完全一致することを全件検査する。

質問は [pdf-queries.json](../../../poc/rag/pdf-queries.json) に保存した。
対象は sample 2、3、4、9 で、合計 60 問。
原資料の PDF や製品コードの変更は依頼していない。

## 確認と限界

親エージェントが根拠の存在を再検査し、比較用コーパスへ取り込んだ。
抽出根拠の一致は、質問の妥当性や唯一の正解ページであることを保証しない。
人手レビュー済みのデータセットとは扱わず、PoC の予備評価として使用した。

実行と結果は [PoC 検証記録](../../research/rag-poc-2026-11-04/README.md) にまとめる。

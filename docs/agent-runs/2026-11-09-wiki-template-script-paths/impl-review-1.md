### 重大：空白を含むスキルパスを扱えない

- **主張**：`<skill-root>` を実際のパスに置換しても、そのパスに空白があると、シェルがスクリプトのパスを複数の引数に分割する。

  python C:/Users/Test User/.claude/skills/info-hive/scripts/wiki_search.py "query" --no-embed

  Python に渡されるスクリプト名は `C:/Users/Test` になるため、意図したスクリプトを実行できない。グラフのコマンドも同じ分割を受ける。

- **スキルの絶対パスを引用せず渡せること**：ユーザー名やインストール先に空白があると崩れる。上記の欠陥に該当する。

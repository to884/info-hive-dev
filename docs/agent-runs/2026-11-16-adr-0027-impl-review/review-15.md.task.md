# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（15 回目）

14 回目のレビュー（`review-14.md`、却下。重大 1、軽微 1）の指摘を直した。13 回目までの反例は 14 回目で崩れなかった。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-15.patch` にある。`review-12.md`〜`review-14.md` も読んでよい。

## 直したこと

1. **NFC にそろえると同じ名前になる別のファイル（重大 1）。** `load_pages` は、ページを NFC にそろえた相対パスで区別する前に、重なる名前を探す。重なれば、最初の 1 つだけを読み、残りを `ambiguous_page_path` の指摘にする（`check_wiki` は、この指摘を `only_raw` によらず返すので、`verify` は終了コード 1 になる）。新しいページの名前が既存のページと NFC で重なるときも同じである。
2. **大文字と小文字だけが違うスラッグの別版（軽微）。** `relations` は、スラッグのファイルが同じ動画の raw のどれかと同じ実体か（`os.path.samefile`）で決める。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（59 件）で、14 回目の反例も入れた（名前を正規化するファイルシステムでも確かめられるよう、一覧と読み込みを差し替えた版も入れた）。

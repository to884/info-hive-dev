# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（10 回目）

9 回目のレビュー（`review-9.md`、却下。重大 2、軽微 2）の指摘を直した。語の境目と、用意したページの場所の 2 つでは、別の形を挙げて塞ぐ直しが続いたので、出どころを断つ作りに替えた。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-10.patch` にある。`review-7.md`〜`review-9.md` も読んでよい。

## 直したこと

1. **語の境目（重大 1、軽微 1）。** `tail_problem` は、表示の文字と語を `visible_text` に通してから照らす。`visible_text` は、NFKC にそろえ、空白の制御文字（改行、タブ）を空白にし、目に見えない文字（書式 Cf、私用 Co、未割り当て Cn、そのほかの制御 Cc、サロゲート Cs）を取り除く。目に見えない文字を語の前に置いても語の先頭に入れても、取り除いたあとの前の文字で語の途中の切れ目が分かる。改行は閲覧と同じく空白になるので、段落の途中で折り返した印も通る。結合文字（M）と濁点・半濁点の記号は取り除かず、語の始まりか語の前にあれば誤りにする。さらに、訂正した語に目に見えない文字か改行を入れた定義は `bad_definition` にする。
2. **用意したページの場所（重大 2、軽微 2）。** `walk_reaches` が、ページの一覧（`wiki_pages.walk_markdown`）の規則でその場所に降りるかを確かめる。途中の段がシンボリックリンクかディレクトリでなければ拒み、ない段は書くときにふつうのディレクトリとして作られるので受け入れる。ファイルがあれば、ふつうのファイルでなければ拒む。予約された名前は、閲覧と同じ `wiki_browse_core.is_reserved_windows`（`COM¹`、`CONIN$` を含む）でも拒む。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（53 件）で、9 回目の反例も入れた。

# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（6 回目）

5 回目のレビュー（`review-5.md`、却下。重大 1、軽微 1）の指摘を直した。4 回目のあとに替えた作り（指摘を絞らない、raw をファイルの実体で見分ける、印を表示の文字だけで読む）は、5 回目で崩れなかった。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-6.patch` にある。`review-1.md`〜`review-5.md` も読んでよい。

## 直したこと

1. **印の始まりだけをコードにした印（重大 1）。** 表示に現れた印の始まりを例として数えないのは、決まった形の印（`DISPLAY_MARK_RE`）の全体が 1 つのコードスパンの中にあるとき（`_is_code_example`）だけにした。始まりだけがコードの中のもの（`` 50`〔訂正` L1-1〕 ``、`` 50`〔訂正 L999-9`〕 ``）は `_read_mark` に進み、形の誤り（`bad_mark`）になる。
2. **画像の代替の文字（軽微）。** 種類を `image` にし、「raw にない語」の対象に入れた（閲覧では本文として表示されるため）。語の境目では、本文の文字でないので、続きを切る。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（49 件）で、5 回目の反例も入れた。

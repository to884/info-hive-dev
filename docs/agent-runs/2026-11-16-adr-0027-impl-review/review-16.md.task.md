15 回目のレビュー（`review-15.md`、却下。重大 1）の指摘を直した。14 回目までの反例は 15 回目で崩れなかった。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-16.patch` にある。`review-13.md`〜`review-15.md` も読んでよい。

## 直したこと

1. **実体の鍵（重大 1）。** `wiki_captions._identity` と `raw_key` は、パスの文字列でなく、ファイルシステムが返す識別子（`os.stat` の `st_dev` と `st_ino`）で鍵を決める。別名（ジャンクション、シンボリックリンク、大文字と小文字の違う綴り）は同じ鍵に、別のファイルは名前によらず別の鍵になる。識別子を返さないファイルシステム（`st_ino` が 0）だけ、実際のパスを `normcase` した文字列に戻す。新しいページの鍵は、置くディレクトリの鍵と、大文字と小文字をそろえた名前の組のままにする（大文字と小文字だけが違う 2 つの新しいページは、ディレクトリが区別するかによらず止める）。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（60 件）で、15 回目の反例をまねた試験も入れた（大文字と小文字を区別するディレクトリは試験で作れないので、識別子を差し替えた）。

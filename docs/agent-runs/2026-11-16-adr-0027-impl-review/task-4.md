# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（4 回目）

3 回目のレビュー（`review-3.md`、却下）の指摘を、次のように直した。1〜3 回目の指摘は、どれも「照らせなかったもの（読めない、分類できない、表示の規則が違う）を除いてから数える」ところから出たので、照らせないものは誤りにする（fail closed）方針に寄せた。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-4.patch` にある。`review-1.md`〜`review-3.md` も読んでよい。

## 直したこと

1. **wikilink を表示名にしていなかった（重大 1）。** 表示される文字の並び（`wiki_captions.inline_texts`）を、閲覧の `wiki_browse_core.inline_text` と同じ規則で作る。wikilink は表示名に、行き先を残さない Markdown のリンクは「文字（行き先）」に、画像は代替の文字にする。リンクを残すかの判定は、閲覧の `_keeps_link` と `display_href` をそのまま使う。
   - 印は、本文の続きの原文（`SourceRun`。wikilink は原文のまま）の中の決まった形だけを数える。表示の並びに現れる印の始まり（全体がコードの中のものを除く）の数が、数えた印の数と違う inline は、`bad_mark` にする。`〔[[訂正]] L1-1〕` と `〔**訂正** L1-1〕` は、表示では印の始まりが 1 つあるのに、決まった形の印が 0 なので誤りになる。関係するページの `〔訂正 [[要約ページ]] L1-1〕` は、原文では決まった形で、表示でも始まりが 1 つなので通る。
   - 語の前の文字は、表示の並びで見る（`[[1]]5` の 1）。
2. **1 つの raw に絞ると、分類から外したページの指摘が消えた（重大 2）。** 絞り込みは、要約ページとして数えたかでなく、`raw` にその raw を挙げたページ（`refs_of`）で行う。
3. **一覧を作れないディレクトリ（重大 3）。** `load_pages` は `wiki_pages.walk_pages` の知らせ（`unlistable`、`unknown`）を `unreadable_page` の指摘にし、`check_wiki` は `only_raw` によらず返す。
4. **区間か字幕の行のない raw（軽微）。** `parse_raw` は受け入れない。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（46 件）で、3 回目の反例も入れた。

# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（13 回目）

12 回目のレビュー（`review-12.md`、却下。重大 1、軽微 1）の指摘を受けて、用意したページの場所の照らし方を替えた。6 回目から、ファイルシステムが同じ場所とみなす別の書き方（大文字と小文字、末尾の点、短い名前、シンボリックリンク、ジャンクションの循環と別名）が毎回見つかったので、綴りで照らすのをやめ、ファイルの実体で照らす。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-13.patch` にある。`review-10.md`〜`review-12.md` も読んでよい。

## 直したこと（`wiki_captions.load_pages`）

- 既存のファイルを指す用意したページは、ページの一覧（`wiki_pages.walk_pages`）が読んだページでなければならない。
- 新しいファイルを指す用意したページは、ページの一覧が降りた既存のディレクトリの直下にだけ置ける。新しいディレクトリが要るときは、先に作る（手順 V8 に書いた）。これで、ファイルとディレクトリがぶつかる組は作れない。
- 実体の鍵は、既存のファイルは実際のパス（`os.path.realpath` を `normcase` したもの）、新しいファイルは置くディレクトリの実際のパスと、大文字と小文字をそろえた名前の組である。2 つの用意したページが同じ鍵を指せば止まる（上書きして片方を捨てない）。
- ページの一覧が別名で読んだページも、実体の鍵が用意したページと同じなら、用意した中身で読む（書いたあとの状態にそろえる）。
- 字面の判定（`is_overlay_page`）と、除外する最上位の項目との `samefile` の判定（`lands_in_skipped`）は残す。11 回目の綴りの比べ方と `walk_reaches` は外した。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（55 件）で、12 回目の反例も入れた（ジャンクションの別名は、試験では作れないので入れていない）。

# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（9 回目）

8 回目のレビュー（`review-8.md`、却下。重大 2、軽微 1）の指摘は、6〜7 回目の直しの別の形だったので、文字や名前を 1 つずつ挙げるのでなく、種類と実体で拒む作りに直した。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-9.patch` にある。`review-6.md`〜`review-8.md` も読んでよい。

## 直したこと

1. **目に見えない文字（重大 1）。** `tail_problem` は、NFKC にそろえたあとの語の前の文字が、結合文字（M）、書式の文字（Cf。WORD JOINER、ZERO WIDTH JOINER、SOFT HYPHEN など）、私用（Co）、未割り当て（Cn）、制御（Cc）、サロゲート（Cs）、濁点・半濁点の記号なら誤りにする。
2. **Windows が読み替える名前（重大 2）。** `is_overlay_page` は、末尾の点と空白、前後の空白、`~`（8.3 の短い名前）、Windows で使えない文字、予約された名前（`CON`、`NUL`、`COM1` など）を含む段を、どの OS でも拒む。さらに `lands_in_skipped` が、書く場所の最上位の項目が、ページとして読まれない最上位の項目（`graph/`、`index.md` など）と同じ実体でないかを `os.path.samefile` で確かめる。字面の判定とファイルシステムの判定の両方を通ったときだけ受け入れる。
3. **「raw にない語」の対象（軽微）。** `load_pages` が返す、渡した綴りからディスクの綴りへの対応で、`unknown_for` も直す。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（51 件）で、8 回目の反例も入れた。

# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（11 回目）

10 回目のレビュー（`review-10.md`、却下。重大 2、軽微 1）の指摘は、どちらも「規則を写す」「範囲を並べる」作りの漏れだったので、写さず並べない作りに直した。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-11.patch` にある。`review-8.md`〜`review-10.md` も読んでよい。

## 直したこと

1. **用意したページの場所（重大 1）。** `wiki_pages.walk_markdown` と `walk_pages` に、任意の引数 `visited`（一覧を作れたディレクトリの相対パスを足すリスト）を足した。返り値の形は変えていない。`wiki_captions.load_pages` は、一覧そのものが降りたディレクトリと読んだページで `walk_reaches` を決める。ファイルがあれば、一覧が読んだページでなければならない。なければ、いちばん深いある段のディレクトリに、一覧が降りていなければならない（その下のない段は、書くときにふつうのディレクトリとして作られる）。シンボリックリンク、ジャンクションの循環、最上位の除外などの規則を写さない。字面の判定（`is_overlay_page`）と `samefile` の判定（`lands_in_skipped`）は残す。
2. **文字の種類（重大 2）。** `char_class` は、文字の範囲を並べず、Unicode の分類と文字の名前の文字体系で決める。数字は N の全体、文字（L）は名前の最初の語（KATAKANA、LATIN、GREEK、CYRILLIC、HANGUL など）を種類にする。漢字（CJK）とひらがなは照らさない（ADR で受け入れた限界）。
3. **印のない関係するページの「raw にない語」（軽微）。** `sources` が指す動画の要約ページの raw とも照らす。

ほかに、ソースの中に、エスケープのつもりで書いた U+2028 と U+2029 がそのままの文字で入っていたので、`\u2028` の形に戻した（意味は同じ）。試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（53 件）で、10 回目の反例も入れた。

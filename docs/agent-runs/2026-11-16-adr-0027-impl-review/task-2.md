# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（2 回目）

1 回目のレビュー（`docs/agent-runs/2026-11-16-adr-0027-impl-review/review-1.md`、却下）の指摘を、次のように直した。直しが原因を断っているか、直しで新しい穴ができていないか、1 回目に見なかったところに穴がないかを崩してほしい。目的と対象のファイルは `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-2.patch` にある。

## 直したこと

1. **本文の印をコードと取り違えた（重大）。** 印は、原文の字面でコードスパンを塗る方法をやめ、表示と同じパーサー（同梱の markdown-it-py）が本文の文字とした続き（inline の中の連続する `text`。`wiki_captions.text_runs`）からだけ読むようにした。印の直前の本文も同じ続きから取るので、バックスラッシュのエスケープと文字参照は元の文字に戻っており、書式やリンクの直後の印は、続きが印から始まって誤りになる。`〔` を文字参照で書いたページも読む。定義は今までどおり、定義の節の行の原文から読む。
2. **パーセントエンコードのホスト（重大）。** 判定を、通信の処理がつなぐホストで行うようにした。`wiki_youtube_url.effective_host`（パーセントエンコードを復号し、日本語などのホストは IDNA にする）と、`wiki_fetch.refuse_youtube` では、送る形にした URL の `urllib.request.Request(...).host` も見る。
3. **短縮 URL から始めた旧版の取り込みの再開（重大）。** 再開の分岐で、保存した `final_url` を同じ判定にかけ、YouTube なら終了コード 4 で止まる。
4. 軽微: スラッグに同じ動画の別版がある `write` は `different` を返す。字幕のない動画は、トラックの一覧から選ばせず、終了コード 2 で止まる。チャプターの所属はミリ秒の開始で決める。`parse_raw` は、フェンスの外に、生成器が書く行（見出し、区間の見出し、フェンス、「この区間に字幕はない」、空行）だけを受け入れる。

ADR の「印」の行も、パーサーで読むことに合わせて書き直した。試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（43 件）で、1 回目の反例も入れた。

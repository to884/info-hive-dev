# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（12 回目）

11 回目のレビュー（`review-11.md`、却下。重大 1、軽微 1）の指摘を直した。10 回目までの反例は 11 回目で崩れなかった。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-12.patch` にある。`review-9.md`〜`review-11.md` も読んでよい。

## 直したこと

1. **同時には書けない用意したページの組（重大 1）。** `load_pages` は、用意したページを 1 つずつでなく組として照らす。どの OS でも、大文字と小文字をそろえた綴りで比べ、2 つのページが同じ場所になるか、一方の場所がもう一方の途中のディレクトリになるなら止まる。ディスクにある項目との重なりは、今までどおり、ディスクの綴りに直したうえで `walk_reaches`（一覧が読んだページか、一覧が降りたディレクトリの下か）で照らす。
2. **「raw にない語」の文字の種類（軽微）。** 語の続きを、語の境目と同じ `char_class` で切る（`_word_runs`）。数字は 1 文字から、ほかの種類は 2 文字から挙げる。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（55 件）で、11 回目の反例も入れた。

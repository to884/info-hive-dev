# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（7 回目）

6 回目のレビュー（`review-6.md`、却下。重大 3、軽微 1）の指摘を直した。5 回目までの指摘への直しは、6 回目で崩れなかった。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-7.patch` にある。`review-4.md`〜`review-6.md` も読んでよい。

## 直したこと

1. **結合文字で語の切れ目を隠せた（重大 1）。** `tail_problem` は、語の前の文字を、NFC にそろえた表示の文字で見る。NFC にした語の始まりが結合文字であるか、語の前に結合文字が残るときも誤りにする。
2. **ページとして読まれない場所の用意したページ（重大 2）。** `wiki_captions.load_pages` は、overlay の相対パスが、書いたあとに wiki のページとして読まれる場所（`wiki_pages.is_page_path` と同じ規則。`.` で始まる段と `..` を含まない）でなければ止まる（`verify` は終了コード 1）。
3. **投稿者の字幕の名前が自動字幕の別名と重なる（重大 3）。** `--track` は、一覧に出す名前で先に照らし、別名は名前で当たらないときだけ使う。
4. **拡張子が `.MD` の raw（軽微）。** 置いてある raw の検索は、拡張子の大文字と小文字によらない。

試験は `python -X utf8 -B -m unittest tests/wiki/test_wiki_youtube.py`（50 件）で、6 回目の反例も入れた。

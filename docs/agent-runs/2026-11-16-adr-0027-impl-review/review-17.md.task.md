## 直したこと

1. **綴りの補正をやめた（重大 1）。** `disk_spelling`（大文字と小文字だけが違う既存の項目へ名前を直す処理）を外した。`load_pages` は、渡した場所にファイルがあるか（`os.path.lexists`）と、どの実体か（`_identity`。ファイルシステムの識別子）を、ファイルシステムに尋ねて決める。
   - ファイルがあれば、その実体がページの一覧が読んだページの実体のどれかでなければならず、ページの相対パスはその一覧の綴りにする。
   - なければ新しいページで、置くディレクトリの実体が、一覧が降りたディレクトリの実体のどれかでなければならない。新しいページは、その実体に降りるすべての道筋の下に置いたものとして数える。
   - 大文字と小文字を区別しないディレクトリでは、`detail.md` は既存の `Detail.md` として扱われ、区別するディレクトリでは新しいページになる。OS が実際に書く場所と同じである。

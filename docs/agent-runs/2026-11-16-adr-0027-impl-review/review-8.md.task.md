# ADR-0027 の実装（wiki 0.22.0）の敵対的レビュー（8 回目）

7 回目のレビュー（`review-7.md`、却下。重大 3、軽微 1）の指摘は、どれも 6 回目の直しの別の形だったので、別の形が出ない作りに直した。直しが原因を断っているか、新しい穴ができていないか、これまでに見なかったところに穴がないかを崩してほしい。目的と対象は `task-1.md` と同じで、サブモジュールの差分は `wiki-diff-8.patch` にある。`review-5.md`〜`review-7.md` も読んでよい。

## 直したこと

1. **語の境目（重大 1）。** `tail_problem` は、表示の文字と語を NFKC にそろえて照らす。NFKC は、全角と半角、合成済みの文字と分解した文字をそろえる。そろえたあとで、表示の末尾が語で終わらない（語の始まりが前の文字と合成された）か、語の始まりが結合文字か、語の前に結合文字か濁点・半濁点の記号が残れば誤りにする。
2. **用意したページの場所（重大 2）。** `is_overlay_page` は、除外する最上位のディレクトリとファイルの名前を、大文字と小文字によらず比べる（どの OS でも）。`load_pages` は、用意したページの場所を、ディスクにある項目の綴りに直してから（`disk_spelling`）、もう一度照らし、その綴りでページの集合に入れる。
3. **トラックの選び方（重大 3）。** トラックに、種類を前に付けた ID（`uploaded:ja`、`asr:ja-orig`）を付け、一覧（`tracks[].id`）に出す。`--track` は ID で選び、名前と別名は 1 つに決まるときだけ使う。手順 V2 も ID で選ぶように書いた。
4. **動画の ID（軽微）。** ID の照合を `fullmatch` にした（末尾の改行を受け入れない）。

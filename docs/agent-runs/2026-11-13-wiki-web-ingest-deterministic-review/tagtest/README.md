# タグの往復の試作（2026-11-13）

設計案の「試した結果」の試作のスクリプトである。

- `make_nodes.py`: 基準の raw（`wiki_fetch.py` で取ったままの Markdown）の段落を、リンク、強調、インラインのコード、守る語をタグにした形に変える。設計案では中間表現から作るが、試作では Markdown から作った。
- `check_fill.py`: モデルが返した訳文のタグを、元の段落と照らす（多重集合、閉じ、空の中身、入れ子、Markdown の記法）。結果は、設計案の非対称の入れ子の規則に直す前のもので、入れ子は対称に比べている。

試料（段落の原文）と Sonnet 5.5 の訳文は、ページの著作権のためにリポジトリに入れていない。結果は、32 段落のうち 31 段落が一致し、1 段落が入れ子の違いで止まった。

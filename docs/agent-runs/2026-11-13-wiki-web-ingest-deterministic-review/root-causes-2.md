## 3 版でも残る限界

- モデルが「守る語」に挙げなかった固有の名前は、訳されても検査で分からない。候補は原文の形から挙げるので、見落としは減るが、なくならない。
- 原文にない内容の追加は、検査で止められない。取り込みの記録に、増えた英数字の並びを残すだけにする。
- 錠は、同じ wiki を同じ機械で使う前提である。ネットワークのフォルダーの上の複数の機械での同時の取り込みは、対象にしない。

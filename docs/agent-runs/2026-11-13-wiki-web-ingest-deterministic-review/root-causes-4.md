# 4 版のレビューの指摘の、原因の構造による分類

対象: [docs/plans/wiki-web-ingest-deterministic-2026-11-13.md](../../plans/wiki-web-ingest-deterministic-2026-11-13.md) の 4 版。レビュー: [review-4.md](review-4.md)（GPT-6.1 Sol、effort high、却下）。前の分類は [root-causes.md](root-causes.md)、[root-causes-2.md](root-causes-2.md)、[root-causes-3.md](root-causes-3.md)。

4 版で、3 版の指摘（今の出力との一致、旧来の書き込み口、錠の回収、書きかけの公開、同じ綴りの語）は崩せなかった。新しい指摘は次のとおり。

| 原因の構造 | 崩れた前提 | 指摘 | 5 版での変更 |
| --- | --- | --- | --- |
| 管理用のパスを、スラッグに接尾辞やワイルドカードを付けて組み立てた | 違うスラッグの管理用のパスはぶつからない | 重大 1（`x` の錠と `x.lock` の作業場所）、重大 2（`clean x` が `x.v2` の一時ファイルに当たる）、軽微（公開の直後に止まると一時ファイルが清掃から漏れる） | スラッグをそのまま 1 つのフォルダーの名前にし、その下に決まった名前の子を置く。一時ファイルは `raw/.ingest-tmp/<スラッグ>/` にまとめ、常に確定前の生成物とする |
| 推測による除外の一部が、まだ木の外にあった | `aria-hidden` の要素は画面に見えない | 重大 3（目に見える式が消える） | 木に入れないのを、文字を描かない要素の種類（`script`、`style`、`template`、`head`）だけにする。`aria-hidden`、`hidden`、`noscript` は雑音の候補にする |
| 中間表現の型が、HTML の内容のモデルより狭かった | 表のセルはインラインだけを持つ | 重大 4（セルの中の段落とコードブロック） | ブロックを入れられる HTML の要素は、すべて子のブロックを持てる形にする。子のブロックを持つセルのある表は、HTML の表として描く |
| 判断を表す形が、正しい判断の一部を表せなかった | 訳さないページの雑音は、ノードごとに消せる | 重大 5（段落の末尾の共有の文言） | 訳さないページに `drop_text` を足す。消す文字列は、1 つの `text` の中にちょうど 1 回現れることを条件にする |
| 記録の項目が判断の項目と対応していなかった | 守る語の判断は `keep` と `translate` だけである | 軽微（`release_terms` が記録から漏れる） | 取り込みの記録に、`release_terms` と `drop_text` を足す |
| 文書どうしの食い違い | — | 軽微（`root-causes-3.md` と本文の旧来の使い方の扱い） | `root-causes-3.md` を本文に合わせた |

## 5 版でも残る限界

前の版の限界（候補に挙がらない固有の名前、原文にない内容の追加、境目をまたぐ句、同じ機械の前提）は変わらない。子のブロックを持つセルのある表は、raw の中で HTML の表になり、Markdown の表としては読めない。

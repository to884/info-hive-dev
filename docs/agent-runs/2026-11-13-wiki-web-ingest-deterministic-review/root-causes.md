# 1 版のレビューの指摘の、原因の構造による分類

対象: [docs/plans/wiki-web-ingest-deterministic-2026-11-13.md](../../plans/wiki-web-ingest-deterministic-2026-11-13.md) の 1 版。レビュー: [review-1.md](review-1.md)（GPT-6.1 Sol、effort high、却下）。

指摘の反例を 1 つずつ塞がず、反例が崩した前提ごとにまとめ、前提そのものを変えた。

| 原因の構造 | 崩れた前提 | 指摘 | 2 版での変更 |
| --- | --- | --- | --- |
| モデルに Markdown の文字列を返させていた | 印がそろっていれば記法も対応も保たれる | 重大 1（リンクの括弧を消す、印を入れ替える）、重大 3（表のセルの `\|`）、重大 2 の後半（段落の中の改行）、軽微（印の集合と多重集合） | モデルには平文と対のタグだけを返させ、記法とエスケープは描画がする。タグは木として読み、多重集合と入れ子を照らす。タグの番号が URL を持つ |
| 変換が文字列を返し、構造を失っていた | ブロックの文字列の境目が、訳す単位の境目になる | 重大 2 の前半（引用やリストが 1 つの文字列になる）、軽微（題名が blocks の外）、軽微（引用の中のコードで言語の判定が崩れる） | `Converter` が中間表現の木を返し、描画を別にする。題名もノードにする。言語の判定は文章のノードだけで計算する |

## 2 版でも残る限界

- リンクの文言を別のタグの中に書く、意味の上での取り違えは、英数字の名前のリンクを除いて検査できない。
- 文の先頭の固有の名前は、名前の照合の対象外になる。
- raw の不変性の照合は、偶然の書き換えを見つけるためのもので、改ざんを防ぐものではない。

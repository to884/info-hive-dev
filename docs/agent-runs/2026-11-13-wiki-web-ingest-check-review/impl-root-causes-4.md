# 実装の 4 回目のレビューの指摘の、原因の構造による分類

対象: `wiki_rawcheck.py` の 4 回目の実装。レビュー: [impl-review-4.md](impl-review-4.md)（GPT-6.1 Sol、effort high、却下）。前の分類は [impl-root-causes-1.md](impl-root-causes-1.md)〜[impl-root-causes-3.md](impl-root-causes-3.md)。

3 回目までの指摘は崩せなかった。重大な指摘は 3 件で、2 件は 1 回目から続く「パーサーが知っていることを、正規表現やパーサーの出力の一部で推し量る」構造の名残だった。

| 原因の構造 | 崩れた前提 | 指摘 | 直し方 |
| --- | --- | --- | --- |
| トークンの木だけを照らしていた | raw の中身は、すべてトークンの木に現れる | 重大 1（パーサーが捨てる、表の列数を超えるセルへの書き足し） | 削除の段は、木の比較に加えて本文全体を文字の上でも部分列として照らす。訳と補足の段は、表の行ごとのセルの数を元の行から数えて比べる |
| 参照の定義の行を正規表現で推し量っていた | `[x]: …` の形の行は参照の定義である | 重大 2（段落の続きの行を定義とみなす） | 定義の行は、中身の行を持つブロック（段落、見出し、コード、表、区切り線）のどれにも覆われない行とする。覆うかどうかはパーサーが決める |
| 削除で自然に変わる親の属性を固定していた | 消すことだけをすれば、親の属性は変わらない | 重大 3（番号つきのリストの先頭の項目を消すと `start` が変わる） | 削除の段では `start` を比べない。訳と補足の段では比べる |
| frontmatter の値を、ほかと違う読み方で読んでいた | `translated_by:` の最初の行が値である | 軽微（キーが 2 つあると、ほかのスクリプトと値が変わる） | ほかのスクリプトと同じ frontmatter のパーサーで読み、キーが 2 つ以上あれば誤りにする |
| 雑音の規則の文字数を正規表現で数えていた | 記号を除けば表示上の文字数になる | 軽微（コードの中の `*`、`#` で始まる段落） | 段落かどうかと表示上の文字は、同じパーサーで読んで決める。タグのリンクの判定も同じにした |
| 試験の説明 | — | 軽微（失敗を入れる場所と説明の食い違い） | 説明を直した |

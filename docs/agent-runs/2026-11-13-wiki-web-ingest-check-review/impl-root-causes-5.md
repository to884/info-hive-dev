# 実装の 5 回目のレビューの指摘の、原因の構造による分類

対象: `wiki_rawcheck.py` の 5 回目の実装。レビュー: [impl-review-5.md](impl-review-5.md)（GPT-6.1 Sol、effort high、却下）。前の分類は [impl-root-causes-1.md](impl-root-causes-1.md)〜[impl-root-causes-4.md](impl-root-causes-4.md)。

4 回目までの指摘は崩せなかった。重大な指摘は 2 件だった。

| 原因の構造 | 崩れた前提 | 指摘 | 直し方 |
| --- | --- | --- | --- |
| 補足を丸ごと取り除くので、中にあるものが検査から外れる | 補足が段落だけなら、取り除いても検査に穴は開かない | 重大 1（補足の中の画像が、ファイルの有無と画像の比較を逃れる） | 補足に画像を書けないことにし、書けば誤りにする |
| 照らし合わせの結果を覚えず、失敗の場所を探すために照らし直していた | 貪欲に照らせば、木全体でも速い | 重大 2（深い入れ子で呼び出しが指数的に増える） | 節点の組ごとの結果を覚え、失敗の場所は最上位でだけ、覚えた結果を使って探す |
| 補足の本文の空の判定で、インラインのコードを除いていた | コードを除いた文字で、本文が空かを判定できる | 軽微（コードだけの補足を空とみなす） | 補足の本文にはインラインのコードも含める |
| リンクの比較を、リンク先だけにしていた | リンクの属性はリンク先だけである | 軽微（訳と補足の段で title を書き足せる） | リンク先と title の組で比べる |

リンク先の中のエスケープ（`\!` を `!` にする）だけを消すことは、パーサーが同じ URL と読むので、止めない（レビューも、リンク先の変更の反例ではないとしている）。

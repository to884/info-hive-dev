# 実例の失敗型を再現した転記の追試結果

2026年11月19日、開発専用の合成原稿4種・24行で、現行の転記指示と「提出前に連続記号の位置と個数を見直す。」を加えた指示を比較した。両群は同じ順に同じ16画像を受け取った。SolとAstraがそれぞれ旧・新で独立に一度ずつ読み、合計96票すべてが固定正解と正規化後に一致した。判読不能票と第三読は0件だった。

| 指標 | 旧指示 | 新指示 |
|---|---:|---:|
| 正規化後の全文一致 | 24/24行 | 24/24行 |
| 対象記号の脱落 | 0行・0字 | 0行・0字 |
| 全文字の不足 | 0行・0字 | 0行・0字 |
| 過剰な句読点・記号 | 0行・0字 | 0行・0字 |
| 余分な文字全般 | 0行・0字 | 0行・0字 |
| 未決定 | 0/24行 | 0/24行 |

誤→正、正→誤、既知→未決定、未決定→既知はいずれも0行。双方で確定した24行を同じ行どうしで比較した結果は、全行の集計と一致する。

| 再現した失敗型 | 画像と正解の確認 | 全文一致 旧／新 |
|---|---|---:|
| 細い閉じ記号（原稿1・2） | 枠内の12字は150 DPIで各5画素幅。2連続の4行は8/8字を両群で転記。枠外に置いた同種の9字は全て除外。 | 12/12行・12/12行 |
| 枠端の句点（原稿3） | 枠内幅1/3の2字と0/3の1字は全て除外。2/3の2字と3/3の1字は全て採用。 | 6/6行・6/6行 |
| 縦書きの境界と隣接列（原稿4） | 末尾字全体が7/15入った2字は除外、8/15入った1字は採用。隣接2列の3行では所属と右から左への順序が一致。 | 6/6行・6/6行 |

**改善効果は判定不能。** この試料では新指示による悪化は観測されなかった。実例で問題になった近接と境界を再現したが、旧指示で脱落・過剰転記・未決定が一件も起きなかった。集計の `supports_replication: false` は、不足が減るという事前の判定式を満たさなかったことを表す。原稿全体の文脈や符号の曖昧さを再現しておらず、正式評価への一般化には使えない。

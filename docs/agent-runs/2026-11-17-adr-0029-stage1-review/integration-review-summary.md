## 直したもの

- main の図の走査が、段階1で廃止したジャンクション判定を呼んでいた。共通の link_kind を使い、SVG のハードリンクを許す既存の規則を保った。

## 残した範囲と判断

- raw のリンクの検査は段階2であり、この版では実装していない。
- 補助的な検索の backlinks と判定レイヤーの mention は、拒否した記事と同名の読める別ページへの解決を区別しない経路が残る。禁止した記事を読む迂回ではないが、後続の参照の整合性の対応として残す。
- GraphPages を sorted や内包表記で作り直すと拒否の属性が失われる。現呼び出し元は保持しており、browse は引数で明示している。将来リストを作り直す場合は、拒否を明示して渡す。
- [[concepts/jump]] は規約上 concepts/jump.md のページを指す。リンクのディレクトリ concepts/jump 自体では、そのページの存在や拒否は確定しないので、リンク切れを消す提案は採らなかった。その下のパスを指す [[concepts/jump/x]] は拒否として扱う。
- 検査後の同時の置き換えを完全に防ぐものではない。走査と検査の時点で配置されたリンクが対象である。

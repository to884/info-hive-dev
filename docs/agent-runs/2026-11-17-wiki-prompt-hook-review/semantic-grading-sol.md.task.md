各JSONには question、assertions（期待する命題。今回の回答の採取前に固定）、pages（各スコープと相対パスに対応するwiki本文）、answers（匿名ID、answer、opened）が入っています。全158回答を採点してください。モデル報告の節は削除済みです。開いたページの根拠は成功したReadのtool_use/tool_resultの対応から取得しています。

各assertionを、answersの「答え」「根拠」の内容と、実際にopenedにあるpagesの本文から意味で判定します。
- supported: 命題を実質的に述べ、開いたページに支えられている。言い換えや意味の同じ要約を認めます。
- omitted: 命題を述べていない、または重要な要素や数値を欠く。候補の復唱、リンク名やファイル名に単語があるだけでは supported にしません。
- wrong: 命題に反する主張をしている。期待値の全要素を述べないだけなら omitted です。

命題は複数の要素を持つことがあります。主な内容と、意味を左右する条件・数値・留保を照合してください。期待値のsourceは索引用の抜粋であり、正本はpagesの本文です。期待値自体に誤りがあると気づいたら、最終報告で具体的に指摘し、その項目を勝手に書き換えないでください。

- citation_errors: 存在しない[[リンク]]を根拠にした、同名ページのスコープを混同した、未読ページを読んだ根拠のように使った等。未読であると正直に明示した出典の紹介は、根拠に使った引用と区別し、誤りにはしません。「根拠」の節にあるだけで機械的に未読引用と判定しないでください。未確認の出典や関係のない候補のリンクも、その役割で判定します。既読のページの中の主張を「このページの記録では」と帰属させて答えることは許されます。
- unsupported_claims: 答えの重要な事実のうち、開いた本文で支えられないもの。sourceの記述を一般化した断定、観測の仮説を確定した原因として扱ったものを含みます。問いが判断を求める場合、明記した比較根拠からの自然な限定付きの結論は、それだけで誤りにはしません。未読であると明示した紹介を、未読を隠した主張とは数えません。

## 崩れる前提

`has_console()` が保証するのはコンソールへの所属であり、標準ハンドルの有効性ではない。`FreeConsole` 後などに古いコンソールのハンドルを保持して渡す条件まで、有効な入出力になるとは保証できない。

また、判定から起動までの間に別スレッドが `FreeConsole` を呼べば、判定結果と起動時の状態が食い違う可能性がある。ただし、これは**推測**であり、現在の自前の MCP 経路には `FreeConsole`／`AttachConsole` の呼び出しを見つけられなかった。今回の実装の欠陥とは判定しない。

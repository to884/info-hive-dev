```text

```

`ontology.yaml`には、YAMLのコメントなどとして`P固有値`という文字列を含める。通常ファイルのハードリンク数は1で、配置は問い合わせ前から変わらない。

Aの判定は次のようになる。

1. `U/concepts/policy.md`は記事として受け入れられる。ADR-0029はPOSIXのbind mountを記事のリンク禁止に含めない。
2. その識別子を`x`とすると、U側の集合には`x`が入る。

4. 他に重なりがなければ`disjoint`になる。

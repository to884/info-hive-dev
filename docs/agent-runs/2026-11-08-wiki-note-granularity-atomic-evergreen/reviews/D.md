条件・根拠を主張と同じページに残す単位、同一 raw の再取り込みと独立生成の区別、graph の文書と実装の不一致についての指摘は崩せなかった。**全面的な一文一ページ化が必須である、という前提には依存していない**ため、A・Bへの攻撃のすべてがそのまま当たるわけではない。

## 自分の成果の見直し

私の選別併用案も、今回の攻撃から除外できない。

- **初回のページ境界の未確定は当たる。** 「再利用する問い」「独立した更新単位」「既存ページ優先」は意味判断であり、数えられる情報だけで決まらない。候補 ID と判定表の保存は再実行の安定化にはなるが、初回の別モデル間一致の証明にはならない。
- **graph のノード ID 移行の欠落も当たる。** 型の対応付けや `graph.node_type` を変える際、既存の明示的参照を維持できるという扱いは撤回する。
- **PoC の一致率を採用根拠にしすぎる攻撃も一部当たる。** 私の案には人が定めた候補との抽出精度・再現率を測る項目があるため、Cとまったく同じではない。しかし、検索・再利用の改善を測ることと、それを採用の必須条件にすることを十分に区別していなかった。
- **採点の差を実証結果のように扱うことはできない。** 自案にだけ照合・記録の手順を与えて再現性を高く評価しても、記事単位そのものの優位性を分離できない。
- Aの類似度だけによる同一視、Bの題名を短くするための条件削除、CのCSVの選択肢脱落は、私の記述にはそのままは当たらない。ただし、これで他の抽出例の忠実性が証明されたわけではない。

したがって、私の結論も、**「選別併用を再現性のある完成手法として採用する」から、「選別併用は未検証の候補として残る」へ限定する。確信度は中。**

## 判定

**却下。確信度：高。** browse の更新検知に入力を取りこぼす反例があります。また、列挙時のエラー処理は Python 3.10 の既存動作と異なり、I/O 障害をページの削除として索引へ反映する経路があります。

## 致命的・重大な欠陥

1. **【重大】`indexes/` がディレクトリのシンボリックリンクの場合、browse の入力が印に含まれず、変更後も古いナビゲーションを返す。**

   次の配置が反例です。

   ```text
   wiki/indexes -> 外部の索引ディレクトリ
   外部の索引ディレクトリ/sources.md
   ```

   計画の `walk_markdown(root, keep_top_dirs={"indexes"})` は、除外を解除しても、ディレクトリのシンボリックリンクには降りません。一方、変更しない `wiki_lint.index_files()` は、`indexes` 自体を起点に `rglob()` するため、その先の `sources.md` を返します。つまり、**読む入力と、変更検知の対象が一致しません。**

2. **【重大】列挙時の `OSError` をすべて握り潰すと、Python 3.10 では I/O 障害が索引の大量削除に変わる。**

   wiki の索引を正常に作った後、ページのあるディレクトリへの `os.scandir()` が、読み取り障害の `OSError(errno.EIO)` を返す反例です。

   Python 3.10.11 の `rglob()` は、このエラーを呼び出し元へ送出します。計画と試作では「一覧を作れない」として飛ばすため、通常終了した空または部分的なページ集合になります。試作に `EIO` を注入すると、例外ではなく `[]` が返り、`unlistable` にだけ記録されることを確認しました。

   MCP の `stat_signature()` と `collect_pages()` が、この状態の集合を受け取ると、`WikiIndex.refresh()` は以前あったページを消えたものとして扱います。`known` にあって `current` にない索引行を `deletes` に入れるためです。障害が両方の走査中に続けば、検索結果が欠落し、既存の埋め込みを含む索引行が削除されます。

   「今の `rglob` と同じ」という説明は、少なくとも Python 3.10 について誤りです。3.10.11 の実装がここで捕捉するのは主に `PermissionError` であり、一般の `EIO` ではありません。[CPython 3.10.11 の実装](https://github.com/python/cpython/blob/v3.10.11/Lib/pathlib.py#L403)で確認しました。

   根拠：[計画:82](C:/Works/info-hive-dev/docs/plans/wiki-walk-excluded-dirs-2026-11-11.md:82)、同83・107行、[walk_probe.py:93](C:/Works/info-hive-dev/docs/agent-runs/2026-11-11-wiki-walk-excluded-dirs/walk_probe.py:93)、[wiki_index.py:849](C:/Works/info-hive-dev/info-hive-wiki/skills/info-hive/scripts/wiki_index.py:849)、同852–863行。

   試験189行は例外を出さないことだけを求めており、既存索引を持つ MCP で障害を起こしたときの削除を検証しません。

## 崩れる前提

- **「`keep_top_dirs={"indexes"}` の結果は、索引入力を含む」**  
  `indexes/` 自体がディレクトリのシンボリックリンクなら崩れます。除外解除と、リンクをたどるかどうかは別です。

- **「一覧を作れない場合を飛ばす動作は、Python 3.10 以上で共通」**  
  エラーの種類と Python の版で異なります。権限エラー一種類の実測から、一般の `OSError` へは広げられません。

- **「`samefile()` が返す同一性を、そのまま循環検出の根拠にできる」**  
  同じ `st_dev` と `st_ino=0` を返す条件では、別ディレクトリも同一扱いになります。Raw の設計はこの条件を扱っていますが、試作には対応がありません。

- **「旧版と同じ並びを返す」**  
  NFC にすると同じになる別名が共存すると、追加した綴り順によって旧版の安定ソート順が変わります。

## 見落としと軽微な問題

1. **【軽微・本文と試作の不一致】循環判定に、参照先の Raw 設計と同じフォールバックがない。**

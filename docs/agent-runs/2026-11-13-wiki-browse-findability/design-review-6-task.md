# 依頼: browse の索引とサイドバーの設計（6 版目）の敵対的レビュー

対象は `docs/plans/wiki-browse-findability-2026-11-13.md` である。Claude Code のプラグイン `wiki`（サブモジュール `info-hive-wiki/`）の閲覧機能 `/wiki:browse` の索引のページとサイドバーを直し、静的の検索を足す設計である。

## 目的

この設計は、次を満たさなければならない。

- 作者の決定（設計書の「作者が決めたこと」）に従う。
- 第 1 段階の設計（`docs/plans/wiki-browse-stage1-2026-11-09.md`）の「守ること」1〜9 と、4 の画面の契約を破らない。
- 承認済みの構造の直し（`docs/plans/wiki-browse-structure-2026-11-11.md`）と食い違わない。
- 実装者がこの設計だけで、静的版とサーバーで同じ結果になるものを作れる。
- 今の実装（`info-hive-wiki/skills/info-hive/scripts/wiki_browse_core.py` など）と試験から見て、設計が前提にしている事実が正しい。

## これまでの経過

# ADR-0025 の承認の条件 5 の測り方のレビュー（1 回目、測る前）

## 目的

`docs/research/adr-0025-condition5-2026-11-16.md` は、ADR-0025 の承認の条件 5（OCR の確信度の閾値）を測る前に決めた、測り方、試料の分け方、閾値の選び方、合否の基準である。まだ何も測っていない。

条件 5 の本文は、`docs/adr/0025-pdf-text-layer-with-pdfminer-vertical.md` の「承認の条件」の 5 にある。確信度の数え方は、同じ ADR の「OCR の確信度とページの確認」と、`info-hive-rag/scripts/rag_ocr_confidence.py`、`rag_review.is_low`、`rag_pdf.confidence_min` にある。

次の性質を壊す欠陥だけを、重大として挙げてほしい。

1. **選ぶ資料と確かめる資料が漏れない:** 確かめる資料の結果が、閾値の選び方や測り方の決めごとに影響しうる経路がない。同じ原稿の画像が両側に入らない。
2. **測る量が、条件 5 の文言と製品の決まりに合っている:** (a)〜(c) の数え方、行の対応、誤りの決め方が、ADR の条件 5 と、製品が実際にページに確認を求める決まりと食い違わない。食い違うと、合格しても製品の振る舞いを保証しない。
3. **合否が、測ったあとの選択で動かない:** 測ったあとに決められる自由（除く行、対応の決まり、画像の強さ、配分）が残っていない。
4. **合格が、たまたまで出にくい:** 数が少なすぎる、偏った試料で合格しうる、などの問題がない。

公開の PDF の中身はこの依頼に含めない。合成の原稿はリポジトリの `docs/adr/` である。

## 確かめた事実（参考）

- 製品の決まり: `is_low` は `confidence_min < threshold`。読めなかった行（本文が空）は確信度 0。行のないページは 1.0。
- 今の既定の閾値は 0.8（未校正）。

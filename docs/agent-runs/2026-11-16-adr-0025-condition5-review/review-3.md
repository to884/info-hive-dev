## 判定

**却下。確信度：高。** 新しい分散の計算でも、真の誤り率が基準未満なのに、15%を超える確率で合格する反例があります。また、別の PDF の OCR キャッシュを照合せず採点でき、指定された性質の **4 と 2** を崩せました。

## 致命的・重大な欠陥

### 1. 重大：情報のある原稿が一つだけでも、割合の下限が100%になる

**主張：** `cluster_bound` は、観測された分子と分母が一致すると、すべての残差がゼロになり、下限も100%になります。低い行や誤りが一原稿に集中していても、最低件数を通過できます。

**反例：** 閾値を0.5とし、12原稿×5ページ、各ページ38行、すべて `scan` とします。

- 一原稿の一ページだけ、38行すべてが誤りで、確信度0.1。
- 残りの行はすべて正しく、確信度0.9。
- 対応はすべて有効な1対1とする。

対象の `measure` による結果は次のとおりでした。

| 判定量 | 結果 |
| --- | --- |
| 低い行・誤り・捕捉 | 各38行 |
| (a)、(b) | 両方1.0 |
| (a)、(b) の下限 | **両方1.0** |
| (c)：`always`、`auto` | 両方1/60 |
| (c) の上限 | 両方 **0.0466** |
| 点の値・区間・最低件数 | **すべて通過** |

(a) の計算に入る組は `(38,38)` が一つ、`(0,0)` が十一です。比が1なので、`y − R·x` は全原稿でゼロになります。t分布を掛けても幅はゼロのままです。

これは、低確率の特殊配置だけではありません。次の**反例用の確率モデル**を仮定します。

- 原稿間は独立。
- 各原稿は確率10%で、固定した一ページの38行がすべて低確信度になる。
- そのページは確率40%で全行が誤り、確率60%で全行が正しい。
- その他の行は正しく高確信度。

このモデルの真の (a) は **40%**、(b) は100%、(c) は2%です。(a) が不合格であるにもかかわらず、上記配置だけで、

`12 × 0.1 × 0.4 × 0.9¹¹ = 15.0629%`

の確率で合格します。実資料がこの分布だという主張ではありません。文書が認める原稿内相関の下で、片側95%という限界が成立しない明示的な反例です。

公開側に基準を満たす固定配置を与えると、`score.py` の評価処理でも **合成・公開の両方が合格**しました。

## 崩れる前提

- **原稿単位で分散を計算すれば、少数原稿への集中にも対応できる。** 分子と分母が一致する観測しかなく、他原稿の分母がゼロだと、分散がゼロになります。
- **20行以上あれば、割合の判定に十分な情報がある。** 38行が一原稿・一ページで一緒に変わる反例でも通過します。
- **タグとページ番号が同じなら、キャッシュは現在の入力に対応する。** PDFの再生成や、同じタグでの入力差し替えによって崩れます。

# 条件 5 の 2 回目の測り方のレビュー（7 回目、確かめる資料を数える前）

## 目的

6 回目（`review-6.md`、却下）の指摘を直した。直し方は `docs/research/adr-0025-condition5-v2-2026-11-16.md` の「6 回目のレビューで直したこと」と、「合否」の 2.5 にある。

- 合否に、単位ごとの比の平均の片側 95% の限界（1 標本の t 分布）を足し、行で重みを付けた限界と両方を満たすことを求める（`scripts/score_v2.py` の `measure` の `mean_bound`、`verdict` の `unit_bounds`）。
- 照合の材料のない目で作った正解は止める（`probe_analyze.apply_eye_truth`）。照合の記録に OCR の結果の SHA-256 を残し、採点のときに照らす（`compare_flags.py`、`score_v2.py`）。「不利な側」の件数に、除いた正解とつながる行を数える。

作者は、選ぶ資料の公開が単位ごとの平均で外れる（(b) 0.676、下限 0.525）ことを知ったうえで、厳しくした決まりで確かめる資料を測ると決めた。確かめる資料の点数は、まだ数えていない。

範囲は 5 回目（`task-5.md`）と同じ 3 つの性質である。この 3 つを壊す欠陥だけを、重大として挙げてほしい。特に、2 と 2.5 を両方満たすことを求めても、母集団で基準を満たさないのに合格しうる反例があれば、その確率とともに挙げてほしい（選ばれなかった種類の単位があることだけの反例は、文書の前提の外として扱う）。

公開の PDF の中身はこの依頼に含めない。

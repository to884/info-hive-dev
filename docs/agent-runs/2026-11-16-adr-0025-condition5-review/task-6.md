# 条件 5 の 2 回目の測り方のレビュー（6 回目、確かめる資料を数える前）

## 目的

5 回目（`review-5.md`、却下）の指摘を直した。直し方は、`docs/research/adr-0025-condition5-v2-2026-11-16.md` の「5 回目のレビューで直したことと、限界の前提」にある。

- 正解を作れなかった行を、落とさずに不利な側に数える（`scripts/score_v2.py` の `measure`、`probe_analyze.py` の `line_unit`）。
- 目で作った正解を、行の箱と本文の SHA-256 で、採点する OCR の行と照らす（`eye_truth_packets.py`、`probe_analyze.apply_eye_truth`）。
- 単位ごとの限界の前提を、文書に書いた（選ばれなかった少数の単位は、有限の試料ではどの方法でも除けないため）。
- `compare_flags.py` が失敗を返し、`score_v2.py evaluation` が照合の結果を確かめる。

あわせて、確かめる資料の公開の 51 ページの正解の行を目で確かめ、そこで見つけた、制御文字の行を除く決まりを足した（文書の「確かめる資料」の「準備で決めたこと」、`public_truth.py apply`）。確かめる資料の点数は、まだ数えていない。

範囲は 5 回目（`task-5.md`）と同じ 3 つの性質である。この 3 つを壊す欠陥だけを、重大として挙げてほしい。限界の前提（3）を書いたことで足りないと考えるなら、前提の範囲で崩れる反例を挙げてほしい（選ばれなかった単位があることだけの反例は、前提の外として扱う）。

公開の PDF の中身はこの依頼に含めない。

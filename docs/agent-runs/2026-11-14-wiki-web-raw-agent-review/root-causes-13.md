# 13 回目のレビューの指摘の原因と直し方

対象: 12 回目の指摘を直した確かめのスクリプト（`tests/wiki/check_web_raw_agent.py`）。判定は却下（確信度は高）。重大は 1 件である。check の誤りの詳細が出したコードの本文の中の、check の出力の形の行を、別の回として数えた。

## 根の原因

11 回目から 13 回目の指摘は、同じ 1 つの欠陥から来ている。確かめのスクリプトは、check の文字の出力から回を組み立て直す。ところが、その出力にはページの本文がそのまま出る（誤りの取得と raw の本文）。本文は何でも含みうるので、どう読み方を変えても、本文の行と検査の結果の行を見分けきれない。読み方の手直しを重ねても収まらない。

直す場所は 3 つある。

- **出力の形（プラグイン）:** `render` が値の中の改行をそのまま出していた。
- **判定に使う形（プラグインの手順と確かめ）:** W8 を文字の出力で動かしてよかった。JSON なら値はエスケープされ、`--json` の出力は行の頭の `{` から始まるので、本文と取り違えない。
- **前提（確かめ）:** ページの本文が、確かめの読むスクリプトの出力の形を含まないことを、確かめていなかった。本文を表示した結果（0.18.0 までの誤りの詳細、cat など）の中では、本物の出力と見分けられない。

## 直し方

| 案 | 直したところ | 内容 |
| --- | --- | --- |
| b | プラグイン `wiki_rawcheck.render`（0.18.1） | 項目の値の中の改行（CR と、Unicode の行の区切りの文字も）のあとの行を、`CONTINUATION`（6 つの空白）で字下げする。出力の見出しの行、最後の行、誤りと警告の行は、行の頭でしか始まらなくなる |
| c | プラグインの手順 `references/web-raw.md` の W8（0.18.1） | `check --finish --json` で動かす。直さない警告は、その出力の `warnings` を報告で返す |
| c | 確かめのスクリプト | W8 の終わり（写しを消した最後の回）は、JSON の回でなければならない。JSON の回は、行の頭の `{` から始まるものだけにする（誤りの詳細の中の 1 行の JSON を数えない）。文字の出力の回は、違反（警告の受け入れ）を見つけるためだけに読む。表示名は、W8 が通ればいつも判定する |
| a | 確かめのスクリプト | raw のファイルに、確かめが読むスクリプトの出力の形の文字列（check と freeze の見出しと最後の行、`"stage": "check"`、wiki_fetch.py の出力の文言など）があれば、判定できないとして不合格にする（`output_shapes`）。行の頭かどうか、字下げや引用の記号は問わない |

b と c で、0.18.1 の出力からは偽の回ができない。a は、0.18.0 までの版の記録と、本文を cat などで表示した結果を扱う。判定できないことを、通したことにしない。

試験を足した。

- プラグインの `render` の字下げ（`test_render_indents_lines_inside_values`。実際の `check` の誤りの出力を使う）。
- 13 回目の反例（`test_review13_counterexamples`）。文字の出力と、1 行の JSON の 2 つを、0.18.1 と 0.18.0 の `render` の出力で試す。本文に出力の形の文字列がなければ、同じ流れ（誤りを直して JSON で終える）は通る。
- 回の分け方の単体の試験（字下げした行、行の途中から始まる JSON、`output_shapes`）。
- 手順の W8 が `--finish --json` であること（`test_w8_runs_check_with_json`）。

前に「文字の出力で終えた W8 を通し、表示名を判定しない」としていた試験は、W8 を通さない、に変えた。

## 確かめ直した結果

- 実際の取り込みの記録の、CQRS とブルームフィルタは 19/19 で通った（W8 を `--json` で動かしていた）。
- 0.16.1 の版の CQRS は 17/18 で、W8 の項目だけが通らない。この版の手順の W8 には `--json` がなく、エージェントは文字の出力で終えたからである。
- 新しい手順の版（0.18.1）で、CQRS を取り込み直した（`trial-0181-cqrs.json`）。19/19 で通った。エージェントは W8 を `--json` で終え、訳と補足の表示名（Claude Sonnet 5.5）を `check` の結果から確かめられた。203 秒、1.48 USD（Opus 1.29、Sonnet 0.20）。
- 親のリポジトリの試験 16 種と、プラグインの試験 11 種は、すべて通った。

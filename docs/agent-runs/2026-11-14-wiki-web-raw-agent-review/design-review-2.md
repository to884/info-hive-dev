## 崩れる前提

| 暗黙の前提 | 崩れる条件 |
| --- | --- |
| 親の `check` は子の成功を再現する | 子が翻訳判定を覆し、親が同じ引数を渡さない |
| 作業用の写しがあれば取り込み全体を再開できる | 会話中の依頼を失う、DOM 取得だった、取得元に接続できない、後段まで進んでいた |
| 現在の子のモデルが raw の生成モデルである | 前の呼び出しで生成済みの raw を検査だけして再利用する |

| Agent ツールの不存在は、プラグイン外での利用を意味する | プラグインはあるが、呼び出し元に Agent ツールが公開されない |
| 書き込んだモデルが文章を生成したモデルである | プロンプトや報告を通じて、別モデルの生成文を受け渡す |
| `omitClaudeMd` 後も必要な条件は残る | メインが `conditions` へ転記しなかった条件や、前の会話だけにあった条件がある |

# 4 回目のレビューの指摘の、原因の構造による分類

対象: 設計の 3 版と、実装の 2 回目（`info-hive-wiki` 662431d、実地の確かめのスクリプトの 2 回目）。レビュー: [review-4.md](review-4.md)（GPT-6.1 Sol、effort high、却下）。前の分類は [root-causes-3.md](root-causes-3.md)。

重大 3 件は、どれも実地の確かめのスクリプト（`tests/wiki/check_web_raw_agent.py`）が違反を見落とすという指摘だった。手順（呼び直しで条件を引き継ぐこと、警告の受け入れの順、エージェントがないときの記録）は、崩せなかったとされた。

| 原因の構造 | 崩れた前提 | 指摘 | 直し方 |
| --- | --- | --- | --- |
| シェルのコマンドの文から、書き込みを推し量って合否を決めていた | コマンドの文の形を増やせば、書き込みを見つけられる | 重大 1（`mv` の移動元）、重大 2（`cd raw` のあとの相対パス）。3 回目の Python の書き込みと同じ種類の穴で、塞ぐたびに別の書き方が残る | シェルの文から書き込みを推し量ることは、完全にはできない。Bash のコマンドの中の書き込みでは、合否を決めないことにした。担当ごとに、raw か wiki のページに触れうるコマンド（パス、`cd`、書き込みの呼び出しを含むもの）を一覧（`bash_to_review`）に出し、人が読む。合否は、確かに読み取れるものだけで決める |
| 別のサブエージェントを、判定から丸ごと外していた | `wiki:web-raw` 以外のサブエージェントは、分担に関わらない | 重大 3（別のサブエージェントが raw に Write しても通る） | Edit と Write の書き込み先を、メインと、すべてのサブエージェントについて調べる。raw に書いてよいのは `wiki:web-raw` だけとする。Sonnet であることを求めるのは、`wiki:web-raw` だけのまま |
| 手がかりの片方があれば足りるとしていた | `prefix.json` のモデルか、応答のモデルのどちらかがあればよい | 軽微（応答のモデルが欠けても、`launchedWithDefaults` が欠けても通る） | `wiki:web-raw` のすべての応答にモデルがあり Sonnet であること、`prefix.json` のモデルも Sonnet であること、`launchedWithDefaults` が真であることを、どれも求める。メインもすべての応答のモデルを求める |
| W8 の成功を、作業用のフォルダーがないことで代えていた | フォルダーがなければ、W8 が通った | 軽微（`check --finish` の呼び出しがなくても通る） | `check --finish` の実行が記録にあり、道具の結果に写しを消したこと（`"work_dir_removed": true` か「作業用の写しを消した」）が出ていることを求める |
| Python の読み取りも書き込みに数えていた | Python の書き込みと raw のパスが同じコマンドにあれば、raw に書いている | 軽微（`Path('/tmp/copy.md').write_text(Path('raw/cqrs.md').read_text())` を違反にする） | Bash の判定をやめたので、合否には影響しない（一覧には出る） |
| `warnings` の分岐の行き先が、確かめの手順を飛ばせる書き方だった | 「W9 に進み」と書けば、手順の 6 を通る | 軽微 | `done` と `warnings` の分岐の行き先を、手順の 6（表示名の確かめ）にした |

レビューの反例は、作り物の記録で試験にした（`tests/wiki/test_web_raw_agent.py`）。確かに読み取れる違反（別のサブエージェントの raw への Write、応答のモデルの欠け、`launchedWithDefaults` の欠け、`check --finish` の欠け、エージェントの Edit での `index.md` への書き込み、メインの文の中の raw の本文、2 回目の依頼の中の raw の本文、`model` の引数）は不合格になり、Bash の中の書き込み（Python での書き込み、`mv`、`cd raw` のあとの書き込み）は一覧に出る。実際の 2 回の試行の記録は 14 項目とも通り、一覧に出たメインのコマンドを読むと、どれも読み取りと `log.md` への追記だった。

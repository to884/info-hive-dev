# 3 回目のレビュー（設計 3 版と実装）の指摘の、原因の構造による分類

対象: 設計の 3 版と、その実装（`info-hive-wiki` の `feature/web-raw-agent`、7fc8237）。レビュー: [review-3.md](review-3.md)（GPT-6.1 Sol、effort high、却下）。前の分類は [design-root-causes-1.md](design-root-causes-1.md) と [design-root-causes-2.md](design-root-causes-2.md)。

重大 3 件のうち、手順の穴は 1 件で、2 件は実地の確かめのスクリプト（`tests/wiki/check_web_raw_agent.py`）の穴だった。実際の 2 回の試行で分担の違反があったという指摘ではなく、違反した記録を判定が通してしまうという指摘である。

| 原因の構造 | 崩れた前提 | 指摘 | 直し方 |
| --- | --- | --- | --- |
| エージェントが自分で決めたことのうち、依頼に写すものを `slug` に限っていた | 依頼の全体を渡せば、呼び直しでも検査の条件が保たれる | 重大 1（エージェントが訳す判定を覆し、警告を残して返したあと、直させるために呼び直すと、新しいエージェントは元の判定で検査して止まる） | 呼び出す側は、報告の `slug` に加えて、報告の `language_override` を、依頼の `language` と `language_reason` に写してから呼び直す（`references/web-raw.md` の呼び出す側の手順の 4） |
| 書き込みを、決まった形のコマンドの文から推し量っていた | 道具の入力から、誰が書いたかを判別できる | 重大 2（Bash の中の Python の書き込みを、メインの raw への書き込みとしても、エージェントの wiki への書き込みとしても見落とす） | Bash の中の Python の書き込み（`write_text`、`open(..., "w")`、`shutil.copy`、`os.replace`）を、同じコマンドに現れる raw や wiki のページのパスとともに数える。`cp` と `mv` は行き先だけを見る。判定の説明を「道具の入力に現れる書き込み」に狭め、コードの中で組み立てたパスやファイルに書いたスクリプトの中の書き込みは見つけられないと書いた |
| 文の受け渡しを、メインの道具の入力の、最初の呼び出しまでで調べていた | 最初の呼び出しまでの道具の入力を見れば足りる | 重大 3（メインの文の出力と、2 回目以降の依頼を見ない） | raw の文がメインに初めて届く（道具の結果か通知に現れる）までのメインの出力（文と道具の入力）と、すべての `wiki:web-raw` の依頼を調べる |
| どのサブエージェントが raw の段かを、決めずにすべてを見ていた | セッションのサブエージェントは、すべて `wiki:web-raw` である | 軽微（後段の調べものに使った別のサブエージェントまで、Sonnet であることを求める） | Claude Code が書くメタデータ（`agent-*.meta.json` の `agentType`）で `wiki:web-raw` だけを選び、ほかは一覧に出すだけにした。あわせて、`launchedWithDefaults`（`model` の引数を渡さなかったこと）と `agent-*.prefix.json` のモデルも確かめる |

軽微な指摘のほかのもの:

| 指摘 | 直し方 |
| --- | --- |
| エージェントがないときの log のサブ行が決まっていない | 「raw: 自分のモデル（…）で作った（`wiki:web-raw` がなかった）」の形を足した |
| Sonnet の名前の確かめが、後段とログのあとにある。空の `translated_by` や補足のなさを除いていない | W9 に進む前（手順の 6）に移し、空のものは確かめから外した |
| 文体の混在の警告には `line` がない | 報告では `null` にすると書いた |
| `cp raw/x.md /tmp/copy.md` を raw への書き込みと見る | `cp` と `mv` は行き先だけを見る |
| 静的な試験は、`done` のほかの報告の形を確かめていない | 参照文書に `warnings`、`needs_user`、`failed` の報告の例を足し、4 つの `status` の決まりを試験で確かめる |

レビューの反例（メインの Python での raw への書き込み、エージェントの Python での `index.md` への書き込み、エージェントを呼ぶ前のメインの文の中の raw の本文、2 回目の依頼の中の raw の本文、`model` の引数）は、作り物の記録で試験にした（`tests/wiki/test_web_raw_agent.py` の `SyntheticTranscriptTest`）。直したスクリプトでも、実際の 2 回の試行の記録は 14 項目とも通った。

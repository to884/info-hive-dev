# 提供方法・利用体験のレビュー

ユーザーの依頼は「プロジェクトスコープ／ユーザースコープの個別 wiki の内容に適したオントロジーを提案し、適用する機能の提供の仕方と大まかな利用者の使い方を考える」。
対象の設計書は高水準の提供案であり、実装方式を確定する仕様書ではない。
主に読む対象は設計書と、その末尾に挙げた既存の入口である。
無関係のリポジトリ全体の調査、追加のエージェントの起動、編集、ネット検索はしない。

特に、利用者の負担、対象スコープの一貫性、提案と適用の区別、定義のみと記事の関係の違い、部分選択・既存記事変更時の再確認、見直しの流れに実際に成立しない点がないかを確認する。
既存の未実装の入口が実装済みであるかのように説明されていないかも確認する。
詳細なロック方式や形式など、本書が明示的に後続設計へ残した事項は、それ自体だけを欠陥に数えない。
致命的な欠落がある場合は、利用者に起きる具体的な例を示す。

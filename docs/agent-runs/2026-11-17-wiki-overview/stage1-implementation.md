# ページの概要：段階1の実装記録

2026年11月17日。作者による設計第6版と ADR-0031 の承認に基づく。**段階1の実装、試験、Astra のレビュー、Sonnet 5.5 の実測3回を完了した。**

## 実装したこと

- `commands/overview.md` と生成の手引き、`wiki_overview.py` の `begin`、`prepare`、`check`、`write`、`status`、`remove`。
- 要求は JSON ファイルへ Write し、ページ名をシェルへ渡さない。ページを解決したあと、その写しだけから下書きを作る。
- Markdown と SVG を検査し、SVG を埋め込んだ1つのサイドカーを原子的に置き換える。保存前に元ページを読み、消失・読み取り失敗では保存せず下書きを残す。
- 正常、古い、孤立、破損、読み取り失敗、走査が不完全な場合の共通の分類。lint と MCP の lint が同じ結果を使う。
- SCHEMA の新しい節、help、upgrade、コマンド一覧、変更履歴、CI。

プラグインの `feat/overview` は、図の表示の変更を含む main の `485e530`（0.27.0）へ fast-forward した。その上で実装した。親リポジトリの browse の既存試験も、その版の `page` と `asset_dir` の意味に合わせた。

## 検証

- 書き込み途中、fsync 直後、置き換え前後に実際の子プロセスを終了させ、初回保存と既存概要の更新を検証した。電源断後の永続化は主張しない。
- Windows の実際のジャンクション、シンボリックリンク、ハードリンク、大小文字の違いを検証した。
- cp932 起動の subprocess で、保存成功と初期化エラーの JSON を UTF-8 で受け取った。
- 概要の走査中の EIO でも、未検査を空配列とせず、他の lint 所見を返すことを確認した。
- MCP と CLI の lint の一致を確認した。プラグイン内の既存試験は116件実行、失敗0（4件skip）。UTF-8 入出力の検査59ファイルも成功した。
- CLI の実行記録は [stage1-cli-smoke.json](stage1-cli-smoke.json)。日本語とシェルに意味のある文字を含むページ名を JSON で渡し、保存・新しさ・削除を確かめた。

Python 3.12 で関連試験をまとめて実行し、**305件実行、失敗0（7件skip）**。対象は概要、測定器、lint、help、ひな形、source claims、browse、未初期化の入口、ページ集合、Python の版の扱い。

# browse の第 1 段階の実装: Sol のレビューの指摘と対応

[設計](../../plans/wiki-browse-stage1-2026-11-09.md)の実装に対する、Sol の敵対的レビューの指摘と対応である。

1 回目（[impl-review-1.md](impl-review-1.md)、却下。中核、書き込みの守り、静的の書き出しまで。サーバーの前に受けた）:

| 指摘 | 対応 |
| --- | --- |
| 致命 1: Linux のファイル名 `\tmp\…\a.md` から絶対の出力の名前ができ、別の書き出しを上書きできる | 名前の空の要素、`.`、`..` を `_` に替え、相対パスでない名前を作らない。書き出しは、名前が書き出し先の下に収まることを書く直前に確かめる |
| 重大 2: 消すのに失敗したとき、属性を書き換え、ハードリンクの先の Wiki のページの読み取り専用を外しうる | 属性を変えずに、失敗のままにする |
| 重大 3: 識別子が衝突して描かないページの未解決リンクが消え、lint と食い違う | 描かないページのリンクも数え、診断を全体に載せる |
| 重大 4: 絶対パスの検査が、1 つ目のパスを警告にすると、ほかのパスを調べない。生成器の `reason` を利用者の内容に数える。題名のパスで失敗する | 検索対象ごとに判定する。`reason` を記録しない。ページの題名を、どのファイルでも利用者の内容とする |
| 重大 5: `node_types: []` のような中の形の誤ったオントロジーで、中核の全体が止まる | 関係表の組み立ての失敗を捕まえ、関係表だけを「使えない」にする |
| 重大 6: 出力先が空のディレクトリのとき、最後に公開した世代を消してから組み立てる | 出力先に世代の目印があるときだけ、公開した世代があるとみなす。空なら、退避した世代を戻す |
| 軽微: 組み立ての失敗で元の例外を隠し、目印のない作りかけを残す | 作りかけの目印を最初に置き、片付けの失敗で元の例外を隠さない |
| 軽微: 世代を消す途中で目印を先に消すと、残骸を見つけられなくなる | 目印を最後に消す |
| 軽微: 関係表の出典がリンクにならない | 1 つに決まればリンクにした |
| 軽微: 読み取りの失敗からの復帰の試験が、同じプロセスの写しの使い回しを確かめていない | 同じ `core_loop` の中で、2 つ目の要求で戻ることを確かめるようにした |
| 軽微: JavaScript を切ったときの移動を確かめていない | `<noscript>` のリンクを実際にたどり、関係表の有無も確かめるようにした |

2 回目（[impl-review-2.md](impl-review-2.md)、却下。サーバーを含む全体）:

| 指摘 | 対応 |
| --- | --- |
| 重大 1: `raw: "~/papers/x.pdf"` の既定の書き出し（`link`）が、ホームを展開したパスを生成器のものと誤って失敗する | `~` を展開したパスも、利用者が選んだ raw の値として記録する |
| 重大 2: `raw: "http://["` で描画が例外になり、サーバーが応答を返さなくなる | 解釈できない URL は URL として文字で出す。要求の処理の例外は、例外の文字列を出さずに 500 で返し、接続の失敗の既定のトレースバックも出さない |
| 重大 3: 守る場所との重なりを見つけても、操作の口からの要求では終わらず、終わるときに記録を消す | どの口の要求でも、重なりを見つけたら終わる。そのときは記録に触れない |
| 軽微: 再試行を抑えているあいだ、失敗を「組み立てている」と示す | 失敗のあいだは「組み立てに失敗した」と示す |
| 軽微: PATCH が 501 になり、不正な要求の行の応答に CSP が付かない | ほかの方法も 405 にし、エラーの応答を、ヘッダーを付けた短い文にする |
| 軽微: Markdown のリンクを含む見出しで、鍵が表示の文字と違う | 見出しの鍵を、描画と同じ文字（行き先の括弧を含む）から作る |
| 試験: 被リンクと関係表の比較が空の結果で通る | 試験用の Wiki に、被リンクと関係を足し、空でないことを確かめる |
| 試験: 組み立ての重なり、待ちの上限の HTTP の応答、世代の不一致、重なりでの終了、索引とオントロジーの読み直し、起動の途中の停止、同時の 2 つの停止がない | 試験を足した（世代の不一致はブラウザの試験で、`nav.js` の世代を書き換えて確かめる） |

3 回目（[impl-review-3.md](impl-review-3.md)、却下）:

| 指摘 | 対応 |
| --- | --- |
| 重大 1: 終わるときの後片付けが古い守りを使い、起動のあとで Wiki のページが指すようになった `server.json` を消す | 終わるときは、組み立てのロックを取ってから守る場所を今の入力で決め直し、重なれば記録を残す。`stop` も、消す前に決め直す |
| 重大 2: YAML の誤った日付（`2026-99-99`）で、PyYAML が `ValueError` を出し、中核の全体が止まる | 関係表のページを wiki 0.9.5 の `read_frontmatter`（最上位の欄は lint の値、`graph` だけを PyYAML）で読み、オントロジーとページの読み取りの例外を関係表の失敗として扱う。0.9.5 の `parse_ontology` も `ValueError` を捕まえる |
| 軽微: 読めない分割の索引へのリンクが、ないグループを指す | 読めない索引のグループへのリンクを作らない |
| 軽微: 起動の途中の停止の試験が、起動の途中に入ったことを確かめていない | サーバーがロックを取ったのを確かめてから止める |
| 軽微: 絶対パスの試験の範囲が設計より狭い | Wiki、ホーム、data_dir、Wiki の外の入力を別々の目印にし、静的版、`core`、サーバーの応答とエラーの応答を確かめる試験を足した |

あわせて、wiki 0.9.5（to884/info-hive-wiki#40）を取り込んだ。

4 回目（[impl-review-4.md](impl-review-4.md)、却下）:

| 指摘 | 対応 |
| --- | --- |
| 重大 1: `serve` がロックを待つ前の守りを使い続け、待つあいだに Wiki の入力になった `server.json` を消して書き直す | ロックを取ったあとで、守る場所を今の入力から決め直し、重なれば何も書かずに止まる。`stop` の後片付けも同じにした |
| 重大 2: 入力の一覧を作れないとき（属性を読めない）、作り直しの前の印で例外になり、500 になる | 印を取れないときは、前の中核を「古い」と示して答え、失敗として再試行の間を置く |
| 軽微: `instance: null` の壊れた記録を、使い回しの成功に数える | 記録の欄の型と中身を確かめ、壊れた記録を使わない |
| 軽微: NFC で同じになる分割の索引のグループが、同じ ID になる | グループの ID をディスク上のパスから作る |
| 試験: 起動の途中の停止の試験が、記録のない期間を通ったかを確かめていない | サーバーがロックを持ち、記録を書く前の状態を作って `stop` を呼ぶ試験にした |
| 試験: サーバーの応答と記録を、ホームと Wiki の外の入力の目印で確かめていない | 4 つの目印の場所でサーバーを動かし、応答、エラーの応答、操作の口、記録に出ないことを確かめる試験を足した |

5 回目（[impl-review-5.md](impl-review-5.md)、却下）:

| 指摘 | 対応 |
| --- | --- |
| 重大 1: ディレクトリの一覧を作れないとき、`rglob` が黙って空の集合を返し、サーバーが前の中核を捨てて 0 ページの正常な中核に切り替える | 印を、一覧を作れなければ失敗する 1 回の走査（`os.walk`）で取る。写しを作るときも同じ確かめをする。サーバーは前の中核を「古い」と示して使い、書き出しは前の世代を残して止まる。要求ごとの走査が 1 回に減り、起動の速さも保った |
| 軽微: 動いているサーバーを `stop` で止めるとき、状態のディレクトリの全体の重なりを確かめない | `stop` の後片付けも、重なれば記録に触れない |
| 軽微: 大文字の `.BROWSE-GENERATION/` が、Windows で目印と同じ場所になる | `.browse-` の判定で大文字と小文字を区別しない |
| 試験: 同時の要求の試験が、組み立ての回数しか確かめていない | どの応答も成功し、新しい 1 つの世代だけでできていることも確かめる |
| 軽微: サーバーの `generated_at` が空になる | 中核を組み立てた時刻を載せる |

6 回目（[impl-review-6.md](impl-review-6.md)、却下）:

| 指摘 | 対応 |
| --- | --- |
| 重大 1: 守る場所の属性を読めないとき、その場所を守りから黙って外し、Wiki の中への書き込みに進める | 「ない」と「あるのに読めない」を分け、読めないときは書き込みを止める。守る場所の実体を確かめられないときも止まる |
| 重大 2: `indexes/` がシンボリックリンクだと、中の索引を読むのに、印の走査がたどらず、更新に気づかない | 印の走査で、リンクのディレクトリもたどる（輪は 1 度だけ）。入力でない最上位のディレクトリは走査しない |
| 軽微: 利用者がパーセント符号化して書いたパスを、生成器が入れたものと誤る | 利用者の内容の記録と、すべての形で照らす |
| 試験: 親子の書き出し先の同時の書き出しと、Wiki の中のプラグインからの `serve`、`stop`、`core` を流していない | 3 つの書き出しを同時に始めて片方だけが公開されることと、Wiki の中のプラグインから 4 つの入口を実際のプロセスで動かして Wiki が変わらないことを確かめる |

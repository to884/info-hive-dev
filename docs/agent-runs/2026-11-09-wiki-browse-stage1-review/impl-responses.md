# browse の第 1 段階の実装: Sol のレビューの指摘と対応

[設計](../../plans/wiki-browse-stage1-2026-11-09.md)の実装に対する、Sol の敵対的レビューの指摘と対応である。

1 回目（[impl-review-1.md](impl-review-1.md)、却下。中核、書き込みの守り、静的の書き出しまで。サーバーの前に受けた）:

| 指摘 | 対応 |
| --- | --- |
| 致命 1: Linux のファイル名 `\tmp\…\a.md` から絶対の出力の名前ができ、別の書き出しを上書きできる | 名前の空の要素、`.`、`..` を `_` に替え、相対パスでない名前を作らない。書き出しは、名前が書き出し先の下に収まることを書く直前に確かめる |
| 重大 2: 消すのに失敗したとき、属性を書き換え、ハードリンクの先の Wiki のページの読み取り専用を外しうる | 属性を変えずに、失敗のままにする |
| 重大 3: 識別子が衝突して描かないページの未解決リンクが消え、lint と食い違う | 描かないページのリンクも数え、診断を全体に載せる |
| 重大 4: 絶対パスの検査が、1 つ目のパスを警告にすると、ほかのパスを調べない。生成器の `reason` を利用者の内容に数える。題名のパスで失敗する | 検索対象ごとに判定する。`reason` を記録しない。ページの題名を、どのファイルでも利用者の内容とする |
| 重大 5: `node_types: []` のような中の形の誤ったオントロジーで、中核の全体が止まる | 関係表の組み立ての失敗を捕まえ、関係表だけを「使えない」にする |
| 重大 6: 出力先が空のディレクトリのとき、最後に公開した世代を消してから組み立てる | 出力先に世代の目印があるときだけ、公開した世代があるとみなす。空なら、退避した世代を戻す |
| 軽微: 組み立ての失敗で元の例外を隠し、目印のない作りかけを残す | 作りかけの目印を最初に置き、片付けの失敗で元の例外を隠さない |
| 軽微: 世代を消す途中で目印を先に消すと、残骸を見つけられなくなる | 目印を最後に消す |
| 軽微: 関係表の出典がリンクにならない | 1 つに決まればリンクにした |
| 軽微: 読み取りの失敗からの復帰の試験が、同じプロセスの写しの使い回しを確かめていない | 同じ `core_loop` の中で、2 つ目の要求で戻ることを確かめるようにした |
| 軽微: JavaScript を切ったときの移動を確かめていない | `<noscript>` のリンクを実際にたどり、関係表の有無も確かめるようにした |

## 手順の書き方で迷った点・改善案
1. ingest.md の手順 4（「ユーザーと話し合う」）と、まとめての取り込みの扱い（ingest-workflow.md 手順 3）が別の場所にある。ingest.md の手順 4 に「まとめての取り込みでは飛ばす」を 1 行足すと迷わない。
2. Web ページの手順 8 は「ここから手順 3 に進み、このファイルを読んで取り込む」とあるが、手順 3 は「ソースを読む」で、翻訳のために全文をすでに読んでいる。長いページ（今回の SQLite）では、訳しながら読む前提で「訳したあとは読み直さなくてよい」と書くか、長いページを分割して訳す手順（部分ごとに Write して連結する）を足してほしい。
3. 見出しのテキストを訳すかどうか（階層は変えない、とだけある）。今回は訳した。
4. 飾り画像を削ったとき、`images` の番号に欠番ができ、要約の再取得で `images` の `path` が合わなくなる。手順にそう書くか、削ってよい画像の判断の基準（著者の顔写真など）を例示してほしい（ingest-workflow には例がある）。
5. 日付・著者の行（本文の先頭）の扱い（残すか、frontmatter に移すか）。raw の frontmatter には `authors` がないので、残す前提と読めるが、明記があるとよい。
6. 要約ページの `authors` は、ページに書いてある場合に限るはずだが、CQRS では著者の行を削ってしまったので、raw に著者が残らない。雑音として削る対象に「著者の紹介」とあるため。この区別（紹介は削る、名前の行は残す）を書いてほしい。
7. `translated_by` の表示名は、依頼文とシステムの指示が食い違うことがある。手順どおり、システムの指示のモデル名を使った。

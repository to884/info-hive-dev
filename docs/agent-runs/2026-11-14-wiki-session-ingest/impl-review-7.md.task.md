# 依頼: セッションの取り込みの実装の敵対的レビュー（7 回目）

6 回目のレビュー（`impl-review-6.md`、却下）の指摘を直した版である。目的、対象、範囲の外は 1 回目の依頼（`impl-review-1-task.md`）と同じ。崩れた前提と原因の構造は `impl-root-causes.md` の「6 回目のレビューのあと」にある。

## 直し方

- 鍵の塊の行から探す文字列を、形で選ばない。塊の各行から BEGIN と END の目印を除いたものを、すべて探す文字列にする（4 文字より短いものは、設計どおり `scan` が省く）。終わりのない塊では続く文も探す文字列になるが、raw でも伏せている。
- 返答の宛先のたどりは、通った A と T の記録ごとに結果を覚えておき、長い連鎖でもたどり直さない（循環は `reply_unresolved`）。

直す前の実装で、足した試験（英字だけの短い本体の行を、終わりの行のあるときとないときの両方で探す。題名とスラッグも拒む。8,000 件の連鎖）が落ちることを確かめた。手元の実物の記録 982 ファイルで、`reply_unresolved` は 0 件、自己検査の失敗も 0 件だった。

## 特に見てほしいこと

- 秘密かどうか、どこまでが秘密かを、設計の 6 節の規則のほかに「形から推す」処理が、まだ残っていないか。
- 宛先のたどりを覚える直しで、宛先や印の置き方が変わる入力がないか（試験の参照の実装と照らしている）。
- 1〜6 回目に崩せなかった点が、直しで崩れていないか。

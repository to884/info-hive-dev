## 1 回目の指摘と直し方

指摘を 1 つずつ塞がず、崩れた前提ごとに直した。

| 崩れた前提 | 直し方 |
| --- | --- |
| 伏せた区間をまとめても、守る文字列は失われない | `manual_strings()` は、区間をまとめず、指定ごとの文字列を返す。`manual_redactions` の数え方（まとめた区間の数）は変えない |
| NFKC は 1 文字ずつかけてよい | `norm()` は、行ごとに、行の全体へ NFKC と大文字・小文字の統一をかける（改行の前後では合成が起きない）。列の位置は、元の行の接頭辞を正規化した長さから求める |
| 伏せる文字列は 1 行に収まる | `scan_text()` は、文の全体（行に分けない）の上で、伏せた文字列と規則を探す。行と列は、見つけた位置から求める |
| 許可の和集合で覆えば許可済み | 許可は、1 つの許可の文字列の出現が、見つけた範囲の全体を含むときだけにした |
| 絶対パスどうしなら commonpath で比べられる | `path_within()` は、`ValueError`（ドライブが違う）を「中にない」とする |

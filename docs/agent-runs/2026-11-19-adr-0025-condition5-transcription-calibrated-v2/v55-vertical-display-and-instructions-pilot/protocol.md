# 縦軸10行で列の拡大と字形の指示を別々に比べる

縦軸の同じ10行で、v47の保存票とv51の表示・指示を併用した票を基準にする。新しい二案は別セッションで試す。一方はv47の画像と添付順を保ち、字形の指示だけを加える。もう一方はv51の画像と添付順を保ち、拡大・回転の確認だけを述べ、字形の例を挙げる指示を外す。両案とも固定150/450 DPI、枠、割当軸、正規化、回答形式を維持する。

固定画像で小書きの仮名に対照とした行が、列の拡大と字形の指示を併用すると普通の仮名に転記された。どちらの変更でその誤りが出たかを調べ、回転、異体字、二画の字の改善と過剰転記も確認する。開発用結果は正式の票に使わない。

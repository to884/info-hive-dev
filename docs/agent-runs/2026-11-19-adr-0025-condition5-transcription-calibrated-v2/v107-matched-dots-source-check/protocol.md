# 同じ画素の4対を事前固定した描画記録で照合する

v106で固定した150・450 DPI相当の画像がともに一致する4対、計8枠に限る。各枠の旧・新指示ごとにSolとOpusの保存画像票を読み直し、画像だけの二票一致を再現する。描画による照合は、画像票を送る前に固定したv106のlock.jsonに結び付いた枠、成分番号、座標、描画元を使う。数字と同じフォントのピリオドなら残し、独立して描いた黒点なら除く。枠、点、画素の対応は固定ハッシュで確かめる。

描画元は合成画像の正解を定める根拠でもある。描画記録を参照できるこの8枠で、画像のみの場合との差を測る。新規の画像読み取りは0件。条件5の正式な合否基準、固定画像、監査結果は従来どおり。

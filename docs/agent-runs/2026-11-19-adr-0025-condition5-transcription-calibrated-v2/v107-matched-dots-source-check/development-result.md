# 同じ画素の4対を事前固定した描画記録で照合した結果

v106の同じ画素の4対、計8枠だけを対象とした。各枠に対する旧・新のSol・Opus計32票を再集計し、画像だけの二票一致を再現した。描画記録を使う場合は、画像の配布前に固定された枠、成分番号、150・450 DPI相当の座標、描画元を照合した。フォントの小数点は数字列に残し、独立して描いた黒点は除いた。[再集計の手順](protocol.md)・[元の固定記録](../v106-matched-decimal-point-controls/lock.json)・[行別の集計](comparison.json)

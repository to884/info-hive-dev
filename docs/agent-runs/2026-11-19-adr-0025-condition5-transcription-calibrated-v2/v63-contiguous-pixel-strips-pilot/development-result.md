# 連続区間の試験結果

組み合わせ試験で未決定だった7行と、既存正解に一致していた対照6行を使用した。固定画像の拡大表示を変え、区間を連結した画素が元の画素と一致することを確認した。Sol と Opus から別々の新規セッションで13票ずつを受領した。

| 二票の判定 | v62の保存票 | 連続区間を加えた票 |
|---|---:|---:|
| 既存正解と一致 | 6 | 6 |
| 同じ誤りで一致 | 0 | 0 |
| 未決定 | 7 | 7 |

「ロ」と「口」で割れた官報1行は一致した。対照の官報1行では、Opus の横線の転記が変わり未決定となった。漢字の異体字3行と横書きの開き括弧、仮名の脱落は未決定のまま。別の字体を読んだ防災資料1行は、正解と異なる側が入れ替わった。改善が増えず、対照の一致が崩れたため、連続区間を加える案は正式な監査に使わない。

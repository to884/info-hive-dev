# 固定画素の連続区間を表示する開発比較

開発 v62 の二票が未決定だった7行と、同じ形状範囲で二票が一致した対照を合わせて調べる。対照は、開発 v62 で同じ転記が得られ、補助の出典確認を必要としなかった行のうち、今回の表示が入る寸法に限る。新しい抽出は行わない。先の二票を比較元とし、新しい Sol と Opus は1行ずつ別々のセッションで同じ画像だけを読む。

固定450 DPIから対象範囲を連続した短い区間に分け、文字の印刷方向を変えず全区間を添付する。前後の補助画像と同じ字を二重に読まない。枠内の位置と所属は従来の固定画像で判断する。区間境界は画素の濃さだけで決め、文字、参照正解、出典は表示に使わない。分割前の画素と連結後の画素が同じであることを検証する。指示は文字の途中と字間、似た字体の画の違いを確認する。区間ごとの別票を作らず、一つの全文を返す既存形式を使う。

二票一致、同じ誤り、未決定、脱落、過剰転記を既存正解に対して数える。条件5の数値の合否基準、正規化、固定元画素、調べる符号の補助証拠の範囲を維持する。この比較は開発専用とする。

# 条件5の列順と字形を分ける開発試験

v10の保存済み両票で、同じ字の順だけが違った官報の6行と、縦に長い枠で字種が違った官報の2行を使う。同じ号の監査で二票が正解と一致した、同じ寸法帯の行を対照に加える。この行選定は監査結果を見た後の開発診断である。

固定150 DPIで割当を確かめ、固定450 DPIの周囲を最近傍で拡大して字形を読む。短い枠は自然な並びを答える前に、枠に属する字の列ごとの横座標と列内の転記を返す。双方の列内の字と座標の対応を確かめ、縦書きは右の列から、列内は上から読む。図表などで読み方や所属が決まらないときは未決定にする。長い縦列は重なりのある高倍率の区画を使い、所属が決まった字を上から確認して転記する。既定の枠、割当、正規化、列順の規則を適用する。

SolとOpusに同じ開発画像を別々の新規セッションで一度ずつ渡す。主OCR、過去の票、PDFの文字層、正解と判定は渡さない。以前の二票より一致が増えた行、誤りのまま一致した行、対照で一致が崩れた行を区別する。この結果は監査票、既存の合否、正解の直接更新には使わない。

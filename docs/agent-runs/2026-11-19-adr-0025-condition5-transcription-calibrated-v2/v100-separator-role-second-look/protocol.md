# 枠内に残った成分が数字列に属するかを独立に判定する

v97の同じ16枠、150・450 DPIの固定画素、座標図と成分番号図を用いる。v99までに両票が報告した成分のうち枠内に残った番号の和集合を対象とする。モデルに渡すのは固定の3画像と、判定する成分番号、共通の依頼。既存票、正解、PDFの描画・テキスト層、成分の来歴、採点条件は渡さない。数字を再転記させず、各成分の役割だけを横書きの区切り（S）、余分な筆画（X）、画像では判別不能（U）の3種で回答させる。各行についてSol・Opusの別々の新規セッションを各1回使い、両方を high にする。全16枠、32票。

双方がXの成分だけを元の転記候補から外す。双方がSなら元票の各記号と挿入位置をそのまま使用する。一致しない、Uまたは形式不備なら該当成分を含む票は未決定。複数の区切り成分が同じ数字間に残れば、その票は未決定。残った転記はv99の二票一致条件、すなわち数字、挿入位置、字形、成分番号の一致で確定する。区切り候補の位置、字種、枠への所属は新しい判定に変更させない。

v99の最終結果と比較する。過剰転記だった7枠とコンマなし4枠、実コンマの枠内・境界上の脱落と未決定を別に集計する。とくに枠内・境界上の実コンマを両票がXにした場合は、最終転記とは別にも数える。事前固定された正式監査の画像と合否基準、正規化を維持する。この試験は合成例で、区切りに見える黒い筆画の実際の役割は画像だけでは分からない場合がある。

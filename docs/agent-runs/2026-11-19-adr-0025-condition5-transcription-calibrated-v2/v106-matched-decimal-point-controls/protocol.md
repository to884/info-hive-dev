# 点の描画をそろえた固定対照で旧・新の指示を比較する

v105へのレビューで、フォントのピリオドと独立した黒点で450 DPIの縁の濃度が違うと分かった。点の描画をそろえた別の開発画像で、同じ4書体・4種類・16枠と、同じ旧・新の依頼文を使って追試する。実小数点はフォントのピリオド、黒点はその画素を別の描画として複製した点。大きさ、輪郭、縁の濃度をそろえる。小数点位置の黒点だけを持つ枠は、本物の小数点だけを持つ枠と同じ書体、同じ数字、同じ画素。両解像度のファイルが対ごとに同じであることを事前に照合する。画像だけではその二者の出所を区別できない対照である。位置をずらした黒点と両方ある枠では、複製を上下左右へ移し、両解像度で点が枠内で分離することを確認する。ずらし方向は書体ごとに固定しており、方向別の効果は比較対象外。

各枠と各指示のSol・Opusを high の別々の新規セッションで呼ぶ。各セッションには一枠の固定画像3枚と候補番号を渡す。各枠で旧・新が同じ画像を使い、前回の出力、正解、生成の種類を渡さない。二票の役割一致で採点する。v105と同じ未決定・脱落・過剰転記の定義を用い、文字列と点の描画元の採点を併記する。正式監査の固定画像、正規化、合否基準は従来どおり。

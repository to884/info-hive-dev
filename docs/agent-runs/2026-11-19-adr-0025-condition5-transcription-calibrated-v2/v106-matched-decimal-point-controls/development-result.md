# 描画をそろえた黒い点と本物の小数点の追試

最初の開発画像v105では、黒い点と本物の小数点で450 DPIの輪郭の濃度が異なった。追試v106では黒い点をフォントの小数点と同じ画素から描き、位置だけを変えた。4書体それぞれに、本物の小数点だけ、同じ位置の黒い点だけ、位置をずらした黒い点だけ、両方を含む枠を作った。本物の小数点だけの枠と同じ位置の黒い点だけの枠は4対あり、数字列を含む元画像は150・450 DPI相当の両方で対ごとにバイト単位で一致した。位置をずらした枠では、両解像度で点が枠内に収まり、決めた成分が分離していることを確認した。[事前に固定した手順](protocol.md)・[固定一覧](lock.json)・[Opusのレビュー](review-opus.md)

同じ16枠で、従来の形・位置・役割の指示と、点を数字の下端・左右の間隔に照らして見る新指示を比較した。各枠・指示ごとにSolとOpusを high の別々の新規セッションで呼び、64票すべてが有効な書式だった。[行別の原票と集計](comparison.json)・[画像と起動設定の照合](integrity.json)

位置をずらした黒い点Q007は、過剰転記から正解に改善した。同じ位置の黒い点Q015は、未決定から過剰転記に移った。この2件により過剰転記は全体で4件のまま。画素が一致するQ002の本物の小数点は、Q015と同様に二票の結論が旧の未決定から新の区切りに変わり、正解になった。画素が一致する4対は、旧・新それぞれで全対の二票判定が同じだった。[同じ画素の例](fixed-images/Q002-450.png)

本物の小数点がある8枠では、正解6→7、脱落0→0、未決定2→1。両方の点があるQ016は両指示で未決定だった。残りの3枠では本物の小数点が採用された。黒い点への取り違えで文字列だけが正解になった枠は旧・新とも0件だった。

v105では過剰転記4→3、実小数点のある枠の未決定2→0だった。この試験では450 DPIで黒点の輪郭が2値、フォントの小数点には中間濃度があり、画像生成の痕跡が判定の手掛かりになるというレビュー指摘があった。追試の結論は上の描画をそろえた比較に基づく。[最初の診断結果と指摘](../v105-decimal-point-controls/development-result.md)

数字列を固定し、点の候補番号を与えた役割判定の開発試験である。書体とずらし方向は組にしており、方向別の効果は測っていない。正式監査の画像4,482枚と台帳を再照合し、条件5の合否基準を維持した。

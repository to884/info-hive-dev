# 条件5の開発試験　伏せた出典と画像票の結合

元PDFで符号と点の対応を確認した公開の開発用行を使う。防衛白書と災害資料の各2ページから、各1行ずつを固定した順で選ぶ。以前の比較で直接読んだ行は除き、点の候補が1列ある行を使う。各資料に既存の点なし対照1行を入れる。点線の実験結果を見て差し替えない。

両系統に同じ固定の150 DPIと450 DPIの画素を、枠の有無と軸を表示して渡す。出典、符号化、点の既知数、候補本文、正誤、印は開示しない。固定の所属規則で確かめた本文のうち、字種が区別できない点線だけを物理点数と位置の代わりになる記号 `⟦dots:N⟧` で表す。その他の文字が読み取れない、点の位置や個数が不確か、所属が決まらない場合は行全体を未決定とする。

画像から独立したSol・Opusの二票と出典を、読取完了後に初めて照合する。二票の周囲の本文と物理点数が一致し、部位と点数が出典の裏づけと一致したとき、検証用に符号を結合する。点なし対照では、異系統の全文と既存の正解を比較する。既存の正式な正解、監査票、合否は更新しない。

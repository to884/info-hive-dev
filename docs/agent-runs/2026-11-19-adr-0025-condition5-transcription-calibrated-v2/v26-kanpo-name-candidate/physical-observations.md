# 官報の固定画素で確認した字形

`kanpo1828-p3-p0001` の対象9行は固定450 DPIの枠なし画像を、同じ枠で切り出して見た。対象の開始2字目は、右上が「大」の斜線ではなく「立」の縦画と横画を持つ「﨑」の字形。6字目は左の点と字の下を回る線を持つ「迨」。画像中では、この形が複数の行で同じ位置に繰り返す。資料の文字層や外部の固有名詞表は使っていない。

208行目の末尾は、固定450 DPIの全文の切り出しと枠あり・なしの拡大で「有」の次に草冠と「與」を持つ字がある。枠の下端と表の罫線の間に「亭」の画素はないため、この枠で確認できる末尾は「有藇」。

画素からのこの確認は開発の候補に使う。訂正には同じ固定画像を読んだ別々のSolとOpusの全文一致も必要。この記録は読み手に配布していない。

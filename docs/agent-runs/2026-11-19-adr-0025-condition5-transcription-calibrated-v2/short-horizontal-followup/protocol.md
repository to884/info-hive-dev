# 白書の短い横軸の枠で行う追試

混在した短い枠の試験では官報の9行で全文一致がなく、防災白書では3行すべてが一致した。白書での結果を見て設けた開発試験として、防災白書92ページの未読3行と、防衛白書89ページの同じ短い横軸の未決定3行を読む。同じ頁の既知の対照を1行ずつ加える。

固定150 DPIの元表示が3倍で、枠の座標が整数、寸法が元の枠の3倍であることを確かめる。枠と450 DPIの拡大を保持した前回の同じカードと指示を使う。読み手には正解、主OCR、既存の結果を示さない。対照を含む同じ画像を個別の新規SolとOpusに渡す。再試行に頼った票は技術未決定にする。

本文の完全一致、未知、不一致と対照の状態を別々に残す。正式監査と開発補充は別に扱い、この試験で未読の資料や監査標本を選ばない。

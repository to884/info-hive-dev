# Z014とZ015の保存票を元PDFの描画命令で照合した結果

v104のZ014とZ015について、開発用の元PDFのSHA-256が画像の固定時と一致することを確認した。2ページ目の各行で、数字を描く命令と、塗りつぶされた円とコンマのパスを特定した。パスの座標を保存済みの150・450 DPI座標に結び付け、Sol・Opusの保存票の成分番号、字形、数字間での挿入位置と照合した。[元PDF](../v97-black-punctuation-lookalikes/development-fixed-frames.pdf)・[行別の描画命令と再集計](comparison.json)

| 枠 | 照合前（v104） | 元PDFと固定座標で確認したこと | 照合後 |
|---|---|---|---|
| Z015 | `65.183`、ピリオドの過剰転記 | 成分6は独立した円。成分7は実コンマだが、中心は枠下端より150 DPIで1画素、450 DPIで3画素外 | `65183`、正解 |
| Z014 | 未決定 | 成分6は独立した円。成分7は実コンマで、中心が両解像度で枠下端と一致 | `82,469`、正解 |

Z015では枠内の黒い点を除き、枠外のコンマは以前の枠判定どおり除いた。Z014では両保存票が実コンマを報告していた。元PDFで別々のパスを確認し、黒い点を除いて、境界を含める既存の枠判定で実コンマを残した。v104ではZ014に新たな字形照合を適用しておらず、v101の未決定を引き継いでいた。今回はv104の2通りの保留条件で同じ結果になった。

2枠で正解0→2、過剰転記1→0、未決定1→0、脱落0→0。これは、コンマと黒点が別々の命令列で描かれた合成PDFの出典照合である。新しい画像読み取りと再レンダリングは0件。正式監査の固定画像4,482添付と台帳を照合し、条件5の合否基準を維持した。


Opusの限定レビューは承認。Z014の照合前の結果は、v101の分類「未決定」と保留成分番号から再現し、未決定の回答と採用成分がないことまで照合した。両保存票が元PDFの2パスを記録していたことも検査した。再集計は保存結果とバイト単位で一致した。[レビュー](review-opus.md)

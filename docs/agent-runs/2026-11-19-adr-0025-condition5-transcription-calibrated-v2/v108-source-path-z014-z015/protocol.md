# Z014とZ015の保存票を元PDFのパスで照合する

対象はv104のZ014とZ015。v97で画像と一緒に固定した元の開発PDFのSHA-256を確認する。PDFの行識別子で位置を探し、行の数字の描画、塗りつぶされた円とコンマのパス命令を読む。パスを固定した150・450 DPIの座標に結び付け、成分番号、保存票の字形と数字間の挿入位置を照合する。この合成PDFのコンマと独立した円の命令列だけを扱う。

黒点を外し、コンマには従来の枠所属を適用する。保存した転記の文字や位置から構成したv104の結果と比較する。Z014はv104の対象外11枠に含まれ、v101の結果を引き継いでいる。画像だけの票を置き換えず、開発用の出典照合結果を別に記録する。新しい画像の読み取りと再レンダリングは0件。条件5の合否基準と正式監査の固定画像・監査結果は従来どおり。

# 中立化した画像指示で官報の候補を確かめる

開発で扱った官報の同じ頁の144、164、190、201行目を再読する。既存の画像、枠、所属と正規化を維持し、過去に割れた字の例と既存正解を画像担当に渡さない。四行の選択と、採点・描画・原票の保存方法を両モデルの読取前に固定する。

SolとOpusに別々の新規セッションで、一行の画像だけを一度ずつ渡す。164行目は二つの新規票が本文全体で一致し、固定450 DPIの字形を確認できた場合に、別版の正解に採用する根拠とする。201行目と190行目は、同じ字形と住所の区切りの対照に使う。144行目は別の行として本文全体の一致を確かめる。この再読と未使用の開発行の比較は混ぜない。

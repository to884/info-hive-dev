# 条件5の開発試験　枠寸法を照合した実資料の比較

前版では、幅と高さを終点の座標と解釈したため、選定の層を再現できなかった。前版の対象、固定と原票は保存する。今回はOCRの整数箱 `[x, y, width, height]` を、保存済み150 DPI表示の枠幅・高さの3分の1と全候補で照合する。

全配置を測れなかった公開の評価2回目と3回目から、それぞれ「所属軸xで元画像に詳細分割あり」「所属軸xで詳細分割なし」「所属軸y」の3層を使う。各層から既存未決定と既存確定を1行ずつ選ぶ。画面で確認する位置を一定の寸法にできるよう、対象の長辺800画素以下、短辺120画素以下に限定する。各層・状態で適合行を別版の固定文字列と資料ID・行番号のSHA順に選ぶ。OCRの転記、正解本文、印、スコアは選定に使わない。対象を他の画像に追加する場合は別版とする。

150 DPI・450 DPIの枠あり・なしの同じ位置を、表示上の字を拡縮せずに一枚へ並べる。長い枠は隣の画像と64表示画素以上重なる連番に分ける。枠の周囲も各方向32表示画素残す。両指示で同じ画像を同じ順で渡し、同じ開発用の6行を組ごとに独立したSol・Opusで読む。字種や所属が決まらない行は未決定とする。

旧版で未決定だった行に出た異系統一致は候補一致と呼ぶ。既存確定行では旧全文との一致・不一致・未決定を別に記録する。2組の合計で候補一致が2行以上増え、既存確定の一致が減らず、不一致も増えない場合に別の開発行で追試する。この比較から既存の正解を更新せず、正式な採点と監査には別に定めた独立手順を使う。

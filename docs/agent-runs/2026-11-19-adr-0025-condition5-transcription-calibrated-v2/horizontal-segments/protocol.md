# 条件5の開発試験　長い横行を区画ごとに読む

実資料の前試験で固定した詳細分割のある横軸4行を使う。評価2回目と3回目から、既存未決定と既存確定を各1行。この版では、両群に同じ枠付き・枠なしの切り出しと、区画の境界を示す青い目印を渡す。目印は余白に描き、文字の画素には重ねない。

通常群は各カードを照合して行全体を一度に転記する。区画群は、行全体の枠に所属する字を元の規則で選び、その字全体の横方向のインクの中心で一つの区画にだけ割り当てる。内部境界上の中心は右の区画に属する。自然な読む順が一つの左から右の横行と確認できない場合は未決定。各区画の所属や字種を確定できない場合はその区画を未決定とし、モデルごとに未決定の区画が一つでもあれば行全体を未決定とする。空の区画は有効な空文字とし、全区画を左から順に結合して一つの行の票を作る。既定の枠への所属、入力の解像度、最終的な採点の単位と完全一致の基準を維持する。

各群を新規のSolとOpusで読む。未決定行の候補を空の一致と本文一致に分け、既存確定との相違を数える。既存未決定の本文一致が増え、既存確定の一致を維持した場合だけ、別の開発行で追試する。開発用の4行であり、既存の正解はこの試験で更新しない。

# ADR-0025 条件5の独立監査の敵対的レビュー

監査の開始前に、数値の基準と標本抽出、固定画素を維持したまま、配布と許可済みの出典補助が正しく働くかを確認してください。読み取り専用です。修正を加えず、確実な反例と再現方法を示してください。

1. `run.py` と `delivery.py` を読み、事前固定の入力、標本の一回抽出、同じ画像と二系統の新規セッション、原票の来歴を迂回できないかを調べてください。429を読取前と分類できる条件は `v22-list-mark-pilot/recover.py` にあります。利用枠の拒否、CLIが死んで露出が不明、技術失敗、通常の判読不能、有効な票が返った場合が混同されないか、実際のコードを追ってください。原票を複製したり過去セッションを正当と見なしたりする経路があれば重大です。
2. `source.py` の本文と符号の境界、位置が合意していない票、同じ点の再使用や順序の逆転、一様な地色、フォント対応に矛盾がある場合を確認してください。既存の本文をPDFから採る経路、描画の所有者と実際のCIDの結び付けが抜ける反例を探してください。原本補助を認めるのは画像で字種を区別できない丸印と点線のみです。
3. 合否は既知の領域・画像補充の双方で不一致・参照不足0、既定の上限と全配置を維持します。既存正解、予測、採点層、開発票、監査票の境界を追ってください。今回の変更で本来の分母が減る経路、未使用資料の混入、再抽出があれば示してください。

今回のレビューには監査標本や未使用資料を開く必要はありません。画像を読む実行役とは別のセッションにします。技術的な内容は、候補の採点や二読の結果が未確定でも確認できます。指摘の重大度、対象、根拠、反例と修正の方向性を記録してください。

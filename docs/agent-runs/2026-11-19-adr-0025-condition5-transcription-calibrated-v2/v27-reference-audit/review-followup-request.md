# 修正箇所に絞った再レビュー

初回の5件の指摘に対応した。各項目の修正を確認し、重大な再現反例があれば示してください。監査の正式抽出はまだ実行していません。リポジトリや資料は読み取り専用で扱い、独立な実画像の読み取りや長時間の実行は不要です。

- 新しい `runner.py`、`delivery.py`、`limits.py` と `transport-preflight.json` を確認。利用枠の疑いを含む非受領で該当系統の新規配布が止まるか、読取済みの票や起動済みの原票を消して再送できるか、起動直前の台帳の境界は正しいかを検査する。Codexの失敗イベントは消費量の証明に使えないため、未証明の試行は再送しない。
- `run.py` の固定、検査する段階、対照の留保と正解の来歴を確認する。公開開発用と未使用資料の境界を保つ。
- `source.py` の近接した候補の変更を確認する。二票の座標からそれぞれ3画素以内で二閾値に一致する候補が一つあれば、元の描画の符号を独立に確かめる。点の再使用や許可対象外の文字の符号が受理される例を優先して探す。

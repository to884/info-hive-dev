# 条件5の開発試験　縦列と枠境界

比較用の固定32行と16枚の画像を使う。比較前に行種から縦列12行と境界句点4行を対象に定める。SolとOpusが、現行指示と所属手順を補った指示をそれぞれ別の新規セッションで読む。両指示とも全16画像を同じ順で渡し、同じ16行について画像だけから回答させる。補う指示は列の順序と枠内への所属の確認方法を具体化する。条件5の正式な採点条件、正解と元画像は維持する。

初回二読が異系統で一致した既知の全文だけを確定する。第三読の影響を混ぜず、二読の結果と単独票を別に集計する。縦列と境界を別々に数え、正解、誤確定、未決定、脱落、過剰転記、正解・誤り・未決定の行別遷移を保存する。

縦列で全文正解が増え、未決定が減り、誤確定・脱落・過剰転記が増えず、境界例の全文正解が減らないときだけ、次の開発専用画像で同じ手順を追試する。結果が悪化した場合は、列の順序と文字の所属のどちらで割れたかを調べて、事前に固定する次の試験に反映する。既存の合成画像での比較であり、正解の全面再作成や正式再監査はこの結果だけでは開始しない。

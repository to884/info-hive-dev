# 条件5の開発試験　縦列・境界の指示と画像提示

固定32行のうち縦列12行と境界句点4行を、別々の新規Sol・Opusセッションに画像だけで読ませた。異系統の既知の全文が一致したときに正解または誤りで確定した。条件5の正式採点と固定正解は維持した。

| 比較 | 群 | 縦列の正解・誤り・未決定 | 境界の正解・誤り・未決定 |
|---|---|---:|---:|
| 指示 | 現行 | 0／0／12 | 3／0／1 |
| 指示 | 所属の確認手順を追加 | 0／0／12 | 4／0／0 |
| 画像提示 | 原画像 | 0／0／12 | 4／0／0 |
| 画像提示 | 対象行を切り出し | 0／0／12 | 4／0／0 |

縦列ではどちらの比較でも二読の確定はなかった。Solは4条件すべてで縦列12行を未決定とした。Opus単独では、指示の比較で正解0→1行・誤り0→1行、画像提示の比較で正解6→2行・誤り2→5行だった。後者のOpusの確定票では脱落が2→6字、過剰が2→7字だった。同じ指示・原画像を提示した二つの試験で、Opusの縦列正解数が1行と6行に分かれた。各比較の各条件はモデルごとに1回であり、これらの単独票の差にはセッションのばらつきが含まれる。二読の結果はいずれも事前の進行基準に届かなかった。

## レビューと検算

Opusは、同じ固定での再実行により原票や結果を上書きできる点、切り出しの枠端が保存されることをコード単体で保証していない点などを指摘した。観測済みのこの2件の固定と結果は保存した。各回の異なるセッションID、Solの依頼記録、Opusに渡したストリームを復元したSHA、画像、原票と行別判定を照合した。元の画像生成器で紙目だけの画像を再現し、切り出した16枚のうち削った右端・行境界・見出し下の帯に紙目以外の画素がないことを確認した。カード寸法の違いにより、モデル側の縮小率は異なり得る。後続の実資料試験には二重起動を止める排他的な開始記録を入れた。

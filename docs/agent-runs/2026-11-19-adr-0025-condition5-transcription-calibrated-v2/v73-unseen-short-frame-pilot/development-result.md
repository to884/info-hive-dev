# 未使用の開発用短枠18行の試験

固定した18行を、SolとOpusが旧・新で独立した新規セッションから読み、各版・各モデル18票を受領。双方とも `high`。旧・新とも同じ17行で二票が既存正解に一致し、同じ1行で未決定。二票一致の誤り、脱落、過剰転記、出典待ちは0。Solは両版で18行正解。Opusは官報112行目の枠外の文字を両版で加えた。順序の変更だけでこの行は解消しなかった。

準備では、最初に決めた18行のうち8行で周辺の配置画像が従来の自動配布に入らないことが分かった。同じ選定を再現し、8行の両版に同じ固定150 DPIの配置画像を付けて固定した後に読み始めた。新旧の画像バイト列・順序は各行で同じ。対象選定の除外は手元の開発・監査記録に基づく。今回の一致数から、未使用の別資料で改善したことまでは確認できない。[方法](protocol.md)・[行別集計](comparison.json)

後続の敵対レビューでは、幅35画素以下の官報6行はすべて一字で、列順の誤りを検出できなかった。領域の旧監査・修復の台帳に載る行も含まれていた。未使用の二字の縦列で効果を確認した証拠として使わない。[レビュー](../v72-short-frame-order-pilot/review-opus.md)

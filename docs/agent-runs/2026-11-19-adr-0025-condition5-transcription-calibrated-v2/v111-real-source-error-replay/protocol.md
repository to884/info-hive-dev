# 以前の脱落・過剰転記・未決定を実資料の元PDFで照合する

固定した既存開発の15枠を使う。v22旧指示で二票が矢じりを落とした情報通信白書3行と、正解だった同資料の文字行1行。v88旧指示のコンマ過剰転記2枠。v90新指示の数値3枠の未決定と、元来の数値対照6行。各試験の保存票を固定ハッシュと受領記録から再現する。矢じりの3行には、同じ画像で別の新指示を用いた保存二票も使う。

コンマは保存二票の字形、数字列、同じ挿入位置を、同一のPDF文字描画、固定150 DPIの成分と450 DPIの連結成分に一対一で対応させる。保存票に座標がある場合、その座標が別の成分を指すか、最も近い成分が一つに定まらなければ保留する。挿入位置と横座標の順序も一致させる。従来の座標だけでは未決定だった票では、許容幅を広げず、挿入位置と出典・固定画素が独立に一意な場合だけ対応を確定する。枠所属は150 DPIで判定する。450 DPIは成分の識別に使う。

矢じりの私用領域の符号の字形は別の保存二票が同じ記号を報告したときに限る。旧票の本文と同じ文字列を、新票から矢じりを除いた部分およびPDFの本文で確かめる。埋込み書体の1グリフを同じ位置の固定150・450 DPIの1成分に結び付け、両解像度で閾値170と191の両方を使う。字体の外接位置と固定画素の照合幅は矢じりに限り各解像度2画素以内。描画の重なりを排除できない場合は未決定。枠所属は150 DPIの同じ式で判定する。

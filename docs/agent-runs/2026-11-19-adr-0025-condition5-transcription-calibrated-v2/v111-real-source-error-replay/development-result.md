# 誤りが出た実資料の保存票を元PDFで再集計した結果

実資料の開発15枠を対象に、Sol・Opusの保存二票を照合した。内訳は、v22の矢じりの脱落3件、v88のコンマの過剰転記2件、v90の座標照合で未決定だった3件、正解済みの対照7件。矢じりの3件は、同じ画像に別の指示で回答した保存二票も使い、計36票を原票から再現した。150 DPIで枠への所属を判定し、450 DPIは成分の照合に使用した。[手順](protocol.md)・[行別の照合と結果](comparison.json)

| 指標 | 照合前 | 照合後 |
|---|---:|---:|
| 正解 | 7 | 15 |
| 脱落 | 3 | 0 |
| 過剰転記 | 2 | 0 |
| 未決定 | 3 | 0 |
| 元から正解だった対照の悪化 | — | 0／7 |

- **脱落3件**。情報通信白書PDFの3ページ3行目、4ページ4行目、5ページ3行目。埋め込み書体の同一ハッシュの私用領域符号 `U+F0D8` を、先頭の固定画素成分に一対一に対応させた。150 DPIで3件とも枠内だった。正規化後の本文が元PDFと旧票で一致し、同じ画像を読んだ別の保存二票は同じ本文の前に `➢` を報告していたため補った。字形と固定画素の照合幅はこの書体の矢じりに限り各解像度2画素とし、濃さの異なる二つのしきい値で同じ成分に絞った。
- **過剰転記2件**。防衛白書PDF 525ページ101行目の枠外対照で `138,365` → `138365`、同94行目の枠外対照で `92,116,141` → `92116141`。保存票にあるコンマ計3個を文字描画に対応させ、150 DPIで枠外だったため除いた。
- **未決定3件**。同101行目の境界・枠内と、94行目の境界。二票が同じコンマの字形と挿入位置を報告したが、横座標の差で従来は保留されていた。固定画素と元PDFの対応を一対一に確かめ、`138,365` が2枠、`92,116,141` が1枠で正解。94行目のコンマ2個は450 DPIで枠下端から約1.04画素外だったが、150 DPIでは境界上のため残した。

対照7件は情報通信白書の文字行1件と、防衛白書・防災白書の既存数値対照6件。いずれも同じ文字列を維持した。この比較は過去に結果が判明した開発枠での再集計で、矢じりの字形には保存済みの別指示の票も用いた。新しい画像読み取り・再レンダリングは0件。正式監査の固定添付4,482枚と台帳を再照合し、条件5の合否基準と正式監査結果を維持した。


Opusの初回レビューの指摘を受け、挿入位置と横座標をともに昇順とし、最も近い成分が複数ある場合も保留するようにした。逆順・複数候補を再現した検査で保留を確認し、限定再レビューで承認された。対象外の試験や不足した票も保留し、再実行した15枠の集計は保存結果とバイト単位で一致した。[初回レビュー](review-opus.md)・[再レビュー](review-confirm-opus.md)

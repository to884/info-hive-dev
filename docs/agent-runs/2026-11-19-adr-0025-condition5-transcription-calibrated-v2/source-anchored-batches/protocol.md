# 条件5の開発用画像補充　事前固定した別の行での確認

点の位置を示す補助を使った前試験では、点線4行すべてで異系統の全文・点線位置・点数がそろい、出典と結合できた。今回は、前試験で読んでいない防衛白書と災害資料の別の点線12行を使う。各資料の掲載2ページから3行を、事前に指定したハッシュ順で選ぶ。害の検査として、各PDFの点なしの既知の行を各束に1行ずつ入れる。補助の点は固定150 DPI以外の入力から計算しない。

一度に4行ずつを別々の新規SolとOpusに渡す。元画像を保ち、配置確認に使う補助画像を添える。既存の正解・候補本文・独立した出典の符号は渡さない。両者に見えた点数・所属・位置と周囲の全文がそろい、出典の候補と対応するものだけを検証用の一致として記録する。反証は「双方未決定」「片方未決定」「点位置・点数相違」「周囲の本文相違」「出典と相違」として残す。

点線12行中10行以上の結合ができ、点なしの対照4行で既存の全文との誤った一致がなければ、残る適格な行の補充へ進む。すべての票と使った素材の版を保存する。これは開発中の進行判断であり、正式な条件5の採点・独立監査の合否は変えない。

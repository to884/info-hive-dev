# 色付きの項目丸と単独の小点の開発結果

同じ添付の6行で、同じ行に繰り返す色付きの項目丸と、黒い単独の曖昧な小点を区別する説明を比較した。v29では防衛白書の色付きの丸2行が二票一致したが、既存の中黒1行を両票が黒丸へ誤転記した。v30で色付き丸を複数の項目に絞ると、色付き丸2行は二票とも正解を保ち、単独の小点で一票だけが黒丸を返した。

v32では色・繰り返し・本文の位置を明示し、単独の点の座標は二つ同じ値を書くようにした。色付き丸2行が正解で、単独の曖昧な点、矢じりと小点、凡例の周囲にある本文の小点は4行とも両票が物理位置に一致した。後者は符号の出典照合が必要。脱落、過剰転記、二票の不一致はこの6行で0行。[v29](../v29-typographic-round-pilot/result.json)・[v30](../v30-repeated-bullet-pilot/result.json)・[v32](result.json)

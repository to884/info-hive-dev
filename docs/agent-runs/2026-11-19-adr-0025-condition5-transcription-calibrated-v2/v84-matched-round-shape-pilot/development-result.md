# 同じ径にそろえた丸と先頭の筆画の比較

先頭の字の形と同じ長辺9〜10画素の出典確認済みの中黒3個を、固定150・450 DPIで調べた。資料は防衛白書と情報通信白書。後者の2個は同じ字形。三つとも仮の先頭枠では既存の点検の候補に入り、450 DPIでも二閾値で成分を確認した。四隅を等面積で測った場合は、四隅のどこにも字の筆画のような大きい欠けがなかった。

対象の筆画は150 DPIの右下0〜8.3%、450 DPIの右下5.0〜7.7%、対角は両解像度で65%以上。450 DPIで二画素の周囲に他の成分がない。固定画像から丸の形ではないと確認した。合成の丸は40個作り、31個が既存の150 DPI候補になり、全31個で450 DPIの成分が得られ、丸から除いた例は0。二つの字形の実対照で確認した開発試験で、他の資料の正式な合否への採用は保留。[測定結果](result.json)・[手順](protocol.md)

Opusの `high` の再レビューは、対象1行の先頭の成分が塗りつぶした丸ではないという証拠を承認した。追加で、正式v64の両票が「F-15能力向上」で一致することと、実対照3個が仮の先頭枠で空洞検査を含む従来の保留条件に入ることを確認した。実対照は元の行では先頭候補に入らない。一般の文書に使う規則としては検証していない。[レビュー](review-opus.md)・[追加の確認](review-coverage.json)

# 同じ大きさの丸を対照にして先頭の形を確かめる

v76のOpusレビューの指摘を再現し、奇数画素の中心を左右の片方、上下の片方に入れずに測る。防衛白書84行目の先頭の筆画に対し、固定150 DPIで長辺9〜10画素と確定した元PDFの丸を3個使う。別の防衛白書の1個と、情報通信白書の同じ字形の2個で、独立した字形は2種。丸の位置が文の途中の場合は、まず元の枠で形を測り、丸を先頭から12画素以内に含む仮の枠でも既存点検と同じ候補になるか確認する。既存の本文と枠は変更しない。

固定450 DPIで同じ成分が二つの閾値で決まる場合だけ比べる。二つの解像度で同じ方向の角が薄く、450 DPIの近傍に他の成分が重ならない場合を、丸の形に合わないことの証拠とする。さらに合成丸を大きさ、濃淡、サブピクセル位置を変え、150 DPIの候補抽出から450 DPIの成分確認まで通す。正式監査や他の行の除外規則への反映は行わない。

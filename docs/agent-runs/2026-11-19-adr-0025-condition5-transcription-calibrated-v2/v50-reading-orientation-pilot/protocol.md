# 読む向きと直交する枠端の開発比較

v47の保存票で同じ誤転記が出た4行、片票が判読できなかった行や字形・所属で割れた9行、既存正解と両票がそろった対照3行を使う。v47で渡した固定150/450 DPIの画像と枠をそのまま引き継ぎ、表示の差だけを開発用に加える。試す行、送る画像、指示、役割を先に固定する。開発票を次版の正式な監査に使わない。

短い縦軸には固定450 DPIの同じ画素を両方の90度で表示する。字が横倒しの場合だけ使い、枠と読む順は元の位置で確かめる。長い縦軸には、同じ列の輪郭を続けて拡大する固定450 DPIの表示を加える。語の意味や一般的な字体で置き換えず、横画の両端や偏と旁の違いを調べる指示を加える。

横軸には、上下の枠と固定450 DPIのインクの帯の位置を示す。二つの濃さで安定した帯の中心を補助に使う。字を含める規則は、割当軸に少なくとも半分、直交軸の中心も枠内。帯が複数の文字をまとめていても、各字の中心は画像で確かめる。追加表示は既存の正解や主OCRに依存しない。

別々の新規Sol・Opusセッションに画像だけを渡す。保存済みのv47の二票と比べ、各モデルの一致と、二票の一致・脱落・過剰転記・置換・未決定を行別に集計する。本文は元PDFの文字層で補わない。小点の位置だけが二票で確定した箇所は画像のみの集計では出典待ちとして区別する。

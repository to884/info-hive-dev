# 数値画像の小さい成分を番号で照合する開発試験

v90の12枠を同じ固定画素で使う。既存2枚に、小さい連結成分それぞれの番号と生の画素での拡大を添付する。旧・新で同じ3枚。番号と横位置の目安は本文画素の外側に置く。候補の範囲、所属の計測式、正式枠、既存正解を変えない。

旧は境界を含む指示で全文、新は数字列と、各記号の字形、直前までの数字の個数、成分番号を回答する。番号のある他の筆画を区切りとはみなさない。二票の数字・種類・挿入位置・物理成分がすべて一致した場合に既存の式で所属を計測する。Sol・Opusとも `high` とし、一枠一版の新規セッションを使う。枠外・境界・枠内の6枠と実資料の6行で脱落・過剰転記・未決定を比較する。モデルが複数の成分に分かれた記号を安定して選べるかや、文字行への適用はこの試験の対象外。

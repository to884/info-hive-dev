# 官報164行目の二字目

固定450 DPIで164行目の二字目と同じ頁の201行目の二字目を照らした。両方とも左に山、右上に立の形、右下に可が見える。字形を囲む範囲は四つの輝度閾値のそれぞれで近く、役割を伏せた独立の画像票では両行の本文全体が確定した。201行目は既存の正解のまま。164行目だけ、山の隣に大の字形を使った「崎」を「﨑」に変更する候補とする。

同じ指示を変えた13行の試験では、別の行で既存正解と異なる二票の一致もあった。画像と二票の両方を確認できた164行目だけを今回の訂正に使う。144行目は、本文全体には二票の一致がないため、画像正解の訂正候補に含めない。

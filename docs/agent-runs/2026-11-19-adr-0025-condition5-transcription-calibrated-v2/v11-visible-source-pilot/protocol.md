# 点の符号の出典照合に残った二つの問題

v10の監査で、間接参照のフォントのCID幅を読めず保留した頁と、同じ点を塗りと輪郭の両方で描く命令が候補として重なった頁を開発用に調べる。元PDF、固定画素、両者の保存票、転記の正規化、合否は維持する。

CIDの幅はPDFの間接オブジェクトを解決してから読む。重なった描画は、フォント、符号表、描画行列、実際のCIDと各位置、クリップが同じときに限り、一つの符号の候補として扱う。同じ点について異なる符号や字形の命令が残る場合は参照不足とする。

v10の出典待ち7行を現行と修正版で比較し、先に確定できた4行が保たれること、保留がどう動くかを記録する。v10の票や監査結果には反映しない。

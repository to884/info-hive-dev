# 条件5の開発試験　位置のみの補助を別の12行に適用する

点線4行では、番号なしの位置補助で両方の画像票が周囲の本文と位置を確認し、二つの画像計測と出典から符号を結合できた。点線12行と各資料の対照を含む以前の比較と、対象、元カードの画素・順、所属規則をそろえる。番号付きの補助は、固定150 DPIから切り出す番号なしの位置補助に替える。出典と物理点の数、旧票は提示しない。

独立した新規SolとOpusが、周囲の全文と点線の最初・最後の元カード番号を返す。双方が同じ位置と周辺の全文を確かめ、二つの画像計測と出典を合成できる場合を結合とする。前の番号付きの票はいずれも使わない。12行中10行以上で結合でき、点なし対照に既存本文と違う二票一致が出なければ、同じ条件で残る開発用行を補充する。条件5の合否、固定資料、既存の監査票は維持する。

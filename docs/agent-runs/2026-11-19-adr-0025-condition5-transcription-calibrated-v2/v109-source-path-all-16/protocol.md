# 同じ開発16枠で元PDFの描画命令を保存票と照合する

事前に固定したv97の元PDFと150・450 DPIの画像を使う。元PDFの行識別子から、数字、コンマ、独立した円、短い斜線の命令を特定する。各パスの外接範囲を両解像度で固定座標に変換し、v108と同じ1画素以内の照合幅で、他の候補と重ならず一対一で対応する成分だけを使う。保存票の成分番号・数字間の位置・枠への所属と照合する。両票で数字列が一致することを確認し、枠内・境界上に採用するコンマは保存二票に同じ字形・成分番号・挿入位置があることを求める。独立の黒い筆画はパスが同一成分を指すと確認できたときに外す。黒い筆画については、保存票の記号の種類が異なるか、片方または両方が報告していない場合でも、対応した筆画の除外に限って扱う。枠外の成分は従来の所属判定を用いる。画像票だけでは除外を保留した候補も、元PDFで独立した筆画と一対一に照合できれば外す。対応が不明な枠は未決定。

v104の二通りの保留条件ごとに全16枠と枠の種類別を比較する。v104の元から正解だった枠では、照合後も採点と確定した文字列が一致するかを調べる。Z014・Z015はv108の結論も再現する。新しい画像読み取り・再レンダリングは0件。条件5の合否基準、正式監査の固定画像と監査結果は従来どおり。

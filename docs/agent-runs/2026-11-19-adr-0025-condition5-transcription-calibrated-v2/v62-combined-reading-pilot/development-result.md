# 固定35行での組み合わせ試験

前回の独立監査 v47 で不一致または参照不足だった全23行と、以前の開発比較で使わなかった対照12行を固定した。短い横枠、横の目盛り、段落の丸、縦列と直交する枠の端の表示を組み合わせた。Sol と Opus は1行ずつ別々の新規セッションで読み、両モデルとも35票を受領した。4頁の出典確認は、両票で位置がそろった符号に限って行った。

| 二票の判定 | v47の保存票 | v62の新規票 |
|---|---:|---:|
| 既存正解と一致 | 12 | 28 |
| 同じ誤りで一致 | 4 | 0 |
| 未決定 | 19 | 7 |

最終判定の過剰転記は1行から0行、脱落は0行のまま。個別の票では、Opus に括弧の過剰転記1行と縦列の仮名の脱落1行が残った。対照は12行すべて一致を維持した。正式な監査の数値には加えない。

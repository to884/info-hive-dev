# 画像表示と出典のレビューを受けた扱い

OpusのレビューはMajor 2件、Minor 3件で不承認。v62とv63の票と集計値は保存する。v62の12行から28行への改善は、すでに開発で扱った行を含む改良手順の確認であり、新しい行への効果の根拠として扱わない。既存正解を見て加えた字体例が、別の読みを選びにくくする指摘も、v62の実際の依頼を照合して確認した。

比較コードのハッシュと出典経路を送信前に固定していなかった。v61の方法で開発した同じ行をv62の集計に含めたことも確認した。最初の二票の出力と後の集計はこの来歴を明記する。以後は二票を得る前に判定・出典のコードと例外の扱いを固定し、集計では両系統の原票の来歴を固定値でたどれるようにする。

次の比較は、個別の漢字や過去の誤読を示さない指示を使う。今回までの補充・診断・再読・正式監査で扱った行を除き、既知の開発母集団から形状により事前に固定する。v65で一致した官報164行目の訂正候補は、中立化した指示で新しい二票と固定画素を照合するまで正式な正解に採用しない。

配布で省かれた細部の有無を束で検査し、必要な細部を上限で落とさない。許可済みの小点を確かめる出典経路は、対応しない描画形式をその行の参照不足として残す。ハッシュやPDFの取り違えは検査の失敗として扱う。v63を採用しない方針を保持する。v64に用意した入口は暫定の開発コードのままとし、正式な母集団の固定・抽出を始めない。

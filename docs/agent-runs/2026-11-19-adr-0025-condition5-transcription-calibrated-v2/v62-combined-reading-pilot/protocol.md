# 固定画像の表示と転記指示を組み合わせる開発比較

前回の独立監査 v47 で既知正解と不一致または参照不足だった23行をすべて使う。加えて v47 で一致した行から、縦軸の長短と横軸の短枠・その他の4群を設け、各群3行を選ぶ。前回までの開発比較に使った行を対照から除き、監査と重複していない行を優先する。同順位では `adr0025-stage2-v62-controls` と行の識別子の SHA-256 順で選ぶ。

保存済みの v47 の Sol・Opus の原票を対照として利用する。今回の Sol・Opus は1行につき1セッションで独立に読む。新しい双方のセッションに、同一の固定150・450 DPIに基づく画像と、同一の転記指示を渡す。前回の原票、参照正解、PDFにアクセスできる状態で読ませない。画像の表示を決めるときに使うのは枠の寸法と固定画素のみとし、行の識別子、正解、過去の結果に応じて表示を変えない。承認済みの符号の出典確認は二票の照合後にだけ行う。合否基準、監査の参照正解、固定画像の元画素を変更しない。

二読の一致、不一致、参照不足に加え、脱落、過剰転記と保留を記録する。この比較は開発専用とし、正式な監査の抽出や未使用評価には使わない。

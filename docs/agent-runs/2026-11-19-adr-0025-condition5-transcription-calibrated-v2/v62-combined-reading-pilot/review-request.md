# 条件5の監査に向けた画像表示と符号確認の反例調査

条件5は、領域正解・画像補充正解の双方で既知の不一致と参照不足を0にする。公開・合成の数値基準、固定150/450 DPI、枠への所属、正規化、SolとOpusが既存正解と相手の票を知らずに一行各一度読む原則を守る。画像から符号が識別できない点線と丸印だけ、両票の位置・形の一致後に補助のPDF描画命令とフォント対応を使用できる。正式な抽出はまだしていない。

対象はv62の描画・切替・照合と、v61の縦組の丸印の証明。v63の連続区間は追加の開発代替案なので、合わせて設計上の問題を確認してほしい。特に以下を確認する。

- 既存の行表示や必須の枠端・目盛りを無言で落とす条件、添付枚数や画像の大きさで本番が成立しない境界。固定画素を背景から切り出し、重ねる画像と本文の範囲を誤認する例。特定の行の正解や語を依頼に教えていないか。
- 連続区間の端、縦罫や下線、複数列を横切る短い横枠、上下の隣行が重なるときの脱落・重複。v63の連結の画素検査が添付上の欠落にも対応するか。
- v61の単一描画命令の非表示が、候補が描く全画素の検証、符号・位置の一意性、フォントとページに関する条件と結び付くか。画像担当の票にない本文の採用、許容外の字の出典補足、候補の読み違いを受け入れる反例を探してほしい。
- 開発の集計と保存票の来歴、正式監査へ昇格する際に追加すべき最小の事前検証。過去の正式監査と開発の結果は上書きしない。

画像の再読、正式な母集団の抽出、元資料の編集、ファイル変更は依頼の範囲外。再現できる欠陥を優先し、根拠と該当コードの行を示す。

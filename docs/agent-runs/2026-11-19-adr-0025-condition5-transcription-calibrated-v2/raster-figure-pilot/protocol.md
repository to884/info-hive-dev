# 防災白書の図表内の小さい文字を読む開発試験

防災白書の固定1頁には、PDF本文と別に図表が埋め込まれている。過去の画像補充で未決定となった図表内の41行を、OCRの枠の高さで三群に分ける。各群から4行をハッシュの順に選ぶ。比較のため、同頁の既知の図表内4行を結果を見る前に別に選ぶ。閾値、正規化、150 DPIの枠と所属軸は維持する。

固定150 DPIと450 DPIの元のカードに、450 DPIの枠周辺を原画素の整数倍で拡大したカードを加える。拡大したカードを重複させ、座標を記載する。画像補間や外部資料からの本文補充は使わない。二系統へ同じ順の画像だけを渡し、別々の新規セッションから全文と状態を受け取る。過去の票、主OCR、出典、正解や既知の状態を示さない。

両票の正規化した全文が一致した行だけを数える。従来未決定の12行で6行以上の全文一致があり、既知の対照4行で旧正解と違う二票一致がなければ、残り29行を同じ方法で補充する候補とする。開発用として記録し、正式な正解と監査の結果は別手順で確定する。

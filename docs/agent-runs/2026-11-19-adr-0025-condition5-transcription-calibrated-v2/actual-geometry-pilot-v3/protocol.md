# 条件5の開発試験　実資料の照合順の対照

枠寸法を照合した前試験の12行と同じカードの画素、順序、提示範囲、Sol・Opusの割付を維持する。前試験で補った指示は、照合順に加え、部分転記を許すようにも読めた。この版では、所属する字を一字でも決められなければ行全体を未決定、所属する字が確実に無い場合だけ文字なしとし、両群で明記する。新指示にだけ、450 DPIの枠なしで字形を見分け、150 DPIの枠あり・枠なしで所属を確かめ、所属を決めてから列順で読む手順を足す。

資料の組ごとに旧指示と新指示を各モデルの別々の新規セッションで比較する。既存未決定行では異系統の一致を、空欄の一致と本文の一致に分けて数える。既存確定行は既存の正規化後の全文との一致、相違、未決定を数える。本文の候補一致が2行以上増え、既存確定の一致が減らず、不一致も増えない場合に別の開発用行で追試する。原票の読取と正式な正解の監査は異なる手順として保存する。

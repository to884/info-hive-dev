# 枠の画素目盛りと丸い点の見分け方

v15を上書きしない。固定されたv15の標本から、画像補充正解で二票が余分に転記した2行、短い枠で判読が割れた2行、丸い点と他の符号で割れた6行、別の読取で既存正解と一致した対照4行を開発用に固定する。同じ固定150/450 DPI、枠、割当軸、正規化、数値の合否を保つ。新規のSolとOpusへ同じ画像を配布する。

短い枠は枠全体、長い枠は両端を固定150 DPIの整数倍で拡大する。赤線と目盛りを外側に引いた表示と、同じ範囲の元の画素を並べる。字が軸方向にまたがる場合は、字の全体の長さと枠に入る長さを見直す。半分以上と直交中心を満たした字だけを転記する。局所表示は所属と字形を確かめるために使い、縦列の全文を区画別の答えからつなげ直さない。

丸い符号は、固定450 DPIで輪の中が抜けているか、黒い点かを確かめる。句点として見える小さな輪は普通に転記する。符号を識別できない小さい黒い点は、行頭・行中ともに固定の形式で物理的な位置を返す。元PDFは画像の読み手に渡さない。本文・位置・形が二票で合う場合だけ、別の出典照合に回す。構造化された最終回答を受領し、開発用の判定の内訳を報告する。

# 二票で位置が一致した明るい小点を元PDFで照合する

固定450 DPIで明るい小点の候補が一つに絞れ、異系統の画像二票が本文とその座標で一致した防衛白書の行を開発で調べる。固定150 DPIの描画を再現し、文字オブジェクトを外したときに小点だけが消え、背景を残したまま該当オブジェクトを戻すと固定画素が復元されることを確かめる。照合するのは二票が指定した位置の丸印だけ。文字の描画と埋め込みフォントの対応を確認し、許可対象の符号だけを候補として採用する。本文の文字、周囲の別の図形、出典位置の追加には使わない。

文字を消しても点が残った画像入りの白書と、別の図形に似た防衛白書の点を陰性対照にする。元の固定画像・票・監査判定は今の版のまま保存し、この試験として結果を記録する。

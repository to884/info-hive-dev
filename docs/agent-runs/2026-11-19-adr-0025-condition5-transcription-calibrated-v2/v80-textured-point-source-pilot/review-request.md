# 小点の固定画素と補助出典の扱いをレビューする

対象はv76の先頭の字と丸を分ける物理的な検査と、v80の明るい点の照合だけ。両方とも開発用で、過去の監査の原票と判定は保管した。条件5の基準と固定画素、画像の異系統二読、出典の対象を画像で区別できない符号に限る条件を前提にする。

貼り合わせ、フォントの形、前景・背景、拡大座標で本当の丸を除いたり、別の文字や図形の符号の割り当てを確定したりする反例を探す。v76の四区画の判定と実対照の来歴、v80の一つの文字の特定とCIDの位置、例外と証拠不足の扱いを確認する。本文・元PDFの文字情報を一般に許可する方向の提案は不要。ファイル編集、モデルの画像読取、抽出は行わない。

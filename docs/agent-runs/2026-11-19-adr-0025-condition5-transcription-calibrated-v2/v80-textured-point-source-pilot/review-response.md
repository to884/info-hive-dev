# 形と背景の敵対レビューへの対応

- **同じ径の丸。** v76の実対照4候補は長辺9〜10画素の判定対象外だった。四隅の奇数画素を片側に数える偏りも確認した。v84で中心の行・列を除き、同じ径の出典確認済みの丸3個を測定した。独立した字形は2種。仮の先頭枠での候補抽出、二解像度、同じ位置への対応、近傍の追加確認を行った。本当の丸の除外0。40個の合成丸のうち31個が実際の判定経路に入った。[修正した開発試験](../v84-matched-round-shape-pilot/development-result.md)
- **暗い背景の種類。** v80の黒い陰性対照が明るい点の反例を覆わないことを確かめた。v83では背景の画像と広い地模様の各実寸を取得し、記録した二つの背景描画だけで36×36画素が再現した。文字でない白い図形と暗い図形に重なる白文字を、実際の背景検査で拒否した。[背景と陰性対照](../v83-direct-white-point-proof/background-controls.json)
- **描画に使った符号。** 逆引きの確認だけだったv80に対し、v83でコンテンツストリームのTJ内の実際の2バイトと埋め込みAdobe-Japan1のCID対応を直接照合。丸の箇所で三点リーダーを候補外にした。固定150 DPIでは点の124画素だけ変化。450 DPIの補助検査では範囲外46画素、最大1階調の差も保持した。対象の1行の証明で、一般にどの記号にも適用できると判断しない。[直接証明](../v83-direct-white-point-proof/result.json)

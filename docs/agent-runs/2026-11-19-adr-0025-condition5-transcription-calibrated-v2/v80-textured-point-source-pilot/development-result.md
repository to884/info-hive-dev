# 地模様の上にある白い点の出典照合

防衛白書13行目は、画像の二票が本文と曖昧な点の位置で一致した。固定450 DPIで明るい点が一つに決まった。元PDFで固定150 DPIの同じ画素を再現し、背景を残したまま点を描く一つの文字オブジェクトを切り分けた。埋め込みフォントのCID 638がU+30FBに対応し、置き戻した全文は既存正解に一致した。

陰性対照では、情報通信白書概要の画像に焼き込まれた点は文字描画を消しても残り、別の防衛白書の黒い丸は点の外にも文字の描画差が出た。どちらも新経路では符号を確認しなかった。開発結果のため正式判定は保留。Opusの敵対的レビューを `high` で開始した。[来歴と照合](result.json)

v64の保存済みmediumの白い点の二票は、開発のhighの本文・位置とも完全に同じだった。小点の形の判定も v64の両票に適用したと仮定すると、開発の試算は領域151一致・7参照不足、画像補充162一致・18参照不足。両方とも不一致0。正式v64は元の規則の領域150一致・8参照不足、画像補充161一致・19参照不足で保留。[保存票での試算](v64-sensitivity.json)

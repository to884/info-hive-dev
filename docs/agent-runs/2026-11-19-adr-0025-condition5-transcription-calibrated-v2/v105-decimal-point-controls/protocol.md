# 黒い点と本物の小数点を含む固定画像で点の所属を比べる

4書体それぞれで同じ数字列と文字位置を用いて4種類を作る。本物の小数点のみ、Z015に近い直径・高さで小数点位置に置いた黒点のみ、そこから上下左右にずらした黒点のみ、実小数点と黒点の両方。同じ数字間を使う。実小数点は数字と同じ書体のピリオドの字形、黒点は独立した円。150・450 DPI相当で点と数字の枠内所属と、二つの点の分離、左右順を検査して固定する。IDは混ぜ、各セッションには一枠の固定画像3枚と候補の番号だけを渡す。描画の区分、正解、他の枠、他の票は渡さない。

旧はv102の形・位置・役割の依頼。新は、前後の数字の下端と間隔に照らして点を比較し、点の形や見かけの位置だけで所属を決められない場合は判別不能とする。区切り個数、数字の意味、書式の慣習で補わない。回答書式は同じ。画像を共用し、SolとOpusをそれぞれ high の別々の新規セッションで、各枠と指示ごとに一回呼ぶ。全16枠、64票。

同一成分の役割は二票一致を採用し、食い違い、判別不能、書式不備は未決定。同じ数字間に二点を採用した場合も未決定。どの点を採用したかを元の描画区分と比べる。黒点を採用すれば過剰転記、本物の小数点を採用しなければ脱落と数え、未決定は別に数える。両方のある枠で黒点だけを採用した場合には、同じピリオドに見えても実小数点の脱落と黒点の過剰転記を各1件とする。文字列だけの採点と、未確定になる前の成分ごとの二票判定も併記する。正式監査の固定画像、正規化、合否基準は従来どおり。

# 条件5の開発試験　固定画像から測った点数を添える

前回の点線4行と固定画像を使う。通常の固定画素のカードは同じものを維持する。防衛白書の点なし対照を維持し、誤って官報から選ばれていた評価3回目の対照は、事前の行選定規則に沿って災害資料の別の行に直す。

点線のある行にだけ、元の固定150 DPIから水平走査で数えた点の位置・番号を示す画像を別に添える。先に、水平走査と8連結成分が同じ位置・個数を測ったことを確認する。補助画像には元PDFの符号、出典、候補の本文、旧票を載せない。読み手は補助を使う場合も、固定画像で番号が指す点とその所属を確認する。予備試験の2票は使い回さない。成分データは二票の独立性を意味しないため、周囲の本文と所属の確認、および補助の画素との照合が二系統で得られるかを評価する。

新規SolとOpusを読む担当とする。両方の全文・点数・点線の位置と、固定した出典が一致したときだけ、開発用の候補を作る。公式の正解を更新するには次の別版の判定が必要。

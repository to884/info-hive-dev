# 固定画素で小さい先頭成分が丸かを確認する

防衛白書84行目では、SolとOpusがいずれも本文を同じように転記したが、固定150 DPIで字の左と上の画からなる成分を既存の小丸点検が止めた。固定450 DPIで同じ成分を求め、輪郭の四つの区画で塗られた範囲を測る。両方の解像度と二つの濃さで、同じ区画の濃い部分が28%以下で対角の区画が58%以上の場合だけ、丸の形から外れることを記録する。450 DPIで成分を一つに絞れないか、どこかで反証が出れば既存の保留を維持する。

v27・v47・v64の固定した画像と確定済みの証跡を開発として調べる。候補を入力段階で丸・字種に置換しない。既存の丸印を保護するため、出典で確認済みの先頭点と、異なる大きさ・濃さ・中心を持つ合成の丸を対照にする。固定本文、正式監査、正規化、数値の合否基準には変更を加えない。成分が丸の形から外れるという確認は、読者の本文の二票の代わりに使わない。

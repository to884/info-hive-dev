# 先頭の丸に似た成分を固定画素で確認した結果

防衛白書84行目の両票は同じ本文を読んだ。固定150 DPIで小丸の候補になった成分を450 DPIの同じ位置で一つに絞った。150 DPIでは右下の濃い範囲が15〜25%、対角が75%。450 DPIでは右下が約8〜9%、対角が65〜67%。固定画像では、この成分は行頭の字の筆画で、丸の対照と異なった。

保存済みの三つの監査から抽出した6候補で、丸以外の条件を満たしたのはこの1行。出典で確定した4候補、別の画像票1候補、合成丸48例に丸以外の判定は出なかった。得られた物理的な証拠は開発用。固定した監査票の判定を変えていない。[手順](protocol.md)・[数値と対照](result.json)

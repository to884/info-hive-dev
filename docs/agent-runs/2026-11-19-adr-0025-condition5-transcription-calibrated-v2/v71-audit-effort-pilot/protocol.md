# 監査と同じ画像を使う推論設定の開発比較

確定済みのv64で既知の参照不足となった27行をすべて使う。対照は同じ監査で画像の二票だけで既存正解に一致した行から、短い横枠、その他の横枠、短い縦枠、長い縦枠の各群2行を、固定文字列と行IDのSHA-256順で選ぶ。画像、順序、指示、回答形式、モデルと正規化を固定する。参照ラベルと保存票は採点だけに使う。

SolとOpusが別々の新規セッションで、同じ束を `high` で一度読む。保存済みの `medium` の二票と、新規の二票、Opusだけを `high` に置き換えた組、Solだけを置き換えた組を比較する。新規の読取者には旧票や出典を渡さない。区別できない符号の位置がそろった例は出典待ちとして記録する。今回は固定画像に対する推論設定の比較であり、出典で確定した監査の判定を更新しない。

この試験に含まれる行は開発で扱った行として記録する。正式監査の合否、既存の原票、製品経路および未使用資料はこの試験から分ける。

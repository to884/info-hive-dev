# 成分を先に枠で絞った保存票の再集計

v97の同じ16枠と、事前固定した150・450 DPIの画像、所属の式、成分番号、正解を使う。v98で確認済みの保存原票を両方式・両系統から各16票、計64票再検証する。既存の旧は比較のため計算して一致を確認する。評価する変更は新方式の保存票の後処理に限る。

新で同じ数字間に異なる成分が複数報告されても受け付ける。各成分の中心と枠の上下端、横方向の重なりを既存の150 DPIの式で測る。枠外の成分を除いたあと、同じ数字間に複数残ればその票は未決定。1成分だけ残ればその字形と成分を使う。0成分なら記号を付けない。同じ成分番号の重複、存在しない番号、成分の順序と配置が矛盾する票は未決定。異系統の二票は、残った成分、字形、挿入位置と数字列で一致した場合に確定する。

これまでの新方式を基準に、位置4群と全体について、正解一致、脱落、過剰転記、未決定を数える。黒い筆画の採用、そのうちコンマとしての採用、実コンマを別記号として採用した場合を別に数える。取り違えに関する注記は合成PDFの成分に基づき、読み手の心理を推定しない。枠外の候補の除外と枠内に残った候補を行別に記録する。固定画像、正式監査、条件5の合否基準と正規化は従来どおり。読み取りは保存済みの票を用いる。

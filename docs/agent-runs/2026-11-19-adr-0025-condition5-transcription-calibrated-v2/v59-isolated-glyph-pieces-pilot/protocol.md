# 同じ縦軸10行の筆画を字の近くで確認する

開発v51の縦軸10行と同じ固定画像を使う。元の全区間と枠を保ち、二つの濃さで近いインクの範囲を確かめて、周りの字がほとんど入らない450 DPIの表示を一枚加える。短い列は全体から、長い列は行頭約600画素と行末約320画素の範囲から作る。全部の字が一枚にあるとは限らない。切り出しは固定画素に基づき、正解や文字層と対応させない。

目で区別できる筆画が複数の字体に対応する字では、印を元の字の位置に返す。事前固定した一対一の対応で本文の文字へ戻す。正規化は従来のまま。分かる本文と印を一行全体で返し、元の枠への所属も画像で保つ。

別々の新規SolとOpusで、既存正解への一致、異体字と小書きの仮名、脱落、過剰転記、未決定を比較する。画像で読めない本文を元PDFで補わない。

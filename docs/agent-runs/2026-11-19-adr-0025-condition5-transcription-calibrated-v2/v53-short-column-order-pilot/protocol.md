# 横に短い枠で縦列をたどる開発比較

v47で二票が割れた官報の短い7行と、官報の縦列、白書の数字・括弧、短い横書きの一致対照5行を固定する。既定の正解、割当軸、枠と文字の所属、固定150/450 DPI、正規化は維持する。

第一案は原票の画像をそのまま使い、目印に分けず一つの全文として答える。枠をまたぐ元の文章が縦書きである場合は、列を右から左へ、各列を上から下へ読む。横書きの場合の左から右の順序と所属は従来どおり。

第二案は同じ全文の指示に、元の450 DPIを使った上下の列とのつながり、上下・左右の枠を外側の目印で示す表示を加える。非常に短い枠には90度回した同じ画素も添える。本文や字の数、既存正解は表示から推測して記入しない。

二つの案は別々の新規Sol・Opusセッションで試す。既存のv47票も合わせ、正解への一致、脱落、過剰、読み順を含む別の転記、未決定、必要な出典待ちを比較する。開発の比較のために使った新しい票は正式監査へ流用しない。

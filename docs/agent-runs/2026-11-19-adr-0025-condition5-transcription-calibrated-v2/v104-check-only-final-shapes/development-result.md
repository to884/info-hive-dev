# 最終転記に残った成分だけを字形票と照合した結果

v101で使った保存役割票と保存転記で、同じ開発5枠の最終転記を再現した。各方式で最終転記に採用された成分番号だけをv102の字形二票と照合し、v103と同じ字形の対応で不一致なら枠を未決定にした。[再集計の手順](protocol.md)・[行別の結果](comparison.json)

- Z010はv101でコンマとして確定していた成分6を、字形二票がともに短い線と記録したため保留した。
- Z001・Z003はv101の役割票で余分な筆画が外れ、最終転記に残る実コンマの字形と転記が一致した。
- Z009では、両転記票のコンマ一致を求める条件で、黒い筆画の成分6が余分として外れた。字形が食い違うのはその黒い筆画だけで、採用した実コンマは成分7。片方以上の転記票でコンマ候補とすると、v101の保留が成分6にかかり、枠はすでに未決定。検算では、両転記票のコンマ一致を求める条件でも、外れた成分6まで字形の不一致で保留するとZ009は未決定になった。
- Z015は保存字形票の点と保存転記のピリオドが一致するため、引き続き過剰転記となった。

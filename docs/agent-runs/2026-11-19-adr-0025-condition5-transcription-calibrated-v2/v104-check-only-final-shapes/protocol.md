# 最終転記に残った成分だけを字形票と照合する

v101で用いたv100の保存役割二票と新指示の保存転記で、同じ開発5枠を採点する。コンマ候補を保留するv101の2通りをそれぞれ適用して、前回の確定結果を再現する。確定した転記の成分番号だけを、v102の字形二票とv103の字形対応で照合する。両モデルが一致した字形と確定した転記が食い違う成分があれば、枠を未決定にする。v101で外れた成分や未決定の枠はこの工程の対象外。保存された字形、挿入位置や役割を補わない。

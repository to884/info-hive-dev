# 行の区画と構造化回答の開発結果

固定150 DPIと450 DPIの両方で投影上の空白があった開発10行を読み直した。前回一致した対照4行は、今回もSolとOpusの全文が既存正解と一致した。前回の未決定6行は、既存正解と一致1、本文と丸印の位置が合い出典照合が必要2、既存正解と異なる二票一致1、未決定2だった。[保存した二票の照合](../v17-ink-gap-receipt/result.json)

Opusのレビューでは、字の内部の空白を両解像度で検出してしまい、字を分割できることと、区画の余白に隣の区画や列の字が写ることが指摘された。「小」を並べた合成画像では、目標150画素に近い字の内部に境界が選ばれ、450 DPI相当の追加検査も通った。区画の転記を機械的につなぐ方式は採用しない。局所表示は全文の確認用に使う。

構造化回答の単独試験では8セッションすべてから最終回答を受領した。今回のOpusでは1回、構造化回答用の内部処理が壊れたJSONを拒否し、同じセッションで正常な最終回答を返した。拒否の記録と最後の構造化回答が一致することを保存票で確かめ、開発集計を別に作った。新規の読み取りは追加していない。

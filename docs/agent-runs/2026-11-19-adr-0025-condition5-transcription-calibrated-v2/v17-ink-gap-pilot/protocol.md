# 長い行の画素から読取表示を分ける開発試験

固定150 DPIで字のインクがない箇所を探し、同じ範囲を固定450 DPIに写す。長い行の詳細を分けるときも、枠への所属は元の枠に対して確かめる。暗い背景、空白が足りない範囲または分割点が多すぎる枠は従来の全文表示を使う。分割画像には元の行全体の表示も添える。

均等な区画試験では境界が字を横切ったため、その方式を使わない。各区画は原画像の画素から作る。復元した全文だけを既定の正規化と二票一致で比べ、区画の差は診断用に保持する。既存正解、OCR本文、ほかの票と出典を画像の読者に渡さない。診断した長い行と対照を固定してから開発の二票を取り、独立監査の結果は変更しない。

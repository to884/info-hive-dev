# 条件5の開発診断　点線の再計測

点線候補の初版を残し、Opusの指摘を反映して別版で再計測する。元の150 DPI整数箱と画像の切り出し位置を照合する。背景は既存診断と同じく測定窓の短辺だけ周囲を広げた範囲の中央値とする。小成分の縦中心の1画素差を許し、同じ列の先頭や隣接成分の混入で候補の点を取りこぼさないよう、すべての開始位置を調べる。競合する最大列があるときは競合を記録する。

既存全文との比較に限り、ピリオド、中黒、類似の点字形を1、二点リーダーを2、三点リーダーを3として、間の空白を許して物理的な点数を数える。この換算は目視診断専用で、条件5の正規化や誤りの定義には使わない。検出は既存全文を開く前に画像だけで集計し、比較では画像の候補・文字列による点数・両方の一致を区別する。

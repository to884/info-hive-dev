# 句読点に似た黒い筆画だけでのコンマ所属の追試

新しい合成PDFの2ページ・2書体から16枠を作る。全枠に黒い点または短い斜線があり、実コンマを枠内・境界上・枠外に置く各4枠と、実コンマなし4枠。各群で筆画の形2種類とコンマの想定位置に対する左右を均等に割り当てる。両解像度の差分で数字が切れずコンマの中心と下端の差が150 DPIで -1・0・+1画素、450 DPIで -3・0・+3画素であることを検査。黒い筆画の中心は各枠の内側。PDF上の描画命令を一つずつ除いた画像で、実コンマ、対照の筆画、数字を対応付ける。黒い筆画は見た目では句読点と解釈しうるため、既知の実コンマ／別の筆画という区別は合成PDFの描画に由来する。この区別や正解は読み手に教えない。

旧・新で全ての画像が同一。Sol、Opusをどちらも high、各枠・版につき別の新規セッションで読む。旧は150 DPIで所属を決めて全文を転記し、転記に使った記号だけを後置の番号で報告する。番号は旧の文字列の判定に使用しない。新は数字列と、上下の所属を判断する前に記号候補の成分番号と字形を報告する。新の二票は数字・各成分番号・字形が一致したとき、既存の所属式で枠内にあるものを確定する。同じ数字間に複数記号を指定して新の形式が成立しないときは未決定とし、報告された候補は別に記録する。

文字列から正解一致・脱落・過剰転記・未決定を集計。置換は脱落・過剰転記に両方数える。確定した文字列の出典として、黒い筆画をコンマとした、実コンマを別記号とした、黒い筆画を別記号として採用した場合を個別票・二票で別に集計。確定できた記号の成分番号が両票でそろわない場合は成分の所在を未確定とし、文字列の判定は保持する。新の処理前の候補と旧の最終採用は範囲が違うため、候補については新だけを事由として報告する。正式監査の固定画像、条件5の合否基準と正規化は従来どおり。

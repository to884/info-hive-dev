# 条件5の開発試験　点の番号を伏せて位置と本文を確かめる

前回と同じ点線4行と各PDFの点なし対照1行を使う。固定画素のカードとIDを維持し、点に番号を振った補助を、番号なしの固定150 DPIの切り出しに替える。点数・字種・元PDF・既存の票は出さない。各読み手は周囲の全文を転記し、区別できない点線の箇所に、元カードの先頭・末尾のカード番号を `⟦dotspan:P-Q⟧` と書く。少しでも点線が見える元カードを数え、切り出し補助はカード番号に含めない。画像を根拠にその行への所属を確認できる場合だけ記す。

点の物理的な個数は、固定画像を扱う二つの実装が独立に測る。手作業の二票は周囲の本文と位置・所属の確認に使い、両方式の画像計測と、別に確認した出典の物理点数を照合する。点線4行の結合候補と対照2行の全文を保存する。別々の読み手が同じ補助の数字を転記した前回の点数は、独立した読みの結果には含めない。これは方法の開発比較であり、既存の正解を変更しない。

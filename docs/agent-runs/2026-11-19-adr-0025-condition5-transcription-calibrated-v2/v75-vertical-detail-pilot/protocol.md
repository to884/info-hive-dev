# 縦列を短い連続区間で拡大して字形を確認する

v71で両方の `high` の画像票が一致しなかった縦軸の行と、一致を維持できなかった対照をすべて使う。対照をさらに6行加える。v64で画像だけの二票が既存正解と一致した縦軸の官報から、高さ120画素以下と121画素以上を各3行、固定文字列と行IDのSHA-256順で選ぶ。すべて開発用として扱う。

新しい束では、従来の「列の字形」の画像だけを、同じ固定450 DPIの短い区間を縦3倍・横3倍の最近傍で拡大した表示に置き換える。他の画像と指示は変えない。区間の上下は24画素重ね、拡大前の画素の位置と番号を枠外に表示する。すべての区間の元画素を往復で照合し、元の順序を保持する。字種、読み、区切り、文字数の候補は与えない。枠と字の所属は元の枠の画像で確かめる。画像が24枚を超える行があれば、配布前に止める。

SolとOpusは旧・新を別々の新規セッションで `high` で一度ずつ読む。二票一致、同じ誤り、脱落、過剰転記、未決定を対象行と対照で調べる。出典・正解・保存票は転記者に与えない。今の正解との不一致は行別に保存し、固定画素から検証できるかを確認するまで正解を訂正しない。

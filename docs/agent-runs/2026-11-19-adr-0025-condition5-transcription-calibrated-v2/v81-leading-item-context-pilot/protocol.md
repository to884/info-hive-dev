# 行頭の丸と本文中の点を周囲の固定画素で区別する

保存済みの開発画像の二票で、行頭の塗り丸と本文の読みが割れた行、または行頭の小点として位置を報告した行を三つ使う。対照はv64で一致した横軸の資料から、画像だけで確定した項目丸1行、出典で確定した先頭の曖昧な小点1行（固定画像を上限内で配布できる候補は各1行だった）、先頭が記号でない2行を固定文字列と行IDの順で選ぶ。

新指示に、元の行の周囲の上下と左右を見て、同じ大きさや位置に繰り返す項目の丸を確認するための固定150 DPIの表示を加える。画像の元の150・450 DPI・枠・正規化・既存の符号の扱いを保持する。出典と本文の他の読取は扱わない。小点の形で字種が分からないときは、既定どおり両票の座標を記録する。枠外の周囲の文字や図形は追加しない。

SolとOpusを `high` に固定し、旧・新を別々の新規セッションで読む。一致、不一致、脱落、過剰転記、未決定と出典待ちの数を記録する。出典で確定した対照は、小点の座標が両票でそろった場合も、保存された出典とそろうかを別に調べる。正式の判定・数値・標本は更新しない。

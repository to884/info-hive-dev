# v14と同じ画像による配送障害後の独立監査

v14はSolの起動に渡した相対パスが一時作業フォルダーから解決できず、固定画像を配送できなかった。Opusの受領済みと着手済みの原票も障害の記録としてv14に保持する。v14で質を判断できる両票はなく、この監査は通過していない。

v15は配送だけを改訂した新しい版とする。正解、予測、層別の標本379行、束の指定、配布画素、読取指示と判定方法をv14と同一にする。標本の抽出をやり直さない。両系統を新規セッションにし、v14の票は使用しない。受領時に他の版のセッションが混ざっていないことを確認する。

起動前に配送フォルダーと全画像を絶対パスで解決し、期待するハッシュに一致するPNGを渡す。開発画像に書いた短い文字列を、同じ起動・受領の経路で両系統が独立に読めることを先に確かめる。起動後に添付画像の読み込みエラーが記録された束は、応答があっても技術上の参照不足とする。中断時は着手記録のない組だけを再開する。数値の合否、出典の範囲と最終条件はv14のまま。

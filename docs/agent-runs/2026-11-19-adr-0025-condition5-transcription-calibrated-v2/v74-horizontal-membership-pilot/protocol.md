# 横軸の枠で色付きの字と隣接する本文の所属を確認する

v71で両方の `high` の画像票が一致しなかったか、同じ字を脱落した横軸の既知標本を使う。列順の7行と出典待ちは別試験で扱い、ここでは除く。対照はv64で画像二票が既存正解と一致した横軸の枠から、幅120画素以下と121画素以上を各3行、固定文字列と行IDによるSHA-256順で選ぶ。両方とも開発用とする。

両版で固定画像・添付順・モデル・回答形式を統一する。新指示は色付きの字や参照、振り仮名、句読点でも、実際に見える字は同じ枠内の長さと直交方向の中心で判定することを強調する。凡例などの図形の除外、曖昧な点の位置、合否の規則は共通。半分の判定は字を単位とし、色や語の意味で枠の外の文字を加えない。SolとOpusは旧・新を別々の新規セッションで `high` で一度ずつ読む。脱落と過剰転記が対照を含めて増えたかを確認する。

防災資料19行目では、既存の転記の枠末尾に色付きの一字がある。固定画像で色の異なる輪郭の横幅を測ると、枠内は150 DPIで63〜64%、450 DPIで約65%、上下の中心は枠内だった。次の色付きの字は枠外。これは対象を選ぶ前の開発診断で、転記者には字や色の例を渡さない。元PDFの本文は参照していない。

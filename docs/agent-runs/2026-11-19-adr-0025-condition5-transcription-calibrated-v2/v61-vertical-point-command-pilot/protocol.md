# 縦組の丸印と実際に点を描く命令の照合

v47の官報117行目を開発用に使う。二系統の画像票は小点を同じ位置に記録し、固定450 DPIの二つの濃さで同じ点を一つ確認できた。既存の出典照合で参照不足のままにした。この試験の証跡はv47の原票、正式集計と別に保存する。

実際の点の画素を描いた埋め込みフォントを、固定150 DPIの隔離再描画から特定する。元PDFのページで同じフォントの垂直方向の設定とCIDを確かめる。対象はAdobe-Japan1を宣言する、埋め込み済みの縦組フォントの中黒で、固定の二票が符号を区別できなかった箇所に限定する。

同じページからメモリに複製したPDFで、CIDを含む候補の命令のうち一つの字だけを組版したまま非表示にする。変更前の複製を固定150 DPIと比べて全画素が一致し、一つの命令だけが二票の点の画素を消し、窓外の画素に影響しないことを求める。別の位置の同じCIDは対照とする。対象外の黒い項目丸でこの証拠が採用されないことも確かめる。

元PDF、固定画像、本文、採点、出典の許可範囲はそのまま。本文の文字の確認にこの方法を使わない。

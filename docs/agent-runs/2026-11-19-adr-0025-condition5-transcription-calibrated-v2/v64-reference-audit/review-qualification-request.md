# 正式監査の入口に進む前の敵対的レビュー

条件5の数値基準、既知標本の不一致0・参照不足0、同じ固定150・450 DPI、領域と画像補充の母集団・層、所属と正規化、各系統が一行一度だけ画像を読むことを維持する。読み取りの結果が割れた行は未決定とする。画像では区別不能な承認済みの点線と小点だけ、位置と周辺本文の二票一致の後に元PDFを確認する。

最初のレビューで指摘された字体の例と事前固定に対応した。従来／中立の開発用32行は一致30、出典待ち1、脱落判定1で同じ。表示で改善したとの主張はしない。脱落判定の一件は固定画素の枠内率が半分未満で、四つの独立票が当該の一字を省いた。中立指示で二票が割れた官報164行目は訂正候補から外した。新たに選んだ官報120行目の小点の出典も別の描画命令で確認した。

正式抽出の前に、`launch.py`、`preflight.py`、`capacity.py`、`source.py` が以下を実際の経路で守るか確かめてほしい。前のレビューで挙がった重大な点の解消と、新しい正解の一件の根拠を優先する。

- 事前検査で実行する表示と本番の表示が同じ関数と固定値に結び付く。後から変えた方法、素材、配布、正解、出典を検出する。以前の監査・開発票を改変・再利用しない。
- 必須画像、座標、横枠の端、枠の所属が被覆され、全母集団の寸法に対して24枚の上限を守る。開発の最大枠を使った検査が、形式だけの検査に終わらない。
- 新経路の丸印の検証は、よく似た位置・符号や正解の後付けを受け入れない。異常と証拠不足を区別し、符号補助の適用範囲を守る。
- 母集団の固定、抽出、配布、原票の確定、出典の照合、三値判定の順序と、誤差や不足を不利に扱う既定の基準が保たれる。

正式な抽出や既存の結果変更はしていない。レビューも読み取り専用とし、抽出・配布やファイルの変更は行わない。見つけた欠陥は該当コード、起こり得る例、必要な最小の再検査で記述してほしい。

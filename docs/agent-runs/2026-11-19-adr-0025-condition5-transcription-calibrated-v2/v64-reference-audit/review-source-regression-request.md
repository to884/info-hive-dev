# 出典不足の回帰修正の敵対的レビュー

前回の再レビューの Major 1件に絞る。前回確認済みの固定、母集団、画像配布の設計を再評価する必要はない。

source.py の mark_from_source が出典不足と整合性異常を区別するか、preflight.py の replay_archived_marks が前回の実例を拾っているかを読む。符号対応と来歴が異なる場合、誤って採用する経路がないか、例外と証拠不足の診断情報が結果に結び付くかを確認する。新しい正式標本の抽出、モデル読み取り、ファイル編集は行わない。回帰検査はCodex側でも実行中なので、レビューでは該当する関数の読取と静的な反証を優先し、前回のMajorが解消したか明記する。

# 固定画像の表示と小点の出典を検証する独立監査

領域正解と画像補充正解の既知標本で、不一致と参照不足をそれぞれ0にする。画像補充の未決定層は別に集計する。もとの固定150・450 DPI、枠と字の所属、正規化、領域と画像補充の層、モデルの採点、既定の数値基準を維持する。既存監査の標本と二票は再利用せず、抽出された場合は既存の開発・監査との重なりを記録する。

一行一束の同じ画像と指示を別々の新規Sol・Opusセッションへ送り、既存の台帳で原票を保存する。両モデルに出典、既存正解、既存票、主OCR、印は渡さない。v67の中立化した表示を使う。表示の切替は枠の寸法と画素に従い、行の両端の450 DPIの細部を保持する。添付の画素寸法、省いた任意の補助画像を記録する。開発で用いた字体例を本文の指示に加えない。

既存の点線と丸印の補助証拠を維持する。二票の本文・形・位置の一致後、一つの曖昧な小点が他の方法では確定しない場合は、固定画素と同一のPDFに描かれた縦方向の中黒を確認する。対応するフォントの宣言と固定した150・450 DPIを確認し、該当する描画命令一つの非表示で、その位置だけの画素が消える場合に限る。本文、別種の符号、未決定の画像票には使わない。

開発の確認とOpusのレビューを記録してから、手順・画像補充正解の候補v70・固定予測・母集団を固定する。v70は枠端の所属を固定画素と中立化した新規票で訂正した一件をv38に加える。領域の抽出種は2026112009、画像補充は2026112010とする。正式な抽出は固定後に一度だけ行う。正式監査の結果が条件を満たした後、固定モデルの製品経路と未使用の公開・合成資料を従来どおり確認する。

# 成分の形と数字との位置を別々に確かめる

開発画像で過剰転記が残ったZ010・Z015と、前回の転記二票一致の保留条件で実コンマを正しく確定したZ001・Z003・Z009を選ぶ。Z009は前回の片方以上の保留条件では未決定だった。各枠につきSolとOpusを high の別々の新規セッションで1回ずつ呼ぶ。同じ固定画像3枚と、保存票のうち枠に残った成分の番号だけを渡す。正解、役割の真値、過去の出力、選定理由は渡さない。一つのセッションには一枠だけを渡す。

各成分の輪郭、前後の数字との高さ・間隔、役割を順に記録する。輪郭と位置は判断の根拠の記録に用いる。新規の役割二票一致を採用し、不一致、判別不能、形式不備は未決定として扱う。両方が余分とした成分は外し、前回と同じ条件で保存転記のコンマ候補なら未決定を優先する。片方以上と両方の保留条件をそれぞれ適用する。保存済みの数字列、字種、挿入位置、成分番号と枠判定を引き継ぐ。対象外の11枠は前回の集計を引き継ぐ。

この5枠は既存の過剰転記と正解を見て選んだ診断用の例である。正式監査の画像、正規化と合否基準は従来どおり。

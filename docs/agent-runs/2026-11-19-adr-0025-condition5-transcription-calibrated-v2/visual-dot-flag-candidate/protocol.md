# 条件5の開発試験　画像とOCRの点数を比較する特徴

仮転記184行の感度分析を先に固定した。防衛白書では仮転記との差89行中88行、災害資料では55行中50行で、OCRが出した点線の物理点数が画像と異なった。出典を判定器へ渡さず、固定150 DPIの画像と主OCRの本文から、点線の有無・物理点数・点数差を表す特徴を1候補だけに追加する。所属軸yと測定できない場合は、特徴に判定対象外として記録する。画像だけで区別できない符号を点数から決めない。

元の276特徴、同じ木の設定・種、出版物単位の42分割、閾値0.15、固定採点器を使う。元の固定教師での開発結果と、仮転記による感度分析を区別する。本試験では仮転記の教師で学習した場合を、同じ仮転記・同じ設定で元の特徴だけを使った再学習と比べる。新しい公式正解と独立検証を使った結果がそろう前に、製品の既定には適用しない。

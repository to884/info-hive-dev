# 紙面に行・列のつながりがある対照で列順の副作用を確かめる

v79の合成対照は、生成時に横書きとして置いた二字の周りにも縦に並ぶ字があり、元の横書きの行が画素から分かりにくかった。v82では、新しく生成する横書き6行の枠を連続する横書きの行へ置く。3行は罫線で仕切った横書きの表。3行は縦書きの列の中の横長の見出し。縦書きの対照4行には二列のそれぞれに上下の文を配置し、位置のずれを保つ。枠と描画位置だけから正しい文字と順を決める。

旧・新で同じ固定150・450 DPIを使い、v79と同じ列順の段落だけを切り替える。Sol・Opusは `high` で各版を別々の新規セッションで2回ずつ読む。横書き6行の24組で二票一致の逆順・別の誤り・脱落・過剰転記・未決定を比べる。新しい指示で誤った一致または未決定が増えた場合は一律に採用しない。合成で効果が見えても、これだけで公刊資料の合否を判断しない。

# 二票で位置がそろった符号の描画の種類を調べる

開発v71で本文と曖昧な小点の位置が二票でそろい、既存の許可済み出典経路では確定しなかった三行に限る。固定450 DPIで背景より濃い点と明るい点を別々に調べる。二つの閾値で同じ位置に一つの成分が得られなければ保留。固定150 DPIと元PDFの通常描画が同じ場合だけ、その点を含む範囲で文字の描画をすべて非表示にした結果を比べる。

ページの描画はメモリ内だけで切り替える。文字列、他の字種、OCR、既存の正解は補助証拠に使わない。色や図形だけで符号を決めない。文字以外の描画で点が残るときは、その位置を覆う画像・図形を一つずつ非表示にして差分の種類を記録する。ここでは描画の来歴の診断までを行い、符号の確定や正式監査の採点を更新しない。

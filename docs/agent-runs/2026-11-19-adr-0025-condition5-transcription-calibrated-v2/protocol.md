# 記号の取り違えを分離した旧指示の較正と比較

[初回設計](../2026-11-19-adr-0025-condition5-transcription-calibrated/report.md)では枠外の同種記号が脱落を相殺できた。初回の較正と転記は採用しない。新しい本文・配置の乱数種・IDを固定して較正からやり直す。条件5の合否基準と正式評価は既定のまま。

- 細い閉じ丸括弧と書体を全難度で共通にし、0、1、2、2個の4行を各原稿に置く。二連続の行では枠外の記号を正規化後も異なる字種にして、枠外を足しても脱落が隠れないようにする。句点は全原稿で枠内幅1/3。縦列の3行も同じ構成を使う。第三読の担当は全原稿・全群でAstraの新規セッションとする。難度は局所のにじみと前景濃度で変える。450 DPIで弱めた字の濃い8画素の信号が紙のむらの想定標準偏差の3倍以上になることを生成時に検査する。合成字形と画面上での判読の可否は別に扱う。
- 較正は旧指示だけで難度1〜4を各8行。正規化後に一致する既知の二票を採用し、必要時に第三読を行う。二連続の行で最終的な脱落が1行以上、最終未決定が1行以上、全文正解が2行以上のすべてを満たす最低の設定を選ぶ。通過しなければ、本文・配置・IDが異なる予備較正で難度3〜6を一度だけ測る。いずれも通過しなければ判定不能とする。
- 採用した設定で、較正用と本文・画像・IDが重ならない4原稿32行を新規生成して固定する。Sol・Astraが各群で独立に読み、必要時だけ第三読する。最初の二読は旧・新に同じ16画像を同じ順で渡す。150 DPIの所属、450 DPIでの字形確認、正規化、転記形式を両群で共用し、新指示に「提出前に連続記号の位置と個数を見直す。」だけを加える。
- 未決定と確定状態の遷移は全行、脱落・過剰・全文一致は双方が確定した同じ行を主に比較する。各群の全行、原稿、失敗型、初回モデル別の集計も示す。較正画像は比較に用いない。難度の選定は少数標本によるため、本文やモデルを越える効果は推定しない。

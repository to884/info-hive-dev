# 数値の読みと小さい記号の所属を分けた開発試験

v88の開発用の六枠（コンマの中心が下端の内、上、外に各二枠）と、v86の実資料の対照六行を使う。固定150・450 DPIの拡大図と、150 DPIの横座標を画素の外に示した図を両版に同じ順で添付する。元の文字画素と正式枠は変更しない。二系統とも `high`、一枠一版をそれぞれ新規の独立セッションで読む。旧はv86の境界上を含む説明で全文を転記する。新は数字の順列、記号ごとの字形、直前までの数字の個数、横位置を報告する。枠内かどうかは指示で答えさせない。

小さい連結成分を固定150 DPIから検出。元の計測のコントラストと8近傍を使用し、対象の高さや枠との位置で小さい成分を選ぶ。各票が報告した点から横方向3画素以内に候補が一つだけあり、両票で記号、挿入箇所と物理成分が一致した場合に、既存の所属式で中心が上下の境界内または境界上か、横の筆画が半分以上入るかを判定する。記号の報告が割れたり、成分が重なったりすれば未決定。付近の全成分から字種を自動で推定しない。対照にない曖昧な字形、他の組版、文字行への一般化を判断しない。公式の指示を変更せず、正解や元PDFの命令を読取側へ渡さない。

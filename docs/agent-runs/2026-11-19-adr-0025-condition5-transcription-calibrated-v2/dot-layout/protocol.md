# 条件5の開発診断　点線の物理的な位置と個数

長い横行の区画比較で割れた2行をもとに、固定150 DPI枠なし画像で、一定の高さと間隔で並ぶ小さな独立インク成分を抽出する。位置は保存済み画像の整数座標から取る。背景との差64超、8連結、固定の所属軸と直交中心の扱いは既存の画像診断を流用する。幅・高さ2〜5画素、4画素以上の成分が、同じ上端・高さで3〜13画素間隔、差の振れが1画素以内で3個以上並ぶ場合を点線候補とする。規則は先の2行の観察を使った開発用のもので、実データでの検証を要する。

正式な正解や他の票、OCR本文、印、正誤、スコアを検出処理に使わず、v9画像補充の横軸全行に同じ規則を適用する。既存確定行では、独立に得た成分数を保存済みの点線文字数と照合し、過剰候補や不一致を記録する。未決定行では、調べられる候補件数と成分位置だけを数える。成分が同じなら同一Unicodeだとは扱わず、正解ラベルと条件5の正式採点を維持する。

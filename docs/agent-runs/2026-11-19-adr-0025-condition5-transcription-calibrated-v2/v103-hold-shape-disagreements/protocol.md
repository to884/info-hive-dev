# 字形二票と保存転記が食い違う成分を保留する

v102の固定5枠、保存された字形票10票と新指示の保存転記を使う。固定の枠判定で残った同一成分番号を照合する。両モデルの字形が一致し、頭と尾はコンマ、点はピリオド、短い線は横線または斜線のいずれかという対応に反する転記が片方以上にあれば、その成分の役割を未決定に置き換える。字形の不一致・不明・その他の一致は、この保留を発動しない。字形は確定した転記を止めるときだけ使い、数字列・記号・位置を置き換えない。持ち越す役割はv102の二票一致。不明や不一致による既存の保留、v101の2通りのコンマ候補保留、同じ採点を適用する。正解は採点にだけ使う。新規画像読取は0件。正式監査の固定画像と条件5の合否基準は従来どおり。

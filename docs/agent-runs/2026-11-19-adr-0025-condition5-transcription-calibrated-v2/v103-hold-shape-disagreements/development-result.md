# 字形二票と保存転記が食い違う成分を保留した再集計

v102の同じ5枠の保存字形票10票と新指示の保存転記を用いた。枠判定を通った同じ成分番号について、Sol・Opusの一致した字形と、いずれかの保存転記が食い違ったときは、その成分を未決定にした。頭と尾はコンマ、点はピリオド、短い線は横線・斜線として照合した。数字列と記号の転記は置き換えず、従来の2通りのコンマ候補保留を適用した。以下は両方式共通の結果。[手順](protocol.md)・[行別の照合と集計](comparison.json)

| 枠 | 字形と保存転記の照合 | 前回 → 今回 |
|---|---|---|
| Z010 | 二票とも短い線、保存転記二票ともコンマ | コンマの過剰転記 → 未決定 |
| Z015 | 二票とも点、保存転記二票ともピリオド | ピリオドの過剰転記 → 過剰転記 |
| Z001 | 実コンマも黒い筆画も、字形一致と保存転記の食い違いは0件 | 未決定 → 未決定 |
| Z003 | 実コンマも黒い筆画も、字形一致と保存転記の食い違いは0件 | 未決定 → 未決定 |
| Z009 | 黒い筆画は二票とも短い線、Opusの保存転記はコンマ。実コンマの字形と転記は一致 | 未決定 → 未決定 |

5枠全体の過剰転記は2→1、未決定は3→4、脱落は0→0、正解は0→0。Z010は過剰転記の確定を止められたが、枠の転記自体は未決定。Z015では字形が一致し、黒い筆画を区切りとした前回の判定が残った。実コンマ3枠は元から役割判定により未決定で、いずれも同じ結果。対象外11枠を引き継いだ16枠では、過剰転記2→1、未決定13→14、脱落0→0、正解1→1。

前回の保存票を再解釈し、前回の各枠の転記と採点が同じ経路で再現することを確認してから保留を適用した。画像の新規読み取りは0件。正式監査の添付4,482枚と台帳、開発用の固定画像をハッシュで再照合した。条件5の合否基準は従来どおり。


Opusの限定レビューを受け、既存の成分だけを保留し、食い違いのある枠が前回の両保留条件で未決定になることを採点時に検査した。再実行した集計は保存済みの結果とバイト単位で一致した。[レビュー](review-opus.md)

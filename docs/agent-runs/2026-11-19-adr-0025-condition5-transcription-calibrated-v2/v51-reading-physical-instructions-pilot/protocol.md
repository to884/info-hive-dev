# 小書き仮名・行頭の輪・枠をまたぐ横画の指示を分ける開発比較

v50と同じ16行の固定画像、枠端表示、回転、列の拡大、添付順、回答形式を保つ。v50の保存票と比較する。新しいSolとOpusのセッションに渡す画像はv50と同じバイト列とし、指示に加えた差を開発用として確認する。

横軸では横書きの小さい句点を、本文の高さに近い行頭の輪と区別する。上下の二本の線が一字の画であれば、枠の中にある片方を一字として追加せず、字全体の中心を確かめる。縦軸では小書きと普通の仮名を同じ列の大きさと位置で比べ、隣の画を漢字の部品に取り込まない。既存正解や他の読取結果は画像担当へ渡さない。

既存正解との一致、脱落、過剰、別字、未決定、許可範囲の出典待ちを行ごとに比べる。条件5の固定画像、所属、正規化と合否基準は従来どおり。開発中の票は正式監査に使わない。

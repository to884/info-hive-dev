# 丸印の符号を訂正した正解案の開発結果

v15で画像補充の本文に丸印があることを二票が同じ位置に記録した防衛白書1行を、元PDFの描画を切り分けて確かめた。丸印を描く塗りと輪郭の命令だけを残すと固定150 DPIの該当窓が再現され、他の命令を残しても窓にインクはなかった。描画に使った埋め込みフォントのCID 638はU+30FBだった。以前の正解が書いていた黒丸を中黒に訂正した。周囲の本文、枠、正規化と評価行は維持した。[出典の証跡](../v18-point-source-pilot/result.json)

v14の官報1行の末尾訂正を保持し、この防衛白書1行だけに符号の訂正を加えた。固定予測と閾値0.15で開発6組・公開3組の追加条件をすべて通過した。配置数は180・540,672・199,584。[採点結果](result.json)

枠への入り方を示す画素目盛りの試験では、v15で余分に転記した官報2行がともに既存正解に一致した。丸印で割れた6行のうち5行が一致した。短い枠で割れた2行は1行一致・1行未決定。対照4行のうち3行が一致し、1行は新たに丸印の出典照合の対象になった。レビューで二種類の目盛りの単位を明示することを指摘され、次の監査の説明に反映した。[表示と指示の試験](../v18-frame-and-points-pilot/result.json)

正解作成で使った方法とは別に、PDFiumでページ内の文字オブジェクトの描画だけを切り分け、元の固定画素との一致、フォントの埋め込みデータのSHA-256とToUnicodeのCID対応を照合した。防衛白書の訂正対象と、防災白書の行中の丸印で中黒を再現した。この方法を丸印の監査の補助証拠に使う。

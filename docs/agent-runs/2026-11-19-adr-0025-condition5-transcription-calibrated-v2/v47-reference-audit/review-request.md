# 枠端と小点の差分の敵対的レビュー

読み取り専用で、v27の承認済み配送・採点手順を使うv47の差分をレビューしてください。新しい画像読取、正式の抽出、製品経路、未使用資料を開く必要はありません。

- v47の実行入口は、既存のv27の入力、台帳、結果を書き換えず、新しい固定と原票だけを使うか。SHAの継承に穴がないか。正式の二回目の抽出、旧票の流用、合否の数値の変更が入り得る経路を優先する。
- 枠端の表示は固定150/450 DPIの範囲、割当軸、直交中心と配置を保つか。成分の全幅と字全体を混同させる条件、位置の表示の縮小、24枚の上限で必要な添付が落ちる反例を探す。
- 450 DPIを用いた小点の選定は、二票の同じ場所、二つの濃さの一意な候補、対応する150 DPIの元PDFの隔離描画、許可された符号をすべて必要とするか。異なる点や他の文字が補われたり、PNGとPDFの来歴が食い違っても通ったりする例を優先する。

指摘は対象、再現、重大度、修正の方向性を短く記録してください。

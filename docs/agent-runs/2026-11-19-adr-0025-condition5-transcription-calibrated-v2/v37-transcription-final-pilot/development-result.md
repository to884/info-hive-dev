# 次の監査に使う横書きの開発比較

同じ19行で新しいSol・Opusの構造化票を全件受領した。最初の出典照合までで15行が既存正解と一致、3行が二票不一致、1行が出典の位置証明不足だった。位置証明不足の1行は丸印の横に別の字の小さな筆画があった。二票からどちらも3画素以内にある唯一の候補を、二つの濃淡閾値と隔離描画で確かめ、許可された中黒だと確認した。点列も元の描画で同じ符号と分かり、全文が既存正解と一致した。二つの候補の中間を指す対照は保留した。[二票の判定](source-comparison.json)・[丸印の追加確認](narrow-round-comparison.json)

この開発比較は16行一致、3行未決定、二票一致の脱落・過剰転記0行。未決定は、表の先頭の四角を片方だけが写した行、小点の座標差が11画素の行、異体字一字が割れた行。凡例の丸・四角と本文の記号の区別を明示すると、旧の統合指示で図表の見本を出した行が一致した。

横座標は固定150 DPIの画素をそのまま広げ、5画素目盛りに10画素ごとの数値を付ける。不一致を解消したのは開発の特定ケースであり、正式の独立監査は新しい二票を受けて判定する。[横座標だけを変えた試験](../v35-coordinate-pilot/source-comparison.json)

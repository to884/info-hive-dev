# 区画を回答に使わない固定画像の開発試験

対象は直前の試験の15行と、文字命令または画像から描かれる丸印の診断3行。配布するものは固定150/450 DPIの画素、枠、匿名IDと一般の転記指示。既存の票・文字列・原PDFは読者に渡さず、新規のSolとOpusが独立に読む。以前の二票と正式判定はそのまま保持する。

- 短い横軸の枠は、同じ字形の細部を残した上で列の目印と広い周囲を添える。枠外の字を読む順に入れない。判定の前に、各字全体の上下の中心と左右の入り方を確認する。
- 縦軸の枠は、区画ごとの入力を廃止する。枠あり・なしの450 DPIと、固定150 DPIで行頭と行末の隣列まで含む表示から、一つの行の全文を返す。隣の列の意味は書字方向を確認するために使い、字種・所属と記号の数はそれぞれ対象列の画だけで判断する。単独の円もインクを確認する。
- その他の横軸の枠は、枠あり・なしの細部から筆画と記号を確かめる。800画素を超える枠の追加細部は行頭と行末を示し、全文は従来の表示で確認する。本文中で小さくて字種を区別できない点も位置を記録する。字形で黒丸と区別できるものは普通に転記し、図形は除く。丸印に必要な出典は開発の読者とは別に照合する。

判定は既定の正規化で全文を比較する。短い横軸の枠では、区画と縦横の向きの一致も補足で記録する。別の表示と指示を組み合わせる試験であり、効果を要素ごとに分けない。

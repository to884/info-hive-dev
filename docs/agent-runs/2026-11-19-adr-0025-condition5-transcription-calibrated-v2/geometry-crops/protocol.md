# 条件5の開発試験　対象行の切り出し

縦列・境界句点の比較で使った16行に対し、同じ所属確認の指示を使う。原画像16枚を出す群と、同じ画像の対象行を行ごとに切り出して並べ直した16枚を出す群を比較する。画像タイトル、ID、所属軸、枠、前後の画素は元の画像からそのまま移す。切り出す行の位置は版管理済みの画像生成器の行位置と対象IDで決める。文字列・正答・個々の文字の矩形を切り出しに使わない。

各群でSolとOpusの新規セッションを1回ずつ使う。採点は異系統で一致した全文とモデル別の票について、縦列12行、境界句点4行を別々に行う。前試験の進行基準を使い、縦列の全行未決定が動くか確かめる。固定の150 DPIと450 DPIの元画像と正式な条件5は変更しない。切り出しで効果を認めた場合も、別の開発画像で再現性と枠の内外にある字の誤割当を確かめる。

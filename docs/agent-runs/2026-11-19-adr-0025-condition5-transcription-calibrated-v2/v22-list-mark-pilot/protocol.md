# 箇条書きの記号と図表の図形を区別する開発試験

情報通信白書の公開開発資料で、固定画像の枠に全幅が入る箇条書きの矢じりを二票とも落とした。既知の矢じり4行、黒四角の箇条書き1行、色の凡例と通常の本文の対照各1行を使う。従来指示・補足指示の両方で同じ画像を用い、SolとOpusを別々の新規セッションで起動する。本文と図形の所在は答えに示さない。

補足指示は、箇条書きの行頭で他の行と揃う記号を、図表の凡例見本や装飾とは区別する。記号の形と、既定の枠への所属を確認する。表示にある記号の脱落、図形を足した過剰転記、その他の相違と未決定を別に数える。矢印と黒四角の符号を確かめるために元PDFの文字層を使わない。固定画素、正規化、採点と独立監査の合否は維持する。

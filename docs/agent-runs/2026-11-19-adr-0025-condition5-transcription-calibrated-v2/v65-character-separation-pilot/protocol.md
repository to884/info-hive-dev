# 同じ画像で一字ずつ確認する転記の開発比較

開発v62で二票が割れた7行と対照6行を、連続区間の追試と同じ選び方で使う。比較する画像、添付順、枠、枠への所属、モデルと推論設定は、v62の保存済みの依頼と同じ。SolとOpusがそれぞれ別の新規セッションで読む。旧の票や正解は渡さない。

今回は本文を一字ずつ空白で区切って返す指示だけを加える。形を確認する段階と文字列の出力を結び付ける狙いがある。曖昧な丸印と点列の印は空白を入れず一つとして扱う。採点前に空白を取り除く既存正規化を保持する。通常の形式で返った票も既存の手順で採点する。二票の一致、同じ誤り、未決定、脱落、過剰転記を比較し、印の位置を二票で確認できた場合は出典照合待ちと記録する。正式な監査から切り離す。

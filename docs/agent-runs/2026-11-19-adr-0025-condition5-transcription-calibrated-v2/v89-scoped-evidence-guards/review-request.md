# 監査原票と二つの固定証拠を結合する追加検査の再レビュー

v85への指摘を受けて追加したv89の対象は、過去の監査の原票で行う事前検査だけ。公開の未使用データや正式な標本には触らない。条件5のしきい値、正規化、固定した正式画像を維持する。判定の再計算は3行だけ。その他376行は保存判定を集計する。詳細は protocol.md と replay-result.json を確認してほしい。

重点は、元の二票と枠以外で答えが確定する反例、区画・画像構成・記号の個数・白点の本文内の位置を変えた場合の保留、最初の承認の来歴と追補の分離、正式なパスに組むときに残る依存関係。各関数の利用に必要な前提も指摘してほしい。ファイルを編集しない。別モデルの読取は行わない。

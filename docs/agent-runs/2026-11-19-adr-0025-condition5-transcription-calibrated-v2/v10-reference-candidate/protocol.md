# 次版の正解候補の固定

正解候補は、全公開の生の領域正解と有効な画像正解を別に保存する。固定の行、所属軸、主OCRと正規化を維持する。旧版の画像補充の未決定のうち、固定した開発試験で全文の二票がそろい、必要な点線の出典が裏付けられたものを記録する。旧監査で脱落が確かめられた閉じ括弧は、別の画像二読で全文が合った行を訂正して記録する。

点線を含む行の開発試験には、画像の点線の位置から切り出した補助がある。両者へ見せたのは原画の切り出しと位置であり、独立計測が返す個数や符号は出していない。次の独立監査では固定枠に基づく同一規則で原画を切り出し、正解の生成時の補助画像、票、出典抽出結果を引き継がない。

ここで固定するのは監査にかける正解候補。既存の領域正解の母集団と画像正解の母集団を維持し、有効正解の既知・未知の移動を主OCRの正誤と公開の組ごとに記録する。凍結した候補の数値、開発で確認した行を含む範囲、固定予測を確かめてから、別工程で層と標本を確定する。

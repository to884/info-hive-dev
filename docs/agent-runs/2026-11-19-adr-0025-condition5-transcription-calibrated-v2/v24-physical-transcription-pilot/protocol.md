# 点列と枠の二読の開発比較

確定済みv19と公開開発資料から、座標の食い違い、点列を個別の丸と記録した差、単独の中黒、枠端の句読点、短い枠と縦列の筆画を選んだ。過剰転記2行、末尾を訂正した短い1行、普通の本文1行を対照に入れた。比較は20行。資料は公開の開発用に限る。

同じ固定150/450 DPIとそこから作った同じ画像を、旧指示と追記した指示で新規のSolとOpusへ配る。各行と各指示について各系統一度読む。判読不能や転記差を再送しない。利用上限で画像読取が始まる前に拒否された証跡がある場合だけ、解除後に同じ依頼を再送する。本文、正解、他者の原票、元PDFは読み手に渡さない。

判定では既存の正規化と二系統の一致を維持する。既存の確定文との一致、脱落、過剰、異なる字、参照不足を行ごとに記録する。両票で点の位置が一致した行だけ出典確認の候補とする。旧監査集計と独立標本は変更しない。

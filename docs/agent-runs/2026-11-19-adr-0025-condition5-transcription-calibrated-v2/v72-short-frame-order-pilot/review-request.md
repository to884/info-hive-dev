# 短い横枠の列順の改善を開発手順としてレビューする

条件5の数値、枠への所属、元の固定画素、異系統の独立した二票、元PDFの補助証拠の制限は維持する。既存の7行と対照8行では同じ画像の指示段落だけを変え、両版を別々の新規セッションで読む。次の未使用開発18行も事前固定した。読取は別の処理で進行中。

縦書き列に誘導して通常の横書きを逆転させないか、短い枠の読み順と枠の所属を取り違えないか、出典・既存票・既存正解が読取入力に入らないか、旧・新の添付・指示の差が意図したとおりか、未使用開発行の除外集合に具体的な漏れがないかを調べる。別々の新規セッションを十分に検証するかと、二票が同じ誤りをする場合の対照の限界も確認する。候補を正式監査に入れるために必要な修正や事前確認を具体的に示す。ファイル編集、正式標本の抽出、追加の読取は行わない。

# 固定画像で短い枠の列順の指示を比較する

v64の既知正解で列順が割れた7行をすべて含める。v64で画像だけの二票が既存正解に一致し、枠が横軸・短枠・レイアウト付きである行から、官報4行と他資料4行を固定文字列と行IDのSHA-256順で事前に選ぶ。どの行も開発上の扱いとする。

両版で同じ固定150・450 DPIの添付、順序、回答形式、所属と符号の規則を用いる。新指示では、転記の前に「行と列のつながり」で実際の行・列を判定することと、枠が縦列を横切る場合は二文字でも右の列から読むことを明示する。旧指示の列順の段落だけを置き換える。対象行の正解・旧票・資料名・元PDFの文字情報を読取者に渡さない。

SolとOpusは全行をそれぞれ旧・新の独立した新規セッションで、両版とも `high` で読む。正解、不一致、脱落、過剰転記、未決定、出典待ちを別々に数える。既知の7行と資料群ごとの対照を分け、順序だけが違う場合も行別に確認する。今回の比較から正式の合否や既存の参照を変更しない。

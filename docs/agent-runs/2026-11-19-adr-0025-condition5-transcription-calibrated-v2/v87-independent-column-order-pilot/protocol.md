# 読む方向と位置順の転記を個別に記録する

v72の列順7行と対照8行、v82で横線や前後の横書きが明瞭だった合成対照6行を使う。どの行も既存画像、添付順、回答のJSON、固定枠と文字の所属は共通。旧の指示はv72・v82の保存済みの旧版。新しい指示は、画像で判定した横書き・縦書き・単字の区分と、左から並べた字または列を別の項目として記録させる。各縦列の中は上から下。列の中身、区分ともに読み手が画像から決める。縦列から通常の右から左の順に連結するのは、両系統の区分と各列の転記がすべて合った後。判読不能や構造不一致は参照不足として保持する。許可された曖昧な符号の照合はこの試験に含めない。

SolとOpusは `high` で各行1回ずつ、各版独立の新規セッションで読む。旧・新を併せて採点し、既知7行の一致を増やし、対照14行で同じ誤り・脱落・過剰転記・参照不足を増やさないことを開発の条件とする。固定済みの正式監査で使った本文、過去の票、元PDF、判定結果は入力に含めない。この開発の結果から、条件5の数値基準や正式監査の判定は更新しない。

# 条件5の開発試験　周囲のOCR枠の向き

短い横向きの枠が、縦書きの列をまたぐ官報と横書きの白書に現れる。枠内の補助認識が主OCRと一致していても、官報では文字順の誤りがあり、白書では確信度の高い正しい行にも印が付いた。固定OCRの周囲の枠に、向きの違いを区別する情報があるか調べる。

各行の周囲にある他の主OCR枠について、同方向と直交方向の枠の数、長手方向の重なり、横切る位置の割合を特徴にする。周囲は一行の枠を基準に距離を定める。画像正解、出典、出版物識別子、他行の正誤・予測は特徴に使わない。全15,658行に同じ計算を適用する。

v9の固定済みの276特徴と教師を基準とし、特徴を追加したHGBを1候補だけ比べる。種、木の設定、閾値0.15、出版物単位の42分割、6組の評価、未決定の配置上限、公開の余裕を維持する。画像補充や出典確認の新しい候補ラベルはこの実験の教師に使わない。結果は開発中の比較として扱う。

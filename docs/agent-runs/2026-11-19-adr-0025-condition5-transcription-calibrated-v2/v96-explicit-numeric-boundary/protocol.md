# 同じ固定画素で所属の指示を明確にした再試験

v95レビューで、新に「記号の所属は判断しない」と「枠への所属は判断する」が混在すると指摘された。v95の全64票と実機の起動を再検証し、新のSol・Opus両者が枠外コンマ4件を含めてコンマのある12枠すべてで実測の成分番号を回答したことを確認した。青い罫線片を回答に含めた票は0。v95の数値は実際の挙動として保存する。

v96はv95の16枠、固定の画素、事前の正解と分類を全て再利用する。旧の指示と両版の添付3枚はv95と同じ。新の末尾だけを「数字の所属は確認し、記号の上下の所属は計測に任せる」と明確にする。青い罫線片が表の目印である説明は両版にある。画像だけをSol・Opusに `high` の別々の新規セッションで各32回送り、同じ方法で二票の文字列の脱落・過剰転記・未決定・一致を比較する。新だけ原票に成分番号があるため、報告した罫線片や取り違えは文字列の集計と別に確認する。この試験の手掛かりはv95と同じで、黒い紛らわしい筆画の見分けはv94で別に検証した。正式監査の固定画像、条件5と正規化は従来どおり。

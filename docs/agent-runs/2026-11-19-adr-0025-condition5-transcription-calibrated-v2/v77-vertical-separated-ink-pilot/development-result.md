# 縦列を帯ごとに拡大した開発試験

対象の官報4行と対照3行を、両モデルとも `high` で、各版別々の新規セッションで読んだ。既存正解に二票が一致したのは旧3行、新4行。増えた一致は官報180行目だけ。対照3行はすべて両版で一致した。残る144・164・201行は両版で未決定。二票が同じ誤りを採用した行はなかった。対照4行を予定したが、固定画素から同じ条件で分けられた対照は3行だった。[固定方法](protocol.md)・[行別結果](comparison.json)

4行の二字目・六字目の固定450 DPIを二つの閾値で切り出し、平行移動だけで比較した。四つの行どうしの二字目・六字目の重なりは0.80〜1.00、比較対照にした別の字は0.27以下。行によって印刷の輪郭と撮像の位置が異なるため、重なりだけでUnicodeの字種を確定しない。144行目の六字目を両者が既存の字と異なる字で読んだ一方、二字目が割れて全文は確定しなかった。既存正解は更新しない。[固定画素の比較](printed-form-comparison.json)

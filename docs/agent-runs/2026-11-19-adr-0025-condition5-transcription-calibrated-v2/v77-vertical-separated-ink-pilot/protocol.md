# 固定450 DPIで分離した字の帯を個別に確認する

官報の同じ頁の144・164・180・201行を対象とする。既存の正解や数回のただの拡大で字体が割れた4行である。同じ分離条件で既存の画像二票が正解に一致した官報から、同じ頁で条件を満たした2行を優先し、他の頁で条件を満たした1行を加える。4対照の予定に対し、同じ固定条件で得られたのは3行だった。各群で固定文字列と行IDのSHA-256順を使う。対象も対照も開発用とする。

縦軸の枠に固定450 DPIでおおむね均等な横方向の空白が続き、異なる二つの濃さで同じ帯になる場合だけ、番号付きの拡大を追加する。枠の上下を含む連続した画素を切り分ける。切り分けた画像の帯や数は文字の正解を表さない。元の画像・所属・順序を維持し、元の色・文字の形を変えない。全文と輪郭を元の画像で確かめ、個別の拡大では画の接続や角を確認する。転記者には字種の例、候補の字、正解、保存票、資料名を渡さない。

SolとOpusは両版を別の新規セッションで `high` で一度ずつ読む。新しい画像1枚と、その使い方の短い指示が違い。二票一致、同じ誤り、脱落、過剰転記、未決定を比べる。既存の正解と異なる一致が出ても、開発の事実として記録して固定版はそのままにする。

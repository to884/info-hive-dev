# 次版の正解を監査する流れ

正解候補、固定予測、採点器、発表済みの基準を固定したあと、母集団と層別の分母を保存する。生の領域正解は生の本文の正誤、画像正解は有効な本文の正誤で層を作る。以前の監査や開発で読んだ行も同じ抽出の対象にする。既知の正解の各層から15行または全数を採り、画像の未決定層は別に診断する。同じ行が両方に入ったら画像の二票は共通にして、母集団ごとの結果を別々に数える。

監査用には、元の固定画素と枠だけから、所属判定用の150 DPI、字形確認用の450 DPIのカードを作る。補助を作る位置は枠と等分した座標で決まる。過去の票、原PDF、主OCR、正解、印、得点、点を計測した位置と個数を渡さない。割当の軸は同じ。各行を二系統の独立した新規セッションで一度読み、新旧の票を混ぜない。未決定と不一致は参照不足として保持する。

行の形は見えるが符号だけを区別できない場合、本文のその位置に種類と点の先頭・末尾の横座標を書く。座標は固定画像の枠から一様に付けた5画素刻みの目盛りを使う。両者の本文・形・位置が合う場合だけ、別に取得した描画命令、フォントと固定画素を照合する。双方が示す端点の差と、固定画像から二つの実装で測った端点との差は、いずれも10画素以内とする。描画の基線は固定枠の縦範囲内にあり、整数への丸めは半画素の範囲で扱う。位置を決められない同じ形の候補や他の描画命令が重なる場合は保留する。

前後の文字は画像二読で確かめる。抽出器、座標や字形の照合は正解作成時と別にする。曖昧の判断、所属、本文、出典のどれかが割れた場合は参照不足を記録する。生の領域と有効な画像正解の既知の層で、不一致も参照不足も0のときに各監査が通過する。

出典は点を実際に描ける文字命令を使う。非表示の文字モード、塗りの分からない命令、透明や切り抜きで点が描かれると確かめられない命令は符号の裏付けに使わない。点線や行頭の丸印に当たる表記が位置の記録なしに直接書かれた場合は、字形と符号への結び付きが確認できないため参照不足にする。

この手順で抽出・受領・集計を一回の版として記録する。事前に固定した正解や予測は、監査の結果を受けて上書きしない。次に進む場合は、既定の二監査、製品の経路との一致、未使用の公開・合成試料の順に結果を残す。

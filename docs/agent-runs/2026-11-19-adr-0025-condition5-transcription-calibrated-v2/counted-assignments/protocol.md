# 条件5の全配置を単位別の件数から再計算する

現行の採点器は配置ごとに全行の辞書を作り直し、毎回同じt分布の分位点を計算する。採点の上限に近い組でも扱えるよう、行ごとに再集計する処理を単位別の件数に置き換える。

行識別子、配置を列挙する順序、上限100万、指標と丸め、片側95%限界、追加関門、最初の反例で停止する条件を維持する。分母が0の場合の扱い、単位の順序、渡す行の数も維持する。未決定の誤りを印あり・印なしの単位別件数として足す。入力や元の採点器は改変しない。

実際の固定予測で、元の採点器と件数版を同じ資料に当てる。加えて0分母、過小な単位数、境界値、最初に失敗する配置の違いを含む小さい既知の例と生成例で比較する。実用速度を記録する。研究で使えるか調べるもので、正式版に使う前に一致の記録と敵対レビューを確認する。

# 固定の数値画像で小さい区切りが枠の外に出る対照

v86の実資料の数値2行の元画像で、枠の下端だけを固定150 DPIで1画素上・そのまま・1画素下に置き、計6枠を事前に固定する。450 DPIでも同じ物理移動に相当する赤い端の印を使う。画像の文字画素は変えず、元の監査の枠も変更しない。上下の境界を示す左右の印で、古い枠は表示しない。数値の本文の中心は全て枠内で、小さい区切りの中心だけが枠の下端に当たるか、1画素外または内にある。

旧・新で添付は同じ。新指示は、境界上の中心を枠内とするv86の文を加える。SolとOpusが各枠・各指示を独立した新規セッション、両方 `high` で読む。画像だけを渡す。中心が外側の2枠での過剰転記と、内側と境界上の各2枠での脱落・未決定を二票と個別票で比べる。同じ元画像を使うため、独立した資料への一般化は扱わない。正式母集団・正規化・合否判定には使わない。

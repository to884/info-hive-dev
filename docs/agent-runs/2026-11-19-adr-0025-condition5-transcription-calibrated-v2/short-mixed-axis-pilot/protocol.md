# 条件5の短い枠を横切る列の読み

公開の開発で、細い縦書きの列や図表の文字を複数含む短い枠は、字の所属と読む順が割れた。官報3頁と防災白書1頁の全画像補充から、枠幅16〜120画素、枠高さ12〜35画素、所属軸xの行を対象にする。出版物と行順を固定し、各頁の未決定3行と既知の対照1行をハッシュで選ぶ。条件を満たす未決定行が3行未満の不備は、読取前に検出する。

固定150・450 DPIの枠あり・なしのカードを用いる。固定150 DPIの枠の周囲を6倍の最近傍で表示し、元の枠の上下左右へ画像の外側から目盛りと境界を示す。450 DPIは図表の読取と同じ2倍の表示を補助に使う。選択した字形や本文、点の個数、過去の票は渡さない。縦書きの列は右から左、同じ列は上から下の順にし、所属判定では元の指定軸と基準を適用する。

同じ画像を別々の新規SolとOpusに渡す。従来未決定12行のうち6行以上の全文一致があり、対照で旧正解と異なる二票一致がない場合に残りを読む。開発用の補充候補として原票とともに保存する。

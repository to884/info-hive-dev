# 旧指示で難度を較正した転記比較

## 画像設計の修正

[最初の設計](../2026-11-19-adr-0025-condition5-transcription-calibrated/report.md)は、枠内の淡い括弧を落として枠外の同種記号を拾っても正解と同じ文字列になったため、Opusのレビューを受けて較正・比較とも採用しなかった。修正版は、二連続の行の枠外に「＋」を置いた。二つ目の括弧を「＋」で置き換えると、二連続の較正8行すべてで脱落1字、過剰1字となることを検算した。

本文・画像ID・配置の乱数種を作り直した。閉じ記号と書体、境界句点の位置、第三読担当を全段階で統一した。450 DPIで弱めた字も一定の濃度差が残るよう検査した。この検査は生成字形の信号を確認するもので、モデルが必ず判読できることまでは示さない。[実施手順](protocol.md)・[実行コード](visible.py)

本較正では事前の採用基準を満たさず、事前に規定した別素材の予備較正へ進んだ。設定3は、連続記号の脱落・最終未決定・全文正解の三条件を満たした最小の番号。同じ設定3でも本較正と予備較正で脱落数が違ったため、設定番号を本文や配置を越えた難度尺度としては扱えない。[本較正の結果](calibration-result.json)・[予備較正の結果](reserve-result.json)

Opusの再レビューでは、枠外字による脱落の相殺が修正されたことを確認した。一方、濃度下限により設定4〜6で淡い字のピークに差がつきにくくなる点と、枠外の「＋」が二連続の行を示す手掛かりになる点は差し戻しとなった。前者は未採用の設定に関するため、設定3で実際に脱落と未決定が発生したという事実と、同じ設定での対比較は維持した。後者の手掛かりは両群の画像で同じだが、新指示との相互作用はあり得るため、結果をこの画像条件に限って解釈する。

## 事前固定した別画像での比較

予備較正を終えてから、設定3で別の合成原稿4種・32行を生成した。較正用とは本文、行ID、画像ハッシュが異なる。両群の初回二読は同じ16枚を同じ順序で提示し、新指示にだけ「提出前に連続記号の位置と個数を見直す。」を加えた。[比較の固定記録](comparison-lock.json)・[匿名行別の結果と受領記録](comparison-result.json)

| 指標 | 旧指示 | 新指示 |
|---|---:|---:|
| 確定行 | 20/32行 | 20/32行 |
| 全文正解 | 12/32行 | 12/32行 |
| 確定行の記号脱落 | 8行・8字 | 8行・8字 |
| 確定行の過剰な句読点・記号 | 0行・0字 | 0行・0字 |
| 確定行の余分な文字全般 | 0行・0字 | 0行・0字 |
| 最終未決定 | 12/32行 | 12/32行 |
| 第三読 | 12/32行 | 20/32行 |

双方で同じ20行が確定した。正解のまま12行、誤りのまま8行、未決定のまま12行。正誤や確定状態が変わった行は0行。連続2記号の8行では両群とも1字ずつ脱落し、境界の句点4行はすべて正解、短い縦列12行はすべて未決定だった。

初回票ではSolの連続記号の脱落が8字から0字に減った。Astraは旧・新とも8字を落とした。新指示では連続2記号の8行が二読で割れ、事前割付どおりAstraの別セッションが第三読した。その8行は第三読でも括弧が1字となり、最終結果の脱落数は変わらなかった。第三読には同じモデル系統の読みが再び入る。この結果は票の統合手順を含む比較であり、単独モデルの反復試験ではない。

最終結果では脱落の改善も、確定行の過剰転記や未決定の増加も観測されなかった。新指示で第三読が8行増えた。原票から12セッション分を独立に再集計し、画像・指示・応答のSHA、第三読対象、合意、正解との照合を確認した。条件5のADR、採点器、正規化、固定v9結果、参照監査結果のSHAは開始・終了時で一致した。

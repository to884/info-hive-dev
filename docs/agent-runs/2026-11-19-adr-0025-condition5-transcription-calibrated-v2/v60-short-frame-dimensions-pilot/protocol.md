# 短い枠を寸法で使い分ける開発比較

v53の12行と、新しい対照5行を既知の開発用として固定する。固定の150/450 DPI、領域と所属、順序の原則、既定の正規化は保つ。短い枠は元の横書きなら左から右、縦の複数列なら右から左、列の中は上から下の全文で答える。

150 DPIの枠が幅30画素以下、高さ20画素以下の場合だけ、上下のつながりと90度の同じ画素を添える。小さい一字の枠で向きを確認するための寸法である。他の枠には全文指示と既存の画像を使う。判定に出版物名や正解の内容を使わない。

別々の新規Sol・Opusセッションで読み、v53の保存票、旧の一致対照と比較する。元の枠や固定画像を変えず、追加の表示で生じる脱落・過剰転記・別字・未決定も数える。

# 長い横書きの丸・ピリオド・座標の開発比較

v47で点の座標差が11画素になった総務省白書、本文と項目丸で割れた総務省白書、白い小さなピリオドが丸印扱いになった防衛白書を対象とする。さらに点の位置、色付き項目、英数字、行頭の輪の対照6行を用意する。固定150/450 DPIと枠、割当、正規化、座標を一致とする既定の範囲は保つ。

横座標の上段に10画素の倍数、下段にその中間の5画素を記す。元の画素と同じ座標系で、点の位置や文字を検出した結果は渡さない。長い行にも固定150 DPIから行頭と段落の位置を見せる。添付数は24枚までとし、必要なら二つの表示を固定画素のまま上下に並べる。行頭の大きい丸、小さい曖昧な点、字の下端にある見える欧文のピリオドは大きさと位置で区別する。

既存画像票と新規セッションの画像票を比べ、一致、脱落、過剰、置き換え、未決定、出典照合待ちを数える。開発の比較中は元PDFを開かず、役割と対象を事前に固定する。

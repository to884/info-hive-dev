# 白い中黒を描いたCIDの直接確認

元PDFのコンテンツストリームのTJ命令で、埋め込みAdobe-Japan1フォントのCID 638を直接確認した。対象の二バイトだけを描画しない版をメモリ内で作成した。元の版を再出力した固定150・450 DPIは、監査の画像と一致した。描画を消した固定150 DPIでは点の124画素だけが変わった。固定450 DPIでは点の922画素が変わり、範囲外の46画素にも最大1階調の差があった。

点の周り36×36画素の暗い背景は、点より広い画像と模様の描画だけで再現した。合成の画像背景は通過し、文字でない白い図形、暗い図形に重なった白文字は背景検査で止めた。丸の代用として三点リーダーは候補から除いた。今回の証明は対象の1行に限る。正式の判定への反映は行っていない。[固定画素と描画の記録](result.json)・[合成の背景対照](background-controls.json)

Opusの `high` の再レビューは当該1行の証明を承認した。小点以外の暗い文字を重ねると以前の背景検査だけでは見逃す、という指摘に対し、点の描画だけを消した150 DPIと、文字を全部非表示にした150 DPIの周囲36×36画素を照合した。元の行は差0、暗い文字を重ねた合成対照は差197画素。元のフォントは `CIDFontType0`、埋め込みプログラムは `CIDFontType0C` で、`CIDToGIDMap` を持たないことも確認した。三点リーダーは候補にないことをコードで確認したもので、描画の合成対照は実施していない。[再レビュー](review-opus.md)・[追加対照](text-underlay-control.json)

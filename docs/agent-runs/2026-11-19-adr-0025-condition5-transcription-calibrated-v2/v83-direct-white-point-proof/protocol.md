# 防衛白書の白い小点を実際のCIDと背景で検証する

v80の1行の結果を追加検証する。Opusレビューの指摘に従い、黒い円への白い文字、文字でない白い点、丸に三点リーダーを当てる例を陰性として扱う。元の二票の本文と位置、固定150・450 DPI、元PDFの来歴を先に固定する。出典から読むのは二票が指定した一つの符号だけ。書誌・本文は読取に使わない。

元のPDFを一頁として再構築した場合も、通常の描画が二解像度で同じことを検査する。埋め込みフォントとAdobe-Japan1の宣言、コンテンツ上のTjまたはTJが実際に使う二バイトを確かめる。このうち一つだけを見えなくして、固定150 DPIで対象以外が変わらず、固定450 DPIの対象に同じ消失が現れることを確認する。450 DPIで範囲外に値が変わった画素があれば値と件数を記録する。150 DPIの背景は、対象より十分に広い元の要素だと判定できる場合に限る。

これは対象の一行の追加検証。別資料へ一般化する正式手順や既存の判定を更新しない。

# 枠の周囲から書字方向を確認する開発試験

v87の官報7行、実資料対照8行、方向が明瞭な合成対照6行と、v79の方向が紛らわしい横書きの合成対照6行を固定。旧・新で同一の画像を用いる。変更点は、上下または左右に続く文字の配置を見て紙面の書字方向を判定する指示だけ。割当軸を測る向きとは別に判断する。枠外の文字を転記せず、一字とする前に枠にかかる文字を確認する。返す方向・位置順の各列と所属の条件は両版で同じ。

SolとOpusはどちらも `high`、各行・各版で別々の新規セッション。二票で方向と各列の中身がそろった場合だけ正文に並べ、一致・脱落・過剰転記・誤り・未決定を比較する。以前同じ誤りが出た曖昧な横書きは別集計する。既存の正解、固定の正式画像、数値の合否には使わない。

# 開発用32行での従来と中立化した表示の比較

過去の開発と監査の選定を除き、固定済みの開発用資料から形状の4群を各8行選んだ。新旧各32行をSolとOpusが別々の新規セッションで読み、各モデルから64票を受領した。指示と画像、採点、原票のハッシュを記録した。

| 二票の判定 | 従来 | 中立化 |
|---|---:|---:|
| 既存正解と一致 | 30 | 30 |
| 出典待ち | 1 | 1 |
| 脱落 | 1 | 1 |
| 過剰転記・その他の不一致・未決定 | 0 | 0 |

判定だけでなく対象行も一致した。出典待ちは防災資料の14行目で、本文と二つの点の位置が前後同じ。脱落は官報の8行目で、四つの新規票すべてが行頭の「一」を省いた。固定450 DPIでの行頭の成分の枠内率は36〜43%。既定の所属に照らし、画像補充正解の一字を別版で見直した。

新しい表示をこの32行で有利とする差はなかった。各束の追加枚数、画素寸法と省いた画像を記録し、枠端の両方の細部が保持された。新しい版の最大は22画像、最大面積の添付は1,108×760画素だった。この試験の結果を正式な監査結果へ混ぜない。

# 両解像度の中心をそろえたコンマ所属の追試

v94のレビューで、450 DPIと150 DPIの中心の差、枠外の数字の下端、余分な筆画と記号の見分け方に問題が残った。v94の固定、原票、結果を保存する。新しい開発PDFは2ページ・2書体・16枠。枠の高さと上下位置は各行のベースラインに対して固定する。黒いベクトルのコンマだけを動かし、枠下端より1画素内、境界上、1画素外の各4枠とコンマなし4枠を作る。各分類の半分には独立した青い短い罫線片を枠内に置く。

コンマ、罫線片、数字のいずれか一つを非表示にした画像との差分を採る。150 DPIと450 DPIの両方で閾値を通るコンマ成分の外接枠の中心が、下端から -1・0・+1画素および -3・0・+3画素であることを確認する。両解像度で数字のインク全体は枠内。罫線片は横に長い青い形で区別でき、コンマと分離する。

両版に同一の3枚。v92の旧・新指示に、所属は150 DPI、450 DPIは字形の確認、青い線は表の目印であることを共通で明記する。Sol・Opusとも `high`、各枠・各版は別々の新規セッション。脱落と過剰転記は両方がある場合に重複して数え、未決定と正解一致を記録する。新の原票では成分番号を実測と比べ、正解文字列に見えても青い成分を選んだ誤りがあるか確認する。青い罫線と手掛かりのある合成例に限った試験。正式の条件、画像、正規化は従来どおり。

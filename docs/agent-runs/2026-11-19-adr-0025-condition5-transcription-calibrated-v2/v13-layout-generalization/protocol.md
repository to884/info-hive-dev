# これまでの診断に使っていない開発行での追試

監査v10で両系統とも有効票がなかった行のうち、既存正解が確定している行を対象とする。短い横軸、縦軸、その他の横軸から、物理寸法と公開の組で分け、決めた順序で各4行を取る。この12行は過去の票の本文を選定に使わない。解消できなかった既知の診断行を対照として別集計する。監査v10の正式票を補うための抽出ではない。

固定150/450 DPIを使う。横軸の複数列では横投影の目印を使い、元の画像と同じ割当を適用する。目印の数が少ないか多すぎる場合は元の枠の表示で全文を返す。縦軸では、行頭と行末が続く周囲を示し、元の画素と字の所属枠の細部を併記する。似た字・リング・横画を筆画と空きから確かめる。画像に見える出現位置と別の文字を区別するが、発行物の内容や書式の一般知識で本文を補正しない。

横書きの本文では、目盛りに沿って、小さく互いに見分けられない点を字種に置き換えず、範囲内の位置を記録する。大きな記号と文字以外の図形は画像から判断する。出典に進むのは、両票の見える本文・形と位置が一致した場合だけとする。新規のSolとOpusに同じ表示を渡し、保存票、元PDFと既存正解を伏せる。

# 条件5の固定画像の開発追試

v10の正解・原票・正式判定はそのまま保持した。新規のSolとOpusに、固定150 DPIと450 DPIから作った表示だけを渡した。

| 表示 | 対象 | 既存正解と二票が一致 | 二票一致・既存正解と相違 | 未決定 |
|---|---|---:|---:|---:|
| 列の目印と450 DPIの広い周囲 | 短い枠の診断6行 | 5 | 0 | 1 |
| 同上 | 短い枠の対照2行 | 2 | 0 | 0 |
| 列の目印と150 DPIの広い周囲 | 短い枠の診断3行 | 2 | 0 | 1 |
| 同上 | 短い枠の対照2行 | 2 | 0 | 0 |
| 450 DPIの細部 | 横書きの診断3行 | 1 | 0 | 2 |
| 高さの区画 | 縦軸の診断5行 | 1 | 1 | 3 |
| 同上 | 縦軸の対照2行 | 0 | 0 | 2 |

監査で読む順が違った官報3行は、最初の列の目印で既存正解と二票が一致した。縦横の向きがなお割れた1行は、より広い周囲を含む追試では一致した。追試では以前の450 DPIの細部を外したため、周囲を広げた効果は分離していない。Opusの敵対的レビューは、この表示差に加え、縦の区画が文字の途中を分け、同じ全文でも区画が違えば未決定になり得ることと、縦の区画で隣列を取り違える可能性を指摘した。対照を失敗させた区画ごとの回答方式は採用しない。[列の目印の結果](../v11-column-slot-pilot/result.json)・[追試の結果](result.json)

丸印3件を原PDFの描画から切り分けた。書き出した各頁の画素は元の固定150 DPIと一致した。防衛白書と情報通信白書の各1件は文字の描画を除いたときに印も消えた。情報通信白書の別の1件は埋め込み画像を除いたときだけ印が消えた。これらは表示がどの種類の命令に由来するかの診断であり、既存の正解を変えていない。

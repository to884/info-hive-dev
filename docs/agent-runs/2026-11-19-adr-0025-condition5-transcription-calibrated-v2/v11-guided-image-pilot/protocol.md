# 固定画素による列順・字形の開発追試

監査v10で既知の本文について票が割れた行と、その前後の寸法の対照を使う。列の目印で既存正解に合った5行のうち2行も対照に加える。両系統の票と出典がすでに合った行は再確認の対象にしない。元の固定画素、所属枠、正規化と正解を保ち、開発の二票だけを追加する。

- 短い横軸の枠は固定150 DPIのインクで横の目印を付ける。従来より広い150 DPIの周囲を同じ色の枠で示し、隣の行と列のつながりをたどれるようにする。縦・横の向きは読み手が決める。判読できるときは区画ごとの全文を返す。
- 縦軸の枠は固定450 DPIで上から80画素相当ずつに分け、区切りの前後を重ねる。枠への所属を確認し、字の上下のインク中心が入る区画に一度だけ書く。区画の境界、行頭、行末は周囲も見る。空の区画も記録する。一行内の意味で紛らわしい字や括弧の数を補正せず、固定画素で筆画を読み分ける。
- 長い横軸の枠は従来の転記形式を維持する。間違いやすい字、括弧、隣の図形を見直すため、固定画素と枠から作った追加表示を使う。点線と丸印の位置の記録は従来のままとする。

二系統は新規セッションで同じ画像を読み、他の票、旧正解、本文を示す資料を受け取らない。開発の照合では、古い監査の判定も変更せず、票と既存正解の完全一致、二票だけの一致、未決定、点の出典確認が要る行を分ける。数値の合否判定と正式な標本抽出には使わない。

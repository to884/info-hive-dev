# 実資料の保存票を元PDFの文字描画と照合した結果

v92で成分番号付きの保存二票がある全12枠を使った。防衛白書の数値3行（うち2行は枠の内・上・外の各3枠）、防災白書の数字だけの5行で、元資料は計8行。Sol・Opusの保存24票を復元し、過去の通信経路切替で差し替えた1票も履歴と照合した。比較の起点はv92の新指示。新たな画像読み取りもPDFの再レンダリングも行っていない。[手順](protocol.md)・[行別の照合と集計](comparison.json)

防衛白書のコンマは、PDFの数字列と同じ文字描画の一部だった。異なるコンマの描画は6個、枠を変えた重複を含めると12件。すべてで保存票のコンマとPDFの文字、挿入位置、150 DPIの固定成分、450 DPIの連結成分が一対一で対応した。防災白書の5行は保存二票の数字列とPDFの文字描画が一致した。

| 集計方法 | 正解 | 脱落 | 過剰転記 | 未決定 | 元から正解だった枠の悪化 |
|---|---:|---:|---:|---:|---:|
| 照合前、v92の保存票 | 12 | 0 | 0 | 0 | — |
| 照合後、v109と同じく両解像度で枠への所属一致を求める | 11 | 0 | 0 | 1 | 1 |
| 照合後、v92の150 DPIの枠所属を用いる | 12 | 0 | 0 | 0 | 0 |

悪化したのは防衛白書のPDF 525ページ94行目、境界対照 `88-pack-373-edge` の `92,116,141`。コンマ2個の中心は150 DPIで枠下端に一致し、450 DPIでは二つの濃さのしきい値で約1.04画素外側に出る。描画と成分の一対一の対応は確認できた。両解像度の所属一致を追加で求めた集計では、枠全体を未決定にした。v92と同じ150 DPIの枠判定では2個とも枠内に含め、元の文字列を維持した。

対象の12枠は照合前から脱落・過剰転記が0件で、実資料でそれらの誤りを減らす効果は測れていない。固定された正式監査の添付4,482枚と台帳をハッシュで照合し、条件5の合否基準、固定画像、監査結果を維持した。


Opusの限定レビューは承認。指摘を受け、PDFのコンマから保存成分への逆向きの対応も一意か確認し、成分番号の重複を検査した。再利用するページの座標も固定画像の原点と倍率で区別した。再集計はバイト単位で同じ結果になり、保存票の着手件数も変わらなかった。[レビュー](review-focus-opus.md)

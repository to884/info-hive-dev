# 実資料の保存票を元PDFの文字描画に照合する

v92で成分番号付きの保存二票がある開発12枠を全件用いる。防衛白書の数値3行（うち2行には枠の内・上・外の試験が各3枠）、防災白書の数字だけの5行。これらの元となった固定画素には正式監査から再利用した画素がある。今回の集計は開発記録に置く。比較の起点は成分番号付きのv92新指示。

元PDFの文字描画から、文字オブジェクトと各グリフの位置を取得する。数字列は保存二票と同じ並びの文字描画で確認する。コンマは保存二票の字形・成分番号・挿入位置、PDFの文字描画、150 DPIの固定座標、450 DPIの保存画素の連結成分を一対一に照合する。別の描画が重なる可能性を排除できない場合は未決定とする。450 DPIは閾値170・191の両方で成分の対応を確認する。保存した字形・位置・数字列を用いるため、PDFから新たな記号や桁を追加しない。

v109と同じく、両解像度の枠所属が一致した場合だけ出典照合で確定する結果を集計する。成分の対応と枠所属の解像度差を区別するため、v92の150 DPI所属を適用して450 DPIを成分の照合に使う場合も併記する。両集計に同じ採点を用いる。新しい画像の読み取りと再レンダリングは0件。条件5の合否基準、正式監査の固定画像と結果は従来どおり。

# 別の固定画像で小点の元描画を照合する

官報の固定150 DPIの画素だけから、開発と以前の抽出に使っていない377個の短い横枠を調べた。枠の幅12〜40画素、高さ10〜25画素に限った。閾値170で枠内に一つの8連結成分のみがあり、外接の高さと幅が2〜10画素、その差が2以下、成分の密度が53%以上で、枠端から1画素より離れている場合を候補とした。該当した120行目を固定する。元PDFは候補を選ぶために参照しなかった。

対照は、小点の証拠を確認済みの官報117行目と、別の字種の独立した大きな丸を含む防衛白書88行目。三行とも同じ中立の指示を使い、SolとOpusが別々の新規セッションで画像だけを読む。元PDFの描画とCIDの確認は、本文・点の位置・形がそろい、画像だけでは符号が区別できない小点を両票が記録した場合に限る。前の票は送らない。新規の行と対照を分けて報告する。

読取前に表示、正規化、照合、出典、例外の扱いを固定する。固定画素とPDFの来歴が異なる場合はエラーとする。対応しない縦組の描画形式、点が一つに決まらない場合はその行の参照不足として記録する。本文の文字は元PDFで補わない。

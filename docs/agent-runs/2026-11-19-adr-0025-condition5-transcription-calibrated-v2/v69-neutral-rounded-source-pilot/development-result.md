# 別の固定画像で確かめた小点の描画

固定画素だけで選んだ官報120行目と2行の対照で、両画像票が曖昧な塗り点の位置をそろえた。出典の判定コードと画像票の指示は先に固定済み。以前の官報117行目には出典で中黒が再現した。

新しく選んだ120行目でも、同一頁の別の描画命令を非表示にすると、両画像票の位置の18画素だけが消えた。同じCIDを描いた残り3箇所ではその位置の画素は変わらなかった。120行目の命令は576番でバイトオフセット8、117行目は554番でバイトオフセット6だった。双方の元の再描画と固定150 DPIは完全に一致し、符号はU+30FBだった。

独立した大きな丸の対照では、両画像票が曖昧な小点の形で返した。確認の経路は、この対照の符号を確定せず参照不足とした。大きな丸を画像で読み分ける改善は必要である。

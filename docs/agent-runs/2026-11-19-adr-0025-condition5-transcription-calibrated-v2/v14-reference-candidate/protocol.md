# 下端をまたぐ字を確認した正解案の感度

既定の所属と正規化を保つ。これまで両票がなかった開発12行を読み直し、官報の1行で新規のSolとOpusが字を一つ補って一致した。元の固定450 DPIでは末尾の字の全体を識別でき、固定150 DPIではその字の上下の範囲と左右の中心を確かめられる。所属を左右する画素を比較するため明度128、160、192の三つのしきい値で同じ窓を測る。

画像補充正解のその1行だけを訂正した場合と、従来の正解を凍結したままの場合を開発用として比べる。判定モデル、教師、固定予測、評価行、配置の上限は同じ。読み手に既存正解、モデルの印、採点と候補の本文を渡さない。出典側に反例のあった黒丸の行は別の試験で扱い、この比較の正解には反映しない。正式な監査標本はここでは計算しない。

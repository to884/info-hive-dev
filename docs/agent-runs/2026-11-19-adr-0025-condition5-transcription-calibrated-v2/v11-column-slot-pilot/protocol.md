# 条件5の短い枠における画像由来の列の位置

座標を各読み手が申告した試験では、対照2行の全文は同じでも、数値の差で一致にならなかった。官報の同じ短い枠8行を用い、固定150 DPIの横方向のインク投影から、埋める場所を同じ番号で示す。前の開発試験の画像は同じものを渡し、別に固定450 DPIの広い周辺の表示を加える。枠、所属、列内の順、正規化は維持する。

枠の外側に左からA、Bなどの目印を付ける。どの目印にどの字が所属するかを画像で確かめ、読み方を縦書きか横書きとして記録する。実際の本文は保持したまま、縦書きは右から左、横書きは左から右へ並べ直し、二票を照合する。目印から文字や所属を推測しない。実際の列が目印で表せない場合は未決定にする。

新規のSolとOpusに依頼し、保存した直前の試験と件数を比べる。区画と広い周囲の表示をまとめた試験であり、要素ごとの効果を分離しない。既知正解の対照2行がともに一致してから、正式な監査用に一般化できるかを検討する。

# 条件5の開発診断　出典と画素を用いた仮の行転記

画像で点線を検出し、文字符号を出典で裏付けた行を対象とする。防衛白書では、Adobe-Japan1のCIDと三点リーダーの描画命令、画像の物理点数がそろった行を使う。災害資料ではPDFMiner・PDFiumの中黒と画素を照合済みの行を使う。点以外は既存v9の所属が一意で平行な字形を使う。別の字が本来の所属基準を満たす、確定した領域に点列と別字が入り交じる、または説明できるインクが不足する行は仮転記へ回さない。側の選定は固定画像と出典で決まり、OCRの転記・印・正誤は選定や復元に使わない。

既存の正式な正解と別に、開発用の仮転記、根拠のSHA、保留理由を保存する。同じ行・印・採点器で仮転記を採点する場合は、仮転記を正しいと仮定した感度分析として報告する。正式な正解や独立監査に適用するには、画像だけで符号化を区別できない場合の根拠と独立性を、既定の統合設計に沿って別に確かめる。

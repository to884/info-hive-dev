# 固定二票と審査済みの補助証拠を結び付ける

次版の監査入口で使うため、開発で審査した防衛白書の二つの枠を照合する。位置は行番号、元の枠、割当軸、150 DPIの来歴、450 DPIの切り出し位置と画素、元PDFのハッシュで固定する。各系統の新しい監査票の転記をそれぞれ読み取った後に照合する。出典・既存票・既存の転記・正解は読取側に渡さない。

84行目の先頭の成分は固定画素で丸ではないことが確認済み。二票の読みが同じで先頭を実際にFとして読んだ場合に限り、従来の小丸保留の条件を解除する。本文全体は常に二票のものを用いる。13行目の白い小点は、二票が既存の整列処理で本文と一つの曖昧な点の座標に合意し、その座標が証明した点に対応するときだけ、直接確認したCIDに対応する中黒に置き換える。既存の補助出典が確定済みのときはその結果を使う。

先に、保存済みのv64の台帳から379行の二票の来歴を再検証して開発用に再生する。旧の出典・小丸点検と照合し、変わるのは前述の2行のみであることを確かめる。画像・枠・本文・点の座標・印の数を変えた陰性対照、画像に焼き込まれた白書の行も確認する。印や像の範囲の変更に対して保留する。新しい標本の抽出や正式v64の上書きはここでは行わない。数値の基準、文字の正規化、画像の所属と二票の一致条件を維持する。

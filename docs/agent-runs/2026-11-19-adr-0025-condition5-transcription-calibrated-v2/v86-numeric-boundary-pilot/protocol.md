# 小さい区切りの中心が下端にある数値の転記

v64の防衛白書の数値2行は、小さい筆画の所属で二票が割れた。対照は同じ監査で画像の二票が既存正解に一致した、幅150画素未満・高さ35画素以下の横軸の数値行をすべて使う。既存正解から行の種類だけを選定に使い、転記者は受け取らない。

切り出した固定150・450 DPIの元の画素を同じ二つの図で示す。枠の上下の位置を画像の左右の外に短い線で表示し、中央の本文・点・罫線の画素を覆わない。両版とも元の添付と追加表示、順序、既存の規則が同じ。新指示は、枠の直交方向の中心が境界にちょうど一致するときも枠内とする現行の計測式を文章で明記する。所在を確認する対象の記号名、位置、個数を指示に書かない。小さい字の全体と中心を元の二画像で確認する。

Sol、Opusは両版とも `high` で、各行各版を別々の新規セッションで読む。既知の課題と対照で一致、不一致、脱落、過剰転記、未決定を比較し、対照で新たな同じ誤りまたは未決定が出た場合は提案を保留する。開発試験として記録する。

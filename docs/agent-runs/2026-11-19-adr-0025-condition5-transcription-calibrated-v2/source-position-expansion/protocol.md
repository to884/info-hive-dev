# 条件5の開発用画像補充　適格な点線行の二読

番号を見せない補助で、事前に固定した点線12行と対照4行の確認を終えた。同じ画像の所属と正規化を使い、まだ読んでいない適格行を、資料ページ・元の行順で漏れなく分ける。各束は最大4行、画像22枚以下。現段階の対象は、画像の連結成分と水平走査で位置と個数がそろい、本文の候補と出典を照合済みの母集団に限る。既存の目視除外を回避するために対象を変えない。未決定や画像・出典の不足は未決定のまま残す。

束ごとに新規SolとOpusで一度ずつ読み、周囲の全文と点線が最初と最後に写った元カード番号を返す。補助は固定画像の番号なしの切り出し。読者には正解、出典、符号、点の個数を与えない。両画像票の本文・位置と二つの計測、独立の出典を照合できた行だけを開発用正解候補とする。画像読取に白黒判定を求める場合の例外は設けない。

技術的に受領不能だったときだけ、別の新規セッションで1回まで再送信し、両試行を保存する。有効な未決定、不一致、点の相違は再読理由にしない。各束を結果どおり記録し、全受領の照合後に集計する。正式な正解の次版への組み込みや独立監査は、別途決めた対象、独立性、採点の順に従う。

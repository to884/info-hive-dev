固定した画像の切り出しに点の位置を示し、個数と符号を出さずにSolとOpusへ別々に配布した。両票が周囲の全文と点線の位置で一致し、固定画像の連結成分と水平走査線で点数が一致し、元PDFの描画命令とフォントで符号が確かめられた行を開発用の正解候補にした。固定150・450 DPI、正規化、評価行、数値基準は従来の値を使った。

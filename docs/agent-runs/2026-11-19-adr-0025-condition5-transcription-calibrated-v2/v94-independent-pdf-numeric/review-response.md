# v94レビューの指摘と再試験

Opus `high` の判定は不承認。記録した比率と票の照合は保存する。境界上の読み取りと余分な筆画への耐性については、次の指摘を踏まえて解釈を限る。[レビュー](review-opus.md)

- 固定画素で確認し直すと、境界を150 DPIの外接枠の中心で定義した6枠は、450 DPIで中心が0.5〜2.5画素外にあった。旧がどちらの解像度を優先するか十分に指定していなかった。v95では数字を含む枠を各行のベースラインに対して固定し、コンマを動かした。両解像度の外接枠の中心が完全に同じ所属を示すことを固定時に検査し、150 DPIを所属、450 DPIを字形の確認と両版に明記する。
- v94の余分な短い筆画は、図だけでは斜線や点と見分けにくい。元の描画では本来のコンマと別の線である。v95では青い横罫線片を使い、目印であることを両版に明記する。v94で両票が同じ数字間の二成分を指定した事実は、区別が難しい例の記録として残る。
- v94では、誤った成分を同じ文字として出した場合に最終文字列だけが一致する可能性がある。v95では成分自体の取り違えを別に集計する。v94の原票照合では、本物のコンマと余分な筆画が共存する9枠はいずれも未決定だったため、この問題で正解一致とされた枠はなかった。
- v94の余分な筆画や数字の上下位置に関する漠然とした一般化を控える。v95で両解像度の全ての数字画素が枠内に収まることを確認する。実際のモデル設定は96原票の起動記録でSol・Opusとも `high` と照合した。

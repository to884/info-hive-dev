# 別の開発用PDFでコンマの所属判定を追試

v92の防衛白書とは独立した合成PDFを新しく作る。3書体×8行の24枠。コンマ中心が下端より1画素内、境界上、1画素外の各6枠と、コンマなしの対照6枠。各分類で3枠にコンマ付近の別の筆画を置く。余分な筆画はすべて枠内に置く。元のPDFからコンマまたは筆画だけを外した対照を描画し、150 DPIで各々の実在、小さい成分の分離、上下の位置と左右の所属を確かめる。ケースの画像と正解は転記前に固定する。合成の符号の中央を整数画素に合わせるため、コンマの描画位置と字の大きさを事前に校正する。

v92の旧指示（全文転記）と新指示（数字、区切りの字形・位置・成分番号）、固定150/450 DPI、横目盛りと成分番号の3画像を引き継ぐ。一つの枠で両版の画像バイトは同一。SolとOpusを両版とも `high`、一行・一版・一モデルにつき別の新規セッションで読む。読み手には開発PDF、描画の正解、過去票を渡さない。新は異系統が同じ成分、挿入位置、字形、数字列で一致したときだけ既存の所属式を適用する。

同じ24枠で脱落、過剰転記、未決定、正解を集計する。脱落と過剰転記は両方のある行を重複して数え、文字の置き換えは元の字の脱落と別の字の追加に数える。判読不能や二票が割れた行は未決定に数える。個別票と異系統の二票の結果を保存し、全体・枠の位置・余分な筆画の有無で比べる。新に新たな脱落・過剰転記・未決定が出るかを行ごとに確認する。正式監査の固定画像と合否基準は従来どおり。今回の票は開発だけに使う。

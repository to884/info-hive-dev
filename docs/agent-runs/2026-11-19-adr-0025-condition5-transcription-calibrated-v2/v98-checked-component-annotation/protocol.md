# v97の成分番号の採点を保存票で再検証

敵対レビューで旧の文字列末尾の区切りが崩れると、成分番号が本文の過剰転記に混入する反例を受けた。空白入りの区切りと全角区切りを、従来の同じ正規化で読み直してから番号を切り離す。単独の縦棒や注記に見える末尾が本文に残った場合は形式による未決定とし、本文の過剰転記に含めない。対照として、普通の本文内のコロンが本文として保たれるかも検査する。保存済みの旧・新の画像と原票を使い、読み取りを繰り返さない。`v97`の固定と結果は保存したまま、採点の再検証だけを別の場所に出力する。

新の二票は、既存の方式どおり成分の一致も必要とする。転記だけが一致して成分が割れたときに転記だけを確定するのは旧。新でも成分一致を外して文字列の二票だけで照合した場合に差があるかを追加確認する。実コンマの成分を採ったことと、それが正しい転記だったかは別の記録。旧の原票に留保対象の符号を含む場合も点検する。正式監査の固定画像、判定、基準は従来どおり。

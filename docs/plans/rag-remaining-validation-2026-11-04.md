# RAG の追加検証

2026年11月4日。対象は PoC サマリに残した項目。利用者の指示により、OS の電源断は行わない。

| 項目 | 検証方法 |
| --- | --- |
| 全資料の規模 | 参照ルートの全 PDF を読み取り専用で調査し、ページ、抽出文字、実際の自動分割によるチャンク数、OCR が必要と判定されたページを記録する |
| 大規模索引 | 実データから ANN と圧縮索引を構築し、容量、CPU 検索、メモリ、正確な全件検索に対する ANN の取りこぼしを測る。GPU による文書埋め込みを利用した場合は CPU 構築時間と区別する |
| 検索品質 | 暫定質問の独立点検と利用者レビュー用ファイルを用意し、自然な自動分割と正解なしの質問で再評価する。AI の点検を人手レビューとは扱わない |
| 製品リランク | 候補リランカーを設定で利用できるようにし、MCP 通信を含む検索時間を計測する |
| 同時実行 | 複数 MCP セッション、取り込み中の検索・制御、同じ PDF の同時投入を実プロセスで確認する |
| OCR | 実資料の代表ページを描画して独立に転記・照合し、複雑な表、数式、低解像度、縦書きの判定と文字認識の限界を記録する |
| OS | Windows と既存の Ubuntu 24.04 WSL で回帰試験と製品 MCP を実行する。実行環境のない OS の結果は捏造しない |

大規模資料の抽出と索引構築は再開できる形で実行する。
モデルと索引は `.rag-poc-data/`、調査結果は `docs/research/rag-validation-remaining-2026-11-04/` に保存する。
原資料の移動、複製、書き換えは行わない。

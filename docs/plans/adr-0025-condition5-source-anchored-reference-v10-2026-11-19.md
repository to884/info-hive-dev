# ADR-0025 条件5の次版で画像と出典を照合する手順

2026-11-19に作者は、画像で符号を区別できない場合だけ、描画命令とフォントのCID対応を正式な正解と独立監査の補助証拠に使うことを認めた。[決定と診断](../agent-runs/2026-11-19-adr-0025-condition5-transcription-calibrated-v2/dot-layout-v2/report.md)

主OCRの本文・枠・検出済み行、150 DPIと450 DPIの固定PNG、所属、転記の正規化、指標・95%限界・単位数・100万配置、開発と独立評価の試料境界を維持する。先行版の正解・予測・監査・判定はそれぞれ読み取り専用とする。次版の正解・予測・監査を別の成果物にする。

条件5が測るのは画像から得た主OCRの誤りに印を付ける判定である。正式な候補の推論には、固定画素、画像由来の主OCRと別読み、その枠・画素・確信度だけを使う。PDFの文字層や符号、出典確認の成果物は正解側に留める。評価前に実装から特徴の全入力をたどり、描画を変えず文字対応だけを変えた対照PDFで、特徴と印が変わらないことを検査する。入力の分離を確かめられない候補は正式判定に進めない。

## 画像だけで区別できない箇所

対象は、離れた小点が一定の高さ・間隔で並び、固定画像では字と字の境目を識別できない点線と、見える丸形からU+2022とU+30FBを識別できない丸印に限る。画像担当の両者が見える位置・所属と形を確かめ、符号を区別できる視覚的な手掛かりがないと判断した場合に限る。実資料では候補字種、フォント・形状・点の並びを証跡に残す。見える字の違い、境界の所属、本文が読めない事例は従来の画像の二読で扱う。対象を追加する場合は作者の確認を得る。正規化は維持する。

1. 補助証拠の担当は、元PDFのSHA、描画命令、使用フォントのオブジェクトと符号対応、固定画像との座標または隔離再描画の一致を検査する。既存正解、主OCR、印、スコア、画像担当の転記は渡さない。根拠にできる符号は点線と丸印に限る。正常なToUnicodeがあるときは使用した対応を記録する。ToUnicodeが壊れている場合は、Adobe-Japan1のように公開登録され、使用されたフォントが宣言するコレクションに限り、その対応と固定画像の字形に描画命令が一意に結び付くことを確認する。Adobe-IdentityのCID単独、対応表の文字列単独、位置が近いグリフ単独では参照不足とする。コレクション、埋め込みの対応、実際の描画に矛盾があれば保留する。
2. 二系統の画像担当は、固定PNG、枠、軸と座標だけを独立に受け取る。周囲の全文、点の位置、枠への所属、形を各自で確認する。符号を分けられない場所は、行の本文と分けて物理的な点列か丸印として記録し、元のどの画面で点列の端を確認したかも返す。画素の拡大と切り出しは枠と共通の分割規則で作る。点群の検出結果、点の個数、符号、元PDF、既存票、主OCRを渡さない。点の個数は画像担当の票から独立させ、固定画素の連結成分と走査線の二つの実装から数え、両者の位置・個数を照合する。
3. 周囲の全文、位置、形と所属の二票が一致し、票と別に計測した点の位置と個数が出典の描画範囲と一致した場合だけ結合する。読取は正解生成でも監査でも、固定した一版の各行につき二系統各一度。判読結果、符号の区別の判断、所属、出典が割れた行はその版では未決定とする。再送が必要な技術失敗は原票と理由を保持し、有効な回答を受けた行を再送しない。旧監査の不一致はそのまま残す。監査には旧票や新正解の生成票を再利用しない。

## 正解の候補と記録

公開8,822行に同じ適格性の判定を適用する。画像と描画資料から候補を特定し、印、正誤、得点、旧転記に記号が含まれるかで対象を決めない。別版の正解では、生の領域正解、画像補充、出典情報、採用した有効正解を追跡できるようにする。覆われた描画のない空行と、判読や符号が決まらない行を区別する。

既存の目視で `eyecheck` により除外した本文を、出典の符号が分かることを理由に当て直さない。`garbled` に含まれる壊れた箇所のうち出典から補えるのは、画像で区別できない点線と丸印だけ。他の字の判読と所属は画像の二読で決め、決められなければ未決定にする。診断184行の一覧は開発記録として保持し、正式な候補は全行に適用した適格性の判定で決める。その判定と診断の重なり、対象外の理由を記録する。

まず、論点の異なる公開の開発用行を別版に事前固定し、画像票の表現、読み手への非開示、出典の照合と保留が機能することを検証する。点のあることだけを根拠に符号を挿入する誤判定、枠外の点の混入、字種が確定できる事例の誤置換を確認する。候補・予測・方法・直接参照した行を固定する前に、次の正式監査の候補行を計算しない。

## 採点と独立監査

新しい正解を別版に固定したら、まず既存の印で採点し、次に固定設定を出版物LOPOで再学習する。未決定を含め、既存の単位別・印ありなしの全配置で判定する。配置数が100万を超えた組は全配置の判定を行えない。開発6組と公開3組の追加条件、および正式な二つの品質監査を通過してから、最終モデルと製品の判定の一致を確認し、未使用資料で一度ずつ測る。

新しい確認の対象にした行は、画像の二票と必要な出典証拠が一致したとき、その結果を最優先とする。二票か出典が足りない場合は未決定とする。対象外の行は元の優先順と旧結果を引き継ぐ。旧版・次版の確定、未決定、確定値の変更を公開組、印の有無、正解の出所ごとに集計し、監査の分母の変化を報告する。既知から未知に移った行も評価行と未決定配置に残す。

二つの監査の母集団は、次版で生の領域正解が確定した行と、次版の有効正解を画像で補充した行とする。領域正解の監査は生の領域本文と主OCRの正誤、画像補充の監査は有効な画像正解と主OCRの正誤を使い、次版で固定した予測と合わせて層を作る。画像補充の未決定層も従来どおり抽出し、既知の正解の一致率とは別に報告する。旧監査の結果に基づく行の除外や母集団の混合をせず、標本数、重複処理と三値判定を維持する。抽出前に層ごとの分母と根拠のSHAを固定する。

監査用の出典確認は、正解生成の抽出器、画素照合コード、途中の成果物を使い回さず、別のPDFの命令抽出器とAdobeの一次の文字対応表で再検査する。位置や字形の対応を別実装と固定画素で確かめ、裏付けが足りない場合は参照不足とする。埋め込んだ対応と宣言に矛盾がある対照と、登録外のCIDの対照を開発時に使い、検出できる矛盾と根拠不足を保留できることをテストする。符号の資料自体は元PDFとフォントの宣言を共有するため、作成者が意図した符号と宣言が食い違い、描画も同じ形の場合までは検出できない。監査の一致、誤り、不一致、参照不足を区別し、補助証拠を使った行数と使わなかった行数も報告する。作者の決定の対象外の字形には従来の画像二読を適用する。

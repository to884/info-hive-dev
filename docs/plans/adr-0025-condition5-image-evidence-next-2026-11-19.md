# ADR-0025 条件5の次版で試す画像の確認方法

[15行の診断](../research/adr-0025-condition5-reference-audit-rootcause-v9-2026-11-19.md)をもとに、連続記号の脱落と箱の境界で判断が割れる原因を調べる。ここで確認するのは診断手順の再現性と、次版の正解補充を検討できるかどうかである。正誤の定義、固定150 DPIでの所属、読みの独立性、正規化、二系統一致、採点、評価行と100万の上限は既定どおりとする。

## 開発時の診断手順

1. 枠あり・枠なしと450 DPIで、行頭・行末、連続記号、境界をまたぐ字を探す。固定150 DPIの枠なし画像では、画素の比較ができるよう候補の外側も見える窓を選ぶ。窓は3倍表示の座標で指定し、元の整数座標へ戻す。範囲は右端と下端を除く半開区間とする。
2. 診断担当が固定した試作を実行する。入力のPNG、一覧、試作のSHAを保存する。窓の周囲を短辺の長さだけ広げた領域の輝度中央値を背景とし、差が64を超える窓内画素の8連結成分を列挙する。選んだ成分の包絡で割当軸の重なりと直交中心を測る。選んだ成分が窓端に接すると値が出ない。選ばなかった成分が窓端に接する場合も、窓を広げて同じ字の断片でないかを確認する。濃い背景と網掛けでは、中央値と対象画像を比較し、背景とインクや同じ字の断片を区別できない場合は診断を保留する。
3. 丸印や点線の位置と個数を記録する。位置と個数だけからコードポイントを確定できない。色付きの凡例見本は元のカラー画像と他の色見本の配置で識別し、文字か図形かを区別できない例は診断で保留する。グレースケールの測定値から図形の種別を判定しない。異体字、回転した短い領域、縦列をまたぐ箱の列順も今回の測定で残る問題である。
4. この測定は監査後の診断専用とする。監査票・補充の正解を直接更新せず、独立した監査の担当へ成分や結論を渡さない。次に試す補充の指示は、画像に写る連続記号の位置と個数を提出前に確認する手順に限定する。割当と字種の判断は既定の指示を適用する。補充側の変更で生じた既知→未決定の行も記録する。

## 次版の検証

- 診断済みの行と合成の反例で、窓の狭い濃い図形、隣の字片、複数成分からなる字を再検証する。窓や成分の選択で測定値が逆転する例を記録する。目視と文字層を併用した診断結果には出典を付ける。
- 正解の作り直しに進む場合は、結果を見る前に対象を全行へ適用できる規則で定める。正解、更新の出典、方法、固定予測と正解更新後のLOPO予測を別版に保存する。100万を超えた評価の組は、現行の判定どおり全配置未測定とし、通過扱いにしない。現時点の固定した印では、最も有利な解消箇所を仮定しても、evaluationで8行、evaluation3で23行の解消が配置数だけを満たす最小数になる。
- 次の正式監査は、画像確認の規則を対象全体で改訂し、別版の正解・予測・方法・開発で直接参照した行一覧をSHAで固定した後に一度だけ抽出する。領域 `2026111901`、画像正解 `2026111902` を既存履歴で未使用と照合する。種は計画上で公開済みなので、固定前に候補行を計算しないことと、抽出を実行した順序を記録する。母集団、層、抽出数、重複行、担当の独立性と合否は既定の指定を適用する。公式集計には抽出された開発既知行も含め、該当数と結果を補足する。過去の各版の監査結果も保存する。
- 定めた監査手順では、監査の担当に旧正解、開発診断や補充側の確認指示を渡さない。v9と同じ画像ファイルの構成と指示を使う。丸印のように画素からコードポイントを一意に決められない場合は、公式の不一致や参照不足が残り得る。未使用資料は既定の関門を通過してから扱う。

今回の診断は既知の行の測定と配置数の感度の確認までを対象とする。次版の正解を作り始める前に、補充側の指示で連続記号の脱落を減らせるか、正式評価には使わない画像による試験で確かめる。

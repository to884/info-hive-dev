# CLAUDE.md

Repository guidance for coding agents lives in **[AGENTS.md](AGENTS.md)**. Read that file.

It is the canonical instruction file for this repository: what the package is, its progressive-disclosure architecture, the helper scripts and their guarantees, how to run the tests and evals, and the hard constraints on frontmatter, licensing, and the generated `manifest.txt`.

This file stays a pointer on purpose. Two near-identical instruction files drift — the previous pair did, and one of them ended up claiming the package must load in "Codex, Codex, and Pi". `tests/test_package.py` enforces that this file remains a pointer rather than a second copy.

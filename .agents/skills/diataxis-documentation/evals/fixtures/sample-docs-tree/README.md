# sample-docs-tree

A deliberately imperfect four-page documentation set, used as an eval fixture.

Known problems, for grading: no tutorial with observable results, no task-shaped how-to guides, a reference page carrying rationale, an operations page with a destructive command and no warning placement or rollback, a dangling "see the API docs" pointer, and no explanation of the delivery model. The `getting_started.md` page mixes at least three user needs.

# 記事のリンクを拒否した wiki 0.31.0 のリリース

ADR-0029 段階1を実装し、wiki 0.31.0 として公開した。プラグインの PR は to884/info-hive-wiki#88、main のマージコミットは `b360f23934f8a2b9768f33e1a72338c72c116140`。注釈付きタグ `v0.31.0` はこのコミットを指し、GitHub リリースも公開した。親の試験と記録は to884/info-hive-dev#173 にまとめた。

## 変更した読み取りの規則

wiki の記事と途中の道がシンボリックリンク、ジャンクション、名前の代理のリパースポイント、ハードリンクなら、読まずに理由を知らせる。wiki の根そのものと、その祖先のリンクは許す。名前が `.` で始まる項目は記事に含めない。raw のリンクの検査は段階2であり、この版では実装していない。

外の別名を `realpath` で一度に解くと、wiki 内の禁止したリンクの先まで解いて、wiki の所属を見失う経路があった。別名を1つずつ展開し、既知の根で止め、残りを記事を読む口に渡す形へ変更した。外のファイルの別名も同じ扱いにした。循環や、所属を決められない行き先は理由を返して止める。

lint、browse、グラフは拒否したページを欠落や同名の別ページへの参照に置き換えない。Index の行ではパスで指す索引の記事も拒否を表示する。本文と `sources:` はページだけを対象にし、索引への誤参照をリンクの配置で隠さない。

## レビューと試験

Astra 第6回の採用後、main の Codex、図の描画、Playwright 対応を統合した。統合後は Opus の敵対的レビューで、別名の連鎖、診断の表示、出典とグラフの扱いを直した。最後の文脈の分離は、Opus の利用上限により Astra で独立に確認し、採用可（確信度中）だった。Astra の指摘した試験範囲の限界は、実ディレクトリのリンクから Snapshot、Core、HTML、lint を通す追加確認で補った。

公開前の CI は、プラグイン4、親の走査6、browse4、MCP1、PDF6の全21ジョブが成功した。走査とリンクの試験は Linux、macOS、Windows と Python 3.12 / 3.14 で行った。POSIX の実ファイル名、相対的な別名と循環も実行した。

補助的な検索の backlinks と判定レイヤーの mention には、拒否した記事と同名の読める別ページへの参照の整合性の残件がある。禁止した記事を読む迂回ではない。検査後の同時の置き換えを完全に防ぐものでもない。

## 公開と導入の確認

最初に予定した 0.30.0 は、並行作業の Playwright 対応が先に公開した。その main を取り込み、今回を 0.31.0 に変更した。比較リンクも両方の版に合わせた。マージ直前にもタグと main を取り直した（[[リリースの確かめ方]]）。

使い捨ての設定で、Claude Code と Codex の `wiki@info-hive` 0.31.0 を導入した。Claude Code は変更28ファイル、Codex は重要な7ファイルがタグと一致した。Codex のスキルと7個の MCP ツール、統計、日本語検索が動き、試験用の wiki は読み取りの前後で変わらなかった。スキル単体も `npx skills add` で導入し、全164ファイルがタグと一致した（[[リリースごとの導入の確かめの記録]]）。通常の設定は変えていない。

Codex の最初の確認では、検証後の一時ファイルのロックで後片付けに失敗した。検証の証拠を先に保存し、後片付けだけを期限付きで再試行するよう開発用のヘルパーを直した。再実行は削除まで成功し、最初に残った一時ディレクトリも削除した。

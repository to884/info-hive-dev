# Box Drive 2 台で競合した wiki の復旧試験

Windows 11 ホストと Hyper-V の Windows 11 VM で生じた競合コピーを使い、同じ検証用 wiki を復旧した。両端末で Box Drive を起動し、復旧版の書き戻しと競合コピーの移動はホストから行った。[[box-driveの2クライアント同時再接続-2026-11-20]]

## 統合と再同期

1. Box の外に、共通版、正規名に残った VM 版、実際の競合コピーに残ったホスト版、記事 2 本を保全した。競合コピーの SHA-1 と SHA-256 は、前回のホスト編集後の値と一致した。
2. 保全した 3 版を照合し、`index.md` に北と南の記事の更新後の要約を 1 件ずつ残した。`log.md` は初期化の記録を残し、ホストと VM の操作を 1 件ずつ加えた。統合版の書き戻し前と退避後にホストで BM25 検索を行い、両記事を検索できた。lint のリンク切れと重複スラッグは 0 件だった。
3. ホストから統合した `index.md` と `log.md` を正規名で書き戻した。保存開始から約 26 秒後の観測で、両端末と Box API の SHA-1 が一致した。両端末の SHA-256 も、それぞれ書き戻し前の統合版と一致した。
4. 照合後、競合コピー 2 本を検証フォルダー内の、`wiki/` と同じ階層の `recovery-archive/` へ移した。退避開始から約 44 秒後の観測で、退避した 2 本も両端末と Box API の SHA-1 が一致した。両端末の wiki 内に別名コピーはなく、記事 2 本の SHA-256 は復旧前と一致した。

約 26 秒と約 44 秒は今回の 1 回の観測値である。

# Box Drive で同じサイズと更新日時の別内容を検出した試験

前回と同じ Box Drive 上の検証用 wiki、Windows 11 ホスト、Hyper-V 上の Windows 11 VM を使った。対象は `concepts/guide.md`、`index.md`、`log.md`。前回の確定版と同じ照合用 JSON を使った。[[box-driveの排他ロックによる引き継ぎ待機-2026-11-21]]

VM のログを Box 外に保全した。ASCII 文字を 1 バイト置き換え、同じ `log.md` に書いた後、`SetLastWriteTimeUtc` で元の最終書き込み時刻にそろえた。照合の直前と直後に、Windows が返したファイルサイズと時刻を読み直した。最後に元のバイト列と更新日時を戻した。

## 実測結果

| VM のログの状態 | サイズ | 更新日時 | SHA-256 | 判定（終了コード） |
| --- | --- | --- | --- | --- |
| 変更前 | 874 バイト | 2026-11-21 18:18:43（日本時間） | 一致 | 引き継ぎ可（0） |
| 1 バイト変更後 | 874 バイト | 変更前と同じ | 不一致（`mismatch`） | 待機（1） |
| 元の内容に戻した後 | 874 バイト | 変更前と同じ | 一致 | 引き継ぎ可（0） |

記事と `index.md` の SHA-256 は全段階で一致し、競合コピーは 0 本だった。変更後のログの SHA-256 だけが確定版と異なっていた。復旧後は VM とホストの両方で 3 ファイルが一致し、再照合でも「引き継ぎ可」だった。試験は VM の `log.md` で 1 回行った。

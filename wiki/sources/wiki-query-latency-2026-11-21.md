# wiki の検索と候補提示の測定結果

2026-11-21 に既存のベンチマークと試験コードを照合した。下の値は各試験の実測値で、計測日と対象を併記する。

| 測定日 | 計測区間と条件 | 結果 |
| --- | --- | --- |
| 11月6日 | 起動・索引作成済みの MCP 中継からハイブリッド検索、Windows 11・16 論理コア、日本語53問と英語32問を各3巡 | 日本語159回の中央値29.92 ms、p95 38.01 ms。英語96回の中央値30.04 ms、p95 35.33 ms |
| 11月6日 | CLI を毎回起動、依存・モデル取得と索引の初回作成は済んだ状態、各言語の先頭15問 | ハイブリッドの p95 は日本語3.927秒、英語3.625秒。語彙検索の p95 は日本語218.32 ms、英語241.74 ms |
| 11月6日 | MCP の初回。依存とモデルは取得済み | 中継の initialize は1.688秒、サーバー起動を含む最初の tools/list は2.356秒。モデル読み込みと英語103セクションの初回埋め込みを含む最初の query は3.588秒 |
| 11月18日 | wiki v0.33.0 の候補フック、合成150ページ | 逐次10回は p95 551.0 ms。フック4本同時で合成負荷8本・明示参照、16本・明示参照、16本・題の一致の順に p95 957.2、1,265.9、1,189.7 ms。各条件20回すべてで2候補が届いた |
| 11月19日 | 公開版の解決、固定版内の語彙検索、根拠ページ取得を一続きで計測。公開195記事の合成 wiki、Windows ローカル NTFS・NVMe SSD | 同時保存1件の試験は読み取り10件成功で最大11.40秒、4件は33件成功で最大10.71秒、8件は68件成功で最大27.25秒 |

> 表 補足: p95 は試行の95パーセンタイル。公開版の値は各条件で観測した最大値。MCP と CLI の値を比べるときは、CLI が毎回起動することと、両者の検索構成の違いを考慮する。

## 確認できた範囲

各試験は回答生成の前に終わる。現行版で質問送信から回答完了までを測った p95 は、照合した性能記録では確認できなかった。公開版の読み取りには保存の最終照合と重なった標本がある。値はこの試験で観測した最大であり、本番の分位点は未判定である。

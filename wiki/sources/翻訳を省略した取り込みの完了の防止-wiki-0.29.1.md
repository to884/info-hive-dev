# 翻訳を省略した取り込みの完了を防ぐ wiki 0.29.1 の修正

翻訳が必要な Web raw に `--language-override keep` を指定し、英語のまま保存した状態を完了としていた。日本語の要約があっても raw の翻訳の代わりにはならない。プラグインの修正は to884/info-hive-wiki#87、回帰試験と記録は to884/info-hive-dev#171 で扱う。

## 完了を決める記録

W8 の JSON に `translation` と `completed` を追加した。`ok: true` は検査に誤りがないことを表し、`completed: true` は必要な警告の確認を終え、`--finish` が成功した場合だけ返す。フォルダーの消失や翻訳者名から完了を推定しない。翻訳必須の `keep` はエラーとなり、`--accept-warnings` でも完了できず、比較元が残る。

警告を受理する場合は、wiki の更新より前に `prepare` の記録に理由を書き、実際の完了の JSON を確認する。raw の確認を終える前に取り込みの完了を記録しない。この区別を Claude Code、Codex、raw のエージェント、セッションの監査でそろえた。

## レビューで変えた判定

初回の Opus のレビューでは、日本語の文字数の割合による判定が崩れた。製品名を英語で残した正しい見出しは拒み、段落の後半の英語や中国語の近似コピーは通していた。名前を推定して文章から除く方法も、各語を大文字で始めた文章を取り逃がした。

文や節の外国語の残存を調べる方式に替えた。2 回目のレビューでは他の文字体系の丸残しと、表示文字列などの誤検出が見つかった。Unicode の語で原文の文を照合し、名前、表示文字列、原語の併記、短い説明と見分けられない句は、具体的な保持の理由が必要な警告に分けた。文章を調べた `checked` と、コードや画像だけの `no_prose` も区別する。これらは典型的な翻訳の省略を止める簡易検査であり、訳の意味や完全性を保証しない。訳文の読み直しは手順に残す（[[エージェントに守らせる決まりの書き方]]）。

## 検証

関連テスト 242 件と encoding の静的検査 60 ファイルが成功した。保存済みの記事を一時 wiki に置く検査では、英語のままの 2 ケースは未完了で比較元が残り、日本語版は既知の警告 4 件を確認して完了した。実際の raw の内容は変えず、ハッシュも記録した。

# wiki 0.16.0（セッションの取り込み）のリリースの記録

wiki 0.16.0（`/wiki:ingest session` で Claude Code のセッションの会話を取り込む変更）の、タグと GitHub リリースの記録である。設計は [[セッションの取り込みの設計-2026-11-14]]、設計と確かめの原本は `docs/agent-runs/2026-11-14-wiki-session-ingest/` にある。このページは、リリースの作業の記録から書いた。

## 経緯

1. 子の PR（to884/info-hive-wiki#59）と親の PR（to884/info-hive-dev#107）が 2026-11-14 にマージされ、wiki の main は 0.16.0（マージコミット `8c400d7`）になった。タグと GitHub リリースは作られなかった。
2. 先に、追い越されていた 0.15.0 をリリースした（[[追い越された版のリリース-wiki-0.15.0]]）。
3. 作者の依頼で 0.16.0 をリリースした。作る直前に、`origin/main` がまだ `8c400d7` で、`plugin.json` が 0.16.0 であること、`v0.16.0` のタグとリリースがないことを取り直した。0.17.0 の PR（to884/info-hive-wiki#60）は、まだオープンだった。
4. 注釈付きのタグ `v0.16.0`（`v0.16.0: Claude Code のセッションの会話を /wiki:ingest で取り込めるようにした`）を `8c400d7` に付けて push した。GitHub リリース `v0.16.0` を Latest として作った。本文は CHANGELOG の 0.16.0 の節である。
5. 使い捨ての設定でマーケットプレイスから入れ、0.16.0 が入ることを確かめた（[[リリースの確かめ方]]）。v0.15.0 から v0.16.0 までに変わった 9 のファイルの SHA-256 が、すべてタグの中身と一致した。入った `wiki_session.py` の `--help` が動き、8 つのサブコマンド（`locate`〜`scan`）を出した。

# YouTube の取り込みを使い捨ての wiki で試した結果と wiki 0.23.2 のリリース

wiki 0.23.0 で出した YouTube の字幕の取り込み（[[youtubeの字幕の取り込みの実装とリリース-wiki-0.23.0]]）を、使い捨ての wiki で手順（`commands/ingest.md` の V1〜V10）どおりに最後まで通した。この記録は、その結果と、見つけた 2 つの不便を直して出した wiki 0.23.2 のものである。レビューの記録は `docs/agent-runs/2026-11-16-wiki-0.23.2-review/` にある。

## 試したこと

- **素材**：東京大学の 45 分の模擬講義の動画を使った。自動字幕は 692 行で、チャプターは 5 つある。初期化した空の wiki に取り込んだ。
- **V2〜V5**：自動字幕のトラック（`asr:ja-orig`）が選ばれ、raw は読み取り専用で置かれた。
- **V7**：要約ページと、コンセプトのページ「ギュゲスの指輪」を書いた。訂正は 3 件である。
  - 名乗りの聞き違いは、根拠を `metadata:title` にした。
  - 生年は、根拠を `model` にした。
  - 「技術の指輪」は、根拠を `caption:L647` にした。この訂正には、関係するページの印も付けた。
- **V8**：`verify` は 1 回目で指摘なしに通った。confidence は `medium`（重み 5、疑いの率 0.72）だった。
  - 印をわざと外した版では、使われていない定義と「raw にない語」（`アカデメイア`）が挙がった。
- **V9〜V10**：書いたあとの lint も、`verify` も、指摘は 0 件だった。
- **字幕の質**：聞き違いは多かった（`ポリ艇や`、`ありステルス` など）。ただ、wiki に書く語は字幕の正しい箇所から選べたので、訂正は 3 件で済んだ。confidence は「書いた語が訂正にどれだけ頼るか」を測るので、聞き取りの悪さそのものは数えない。
- この試しでは、ユーザーとの話し合いと承認の段は省いた。

## 見つけた不便と直し

| 不便 | 直し |
| --- | --- |
| 要約ページの `fetched_at` を書くのに、時刻を別に取る必要があった | `inspect` と `write` が、字幕を取った時刻 `fetched_at` を返す |
| 「raw にない語」に、`## 主張と行き先` の表の行き先の値（`create`、`source_only` の `only`）が混ざった | 表の「行き先」の列で、中身がちょうど `create`、`update`、`source_only` のセルだけを探さない |

> 不便と直しの表 補足: どちらも、手順どおりに 1 本を最後まで通して初めて分かった。レビューと単位の試験では見つからなかった。

## レビューで分かったこと

Sol の敵対的レビューは 3 回で、外す範囲を 2 度絞り直した。進め方は [[敵対的レビューで設計を直す進め方]] と同じである。

1. **節をまるごと外した（条件付きで採用可）**：表の主張も目印から隠れた。表の中の印のない訂正（`999 人`）が挙がらなくなった。
2. **字面で外した（条件付きで採用可）**：本文の「命令は update である」の `update` も消えた。
3. **表の「行き先」の列のセルで、中身がちょうど値のものだけを外した（採用可）**：列は、同梱のパーサーで表の見出しから決める。外す処理を無効にすると落ちる試験も足した。

ADR-0027 は承認済みなので書き換えず、この除外は `ingest-workflow.md` と CHANGELOG に書いた。

## リリース

- 版は 0.23.2 にした。0.23.1 は to884/info-hive-wiki#75 が名乗っていた。作業のあいだに #75 がマージされたので、main を取り込み、CHANGELOG で 0.23.2 の節を 0.23.1 の上に置いた。
- `v0.23.2` は注釈付きのタグで、#76 のマージコミット（`beced3b`）を指す。GitHub リリースの本文は、CHANGELOG の 0.23.2 の節と同じである。
- 使い捨ての設定フォルダーで、マーケットプレイスから入れると 0.23.2 が入った。v0.23.1 から変わった 6 つのファイルは、すべてタグの中身と一致した。
- 親の PR（to884/info-hive-dev#152）は、ほかの PR が main に入ったので競合した。origin の main を取り込んで解いた。

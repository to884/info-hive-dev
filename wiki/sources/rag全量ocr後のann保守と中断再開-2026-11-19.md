# 全量 OCR 後の ANN 保守と中断・再開の検証

[[info-hive-rag]] の保存済み OCR を使い、Windows の全量テーブルで ANN の自動作成・追加時の更新と、3 箇所の中断・再開を確認した。
2026年11月19日に開始し、20日 00:12 に最終監査を終えた。
実行と証跡の詳細は `docs/research/rag-full-ann-2026-11-19.md` にある。

## データと範囲

905 文書・245,346 ページのうち OCR は 22,335 ページだった。
783,117 チャンクを作り、628,400 チャンクは同じ入力の既存ベクトルを使い、異なる新規入力 154,616 件を GPU で埋め込んだ。
本文・ベクトル・公開台帳を一括準備した後、実 MCP の登録から製品の索引保守を起動した。
905 文書の個別 MCP 取り込みを最初から繰り返した試験とは区別する。

## 中断と再開

- ANN 作成中と追加時の索引更新中に MCP を終了し、未コミットであることを版と pending で確認した。
- 差し替えは公開確定後、旧 440 行の削除前で止めた。物理行が残っている間も旧世代は検索対象に出なかった。
- 3 回とも同じジョブ ID の 2 回目で完了した。再開側の文書の埋め込み計算を禁止し、保存済みベクトルの再利用を確認した。
- 最終 783,645 行について ANN・全文・世代の索引が全行を網羅し、未索引行、重複行、旧世代、保留した後始末は 0 だった。

全量の実 MCP 45 項目は成功した。
Windows の回帰試験は 75 件成功、Linux は 73 件成功・Windows 専用 2 件スキップ、小規模な実 MCP 11 項目成功だった。
OS の電源断・再起動と WSL の停止は行っていない。

## 最終監査と制約

全 245,346 ページのファイルと準備時の文書台帳、既存ベクトル、中断前に確定済みの新規ベクトル 79,900 件をハッシュで照合した。
原本 914 箇所のサイズと更新日時は固定目録と一致した。原本全体の内容ハッシュの再読は行っていない。
既知 OCR ページ 3 件の実 MCP 検索、CPU の参照ベクトル 16 件、ANN 単独と全件走査の比較 8 件も成功した。
検索は nprobes=128 であり、既定の 20 の品質評価や人手の質問評価とは区別する。

基準は `4fabe32` と今回の未コミットの修正である。
公開後の後始末の対象を永続化し、行を消す前に再開位置を無効にする順序へ直した。
実 LanceDB の反例と回帰試験で確認し、Opus の製品修正のレビューと最終監査の再レビューは承認された。
[[info-hive-ragのアーキテクチャ-4fabe32]] は修正前の固定コミットを説明している。

この試験時点では、退役文書の再登録で OCR を再実行する場合と、索引リセットで未使用の抽出キャッシュが残る場合が Minor として残った。
その後の修正と検証は [[ragのocrキャッシュの再利用と回収-2026-11-20]] に記録した。
コミット・リリース、全量の Linux 試験、配布用 uv 起動の再試験は今回の範囲に含めていない。

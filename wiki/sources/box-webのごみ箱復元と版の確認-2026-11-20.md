# Box Web のごみ箱から元の記事を復元して版と同期を確認

ホストのオフライン削除と VM の編集が競合した試験を引き継ぎ、同じ検証用 wiki の `wiki/concepts/guide.md` を復元した。前回、ごみ箱に入った元の記事は VM の編集済み版を含んでいた。元のパスには、VM の保全コピーから作った別の Box ファイル ID の記事があった。[[box-driveの記事削除と編集の競合と復旧-2026-11-20]]

## 退避と復元

1. Box Web のごみ箱には同名の `guide.md` が 2 件あった。詳細の削除時刻 8 時 32 分とサイズ 270 バイトを、対象記事の Box Drive の記録と照合した。
2. 作り直した記事を、`wiki/` の外にある `recovery-archive/guide.recreated-before-trash-restore.md` へホストから移動した。退避先へ同じ Box ファイル ID と内容が移り、元のパスがホストと VM の両方で空いたことを確認した。
3. Box Web で対象 1 件を選んで復元した。Box Web で復元完了が表示され、元の `concepts/` フォルダーの `guide.md` から元のファイル ID のプレビューを開けた。 [Box のごみ箱の管理](https://support.box.com/hc/en-us/articles/360044196093-Managing-Trash)

## 照合結果

| 確認対象 | 結果 |
| --- | --- |
| 元のパスと Box ファイル ID | 復元前の元の記事と一致した。退避した記事も作り直したときの別の ID のまま残った。 |
| 現行版 | Box Web の表示は V2。Box API 応答の現行版のバージョン ID は、削除前の VM 編集版、ごみ箱内、復元後の 3 時点で一致した。 |
| 旧版の履歴と本文 | 削除前の Box API 応答では初版と VM 編集版のバージョン ID は別だった。復元後の版履歴パネルは現在のプランで利用できないと表示された。V1 が復元後も取得できるかは未確認。 |
| 両端末への同期 | Box Web で復元を確定してから約 44 秒後の照合で、ホストと VM の SHA-1 と SHA-256 が VM のオフライン保存版に一致した。Box API の SHA-1 と Box Web の本文でも VM の変更を確認した。 |

約 44 秒は操作確定から照合した時点までの時間である。試験用 wiki の lint では、復元後のリンク切れは 0 件だった。 [Box の版履歴の確認方法](https://support.box.com/hc/en-us/articles/360043697054-Accessing-Version-History)

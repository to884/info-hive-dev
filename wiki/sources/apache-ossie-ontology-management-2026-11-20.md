# Apache Ossie の公式仕様と info-hive への適用範囲

11月19日の公式仕様調査、設計、一方向の書き出し、移行・実行の試作を踏まえ、11月20日に上流本体 `344259a` と変換器 `92e6c57` を再確認した。Ossie は Apache Incubator のプロジェクトで、公式配布ページにはリリースがなかった。

## 調査で確認したこと

- Core はデータセット、列、結合、指標を定義する。Ontology では実体型、役割付きの多項関係、複合識別子、制約 `requires` と導出 `derived_by` を宣言できる。Mapping は Core の列を実体と関係に対応付ける。
- 最新の公式検証器は既存の7バンドルの計21文書を受理し、存在しない列を参照する負例を拒否した。変換器は独立 Mapping と新しい `annotations` を含む公式 FOAF 例を拒否した。info-hive 独自の DuckDB アダプターなどの回帰16件は通過した。外部エンジンの実データ実行は今回の試験範囲外。
- 一方向の交換形式として使える。型・関係・識別規則の正本への採用は、互換グラフと実際の消費先で評価する。主張・根拠・旧 ID の履歴、名寄せ、承認付き移行と公開は info-hive が担う。本プロジェクトの wiki はライブ状態で、公開版は有効化されていない。

# Box Drive で最終照合後に変更したログが直後の再実行で検出された試験

前回と同じ Box Drive 上の検証用 wiki、Windows 11 ホスト、Hyper-V 上の Windows 11 VM、照合用 JSON を使った。対象は `concepts/guide.md`、`index.md`、`log.md`。元のログは VM の Box 外に保全した。[[box-driveの2回目の照合による変更検出-2026-11-21]]

VM の計測用ラッパーから通常の照合処理を呼び、1 回目と 2 回目の両方で全件一致したことを記録した。2 回目の読み取りが終わり、判定を出す処理が始まる前に、別プロセスで Box Drive 上の `log.md` を変更した。VM の計測時刻でこの順序を確認した。変更した内容が残っていることを確かめ、直後に通常のコマンドを再実行した。

## 実測結果

| VM での実行 | 照合結果 | 判定（終了コード） |
| --- | --- | --- |
| 2 回目の照合後、返却前にログを変更した実行 | 2 回の読み取りでは 3 ファイルとも一致 | 引き継ぎ可（0） |
| ログの変更を残したまま直後に再実行 | 記事と索引は一致。ログだけ不一致（`mismatch`） | 待機（1） |
| 元のログへ戻して再実行 | 3 ファイルとも一致 | 引き継ぎ可（0） |

最初の実行は、2 回目に読み取った内容を使って判定を返した。元のログを戻した後は、ホストと VM の再照合でも 3 ファイルの SHA-256 が一致した。競合コピーは観測した全段階で 0 本だった。

# raw の段を任せるエージェントの実地の確かめ（2026-11-14）

wiki プラグイン 0.15.0 で足すエージェント `wiki:web-raw`（`model: sonnet`）に、`/wiki:ingest` の raw を作る段を任せ、要約ページから後をメインのモデル（Opus 5.5）で行ったときの記録である。原本は `docs/research/wiki-web-raw-agent-trial-2026-11-14.md`、確かめの結果の JSON は `docs/agent-runs/2026-11-14-wiki-web-raw-agent-review/` にある。設計は `docs/plans/wiki-web-raw-agent-2026-11-14.md`。

## 進め方

- 一時の wiki で、`claude -p "/wiki:ingest <URL>" --plugin-dir <info-hive-wiki> --model opus` を動かした。ページは CQRS（英語）と、ブルームフィルタ（日本語の Wikipedia）。
- セッションの記録（メインと、エージェントの記録）と、Claude Code がエージェントの記録の横に書くメタデータ（`agentType`、`launchedWithDefaults`、`prefix.json` のモデル）を、`tests/wiki/check_web_raw_agent.py` で調べた。

## 分かったこと

- どちらのページも、記録から確かめた 14 項目がすべて通った。メインは `model` の引数を渡さずに `wiki:web-raw` を呼び、エージェントは Sonnet 5.5 で取得から `check --finish` までを行い、wiki のページには書かなかった。要約ページ、`index.md`、`log.md` はメインが書いた。
- 費用のほとんどは、後段の Opus だった。メインが相談の道具（`advisor`、Fable 5.1）に使った分を除くと、Sonnet の raw の段は全体の 1 割ほどだった。
- 取り込み全体を Sonnet で行った回より、時間はかかった。後段を Opus で行うためである。
- 記録から確かめられるのは、応答のモデルと、Edit と Write の書き込み先、スクリプトの実行までである。Bash のコマンドの中の書き込みは推し量りきれないので、合否を決めずに一覧に出して人が読む。どのモデルが文を考えたかは、証明できない。

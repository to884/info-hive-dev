# Box Drive のオフライン編集と再同期の実機検証

Windows 11 Enterprise（ビルド 26300）、Box Drive 2.56.271.0 の Cloud Files 方式、Python 3.14.6、wiki v0.38.1（`b8596d1`）で、架空の記事 1 ページと原本を使って試験した。事前に `wiki/` と `raw/` を固定し、初期化と検索モデルの準備を終えた。

## 切断中に確認した操作

Box 宛ての接続だけを一時プロキシで拒否した。Box の接続を拒否し、別に用意していたオンライン専用ファイルの読み込みが失敗した状態で試験した。

- 固定済みの既存記事と原本を読めた。既存記事、`index.md`、`log.md` を更新し、新規記事と新規原本を保存できた。
- CLI の BM25 とハイブリッド検索が、変更を保存した後の 2 記事から試験用の語句を返した。
- browse の静的 HTML 生成で 2 記事の変更後の本文を確認した。生成時の警告は 0 件。

## 再接続後の照合

元のプロキシ設定に戻した後、Box Drive が受け取った Box API のファイル版の SHA-1 を、切断中に保存した内容と照合した。既存記事、新規記事、`index.md`、`log.md`、新規原本の 5 ファイルがすべて一致した。一致するサーバー応答は、設定を戻してから約 8.4～9.4 秒で記録された。5 ファイルをオンライン専用の状態に戻して再取得し、SHA-256 でも一致した。 [Box API のファイル情報](https://developer.box.com/ja/reference/resources/file)

試験は Windows 1 台で行った。2 台目との競合、端末全体の通信切断、MCP のオフライン検索、初回セットアップ、Box Web 画面は試験範囲外である。

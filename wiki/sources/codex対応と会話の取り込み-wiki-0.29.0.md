# Codex 対応と会話の取り込み、wiki 0.29.0 の公開と導入

Claude Code 用だった wiki を Codex でも使えるようにし、会話履歴の取り込み、0.29.0 の公開、常用する Codex への導入まで進めた会話の記録である。原本は今回の取り込み依頼より前の範囲に固定し、思考、ツール結果、子エージェントの記録を含めない。以下の試験件数や成功の判定は、会話で実行者が報告した内容として残す。

## 依頼とホストごとの分担

利用者は Codex 対応を依頼し、続けてプラグインとしての導入、Claude Code との違い、会話履歴の自動取り込みを確認・依頼した（T1、T89、T92、T96）。Claude の利用上限が近いため、`ask-claude` を控えるよう明示した（T13）。以後は Codex で実装と検証を進め、Claude Code の確認ではプラグインの管理コマンドだけを使ったと報告された（T14、T326）。

検索、lint、統計、グラフ、閲覧、Markdown の保存形式と11操作の手順を共用し、ホストごとの呼び出しを分けた。Claude Code は `/wiki:query`、Codex は `$wiki:info-hive query` を使う。Codex では Claude 用の MCP のパス変数が展開されなかったため、起動設定を分けた（T34、T60、T88、T95）。

Web の取得・翻訳・画像の補足は、Claude Code では専用エージェントに委任し、Codex では使用中のモデル自身が行う。メモリの参照先も `CLAUDE.md` と `AGENTS.md` に分かれる。rag の Codex 対応は今回の対象に含めなかった（T95）。

## 会話履歴の取り込み

T88・T95 時点では自動取得が未対応だったが、T96 の依頼後に追加された。`$wiki:info-hive ingest session` で実行中の会話、`session:<ID>` で指定した会話を取り込める。Codex の読み取り API を使い、従来の保存方式とデータベース方式を読み分ける。取り込み依頼を含むターン全体より前に範囲を固定し、伏せ字、保存前の確認、承認済みハッシュの照合を既存の処理と共用した（T106、T114、T142）。

両方式で raw の保存・ハッシュ照合・読み取り専用化を実機で確認し、追加テスト36件が成功したと報告された（T133、T142）。Claude Code の JSONL の観測をまとめた [[セッションの記録の構造]] を、Codex の保存形式の仕様として流用しない。

## 公開と CI で分かったこと

当初の未公開の予定版は0.28.0だったが、別の未マージ PR が同じ版を使っていたため、0.29.0に変更した（T142、T153）。本体の [PR #86](https://github.com/to884/info-hive-wiki/pull/86)、配布カタログの [PR #6](https://github.com/to884/info-hive-marketplace/pull/6) と [PR #7](https://github.com/to884/info-hive-marketplace/pull/7)、親の [PR #170](https://github.com/to884/info-hive-dev/pull/170) を経て、[v0.29.0](https://github.com/to884/info-hive-wiki/releases/tag/v0.29.0) の公開を完了したと報告された（T167、T191、T200、T326）。

公開カタログの初回確認では、Codex が `github` 形式の配布先を認識しなかった。対応する Git URL の形式へ直し、Codex と Claude Code の両方で導入し直して、導入物とタグの一致、Codex の MCP 7ツール、日本語検索・統計を確認した（T191、T200）。公開後の導入まで確かめる点は [[リリースの確かめ方]] とつながる。

親 CI では、Playwright が対応しない Ubuntu への runner の更新と、新しい表示用 CLI の入口一覧への登録漏れが見つかった。Ubuntu の版を固定し、入口を分類して直した。17ジョブ成功の後、並行 PR と競合した説明コメントを main 側にそろえてマージした（T221、T231、T291、T299、T326）。

## 常用する Codex への導入

利用者は公開後、手元の Codex にも導入するよう依頼した（T327）。通常の設定に `wiki@info-hive` 0.29.0 を導入して有効化し、`info-hive` のカタログ登録と `wiki` の有効化だけを追加したと報告された。スキルと MCP 7ツールの認識に加え、このプロジェクトの wiki から統計を取得できた（T341、T348、T349）。

案内した入口は `$wiki:info-hive help` と `$wiki:info-hive ingest session` である。既存の Desktop のチャットへ追加したツールが自動で反映されたかまでは、この会話では確認していない。

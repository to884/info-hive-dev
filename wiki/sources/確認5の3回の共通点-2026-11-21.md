# 確認 5 の 3 回の共通点

Windows 11 の Claude Desktop 6.6395.0.0 の Code で [[info-hive-wiki]] 0.39.1 の初期化から点検までを 3 回通した。[[claude-desktopでのwiki確認5の1回目-2026-11-21|1 回目]] と [[claude-desktopでのwiki確認5の2回目-2026-11-21|2 回目]] に続き、3 回目も e5 と ruri を取得していない状態から始めた。

- 初期化の `"status": "ready"`、味噌と醤油のページ・索引の行・取り込みログ、質問の出典と確信度は 3 回共通だった。
- 閲覧の Index に味噌と醤油の要約があり、麹には両方からの被リンクが出た。3 回目は URL が返ってもペインが最初は見えず、URL をペインで開くよう追加で頼むと表示できた。
- 構造点検は 3 ページで、孤立、リンク切れ、読み込みエラーが 0 件だった。点検の呼び出し先は CLI が 1 回、MCP が 2 回。MCP は空の `tags` も指摘した。

3 回目の `/wiki:lint` では内容の点検も行った。麹のページが熟成期間の影響を色だけに限定した箇所について、原文で裏付けられるのは「熟成が長いほど色が濃くなる」までだと指摘した。指摘を出した時点で ruri は未取得で、修正は適用しなかった。[確認 5 の検証記録](../../docs/research/usage-docs-facts-2026-11-20.md#確認-5-のチュートリアル-3-回)

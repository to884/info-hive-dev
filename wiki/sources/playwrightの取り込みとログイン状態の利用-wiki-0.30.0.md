# Playwright の取り込みとログイン状態の利用、wiki 0.30.0 の公開

HTTP で本文を取れないページの取り込みに Playwright を加えた wiki 0.30.0 の記録である。子の PR は to884/info-hive-wiki#89、試験・設計・公開記録と参照の更新は to884/info-hive-dev#174 にある。子の 4 ジョブと親の 17 ジョブが成功してから子をマージし、`8cdbb75` に注釈付きタグ `v0.30.0` を付け、GitHub リリースを公開した。日付をまたいだので、公開日は 2026-11-18 とした。

## 普段のブラウザのログイン状態を使う

HTTP 401 / 403 または雑音除去後の本文が空白を除いて 500 文字未満なら、ブラウザの経路へ切り替える。Windows では OS の既定の Chrome または Edge の実行ファイルを調べ、公式拡張で接続する。既定の `existing` は、利用者が許可した、対象 URL に一致する表示済みのタブだけを読む。Cookie / プロファイルは書き出さず、新しいタブも作らず、既存のタブを移動しない。

本文内の読み込み済みの同一 origin の画像も保存する。別 origin や未読込などの画像は未取得とし、匿名で取り直さない。描画中のページは、利用者がブラウザで表示の完了を待つ。`--browser-only` は HTTP と再開を飛ばし、`--browser-session isolated` は独立したブラウザを使う。変換・翻訳・raw の検査は既存の処理を共用する。

接続には Node.js 20 以上、npm、公式 Playwright 拡張が必要である。内部実装への依存を `playwright-core@1.66.0-alpha-2026-11-09` に固定したため、更新するときは契約試験も必要になる。未対応の OS 既定ブラウザでは停止し、Windows 以外ではブラウザを明示する。

## 試験と公開の確認

Claude が利用上限だったため、利用者の指定で Astra が設計・実装・公開用の切り出しを敵対的レビューした。修正後に未解決の重大・中程度の指摘はなかった。並行中の翻訳修正（子 #87、親 #171）は除外した。

関連 Python 試験は 321 件中 319 成功、既存条件の 2 件スキップ。Node の契約 10 ケース、独立 Chromium の実機 7 ケース、ローカルの HttpOnly Cookie が必要な本文・画像を普段の Edge から取得する試験も成功した。後続の内部修正は単体・IPC の試験で確認した。プラグイン自身の CI 手順も手元で完走した。

親の Windows / Python 3.14 の閲覧試験では、静的ページの読み込みが一度タイムアウトした。試験条件を変えず、失敗したジョブだけを再実行して成功した。CI 対象の子の head とマージコミットの差分は空だった。

Claude Code と Codex は、公開カタログから一時設定で 0.30.0 を導入でき、変更した全 15 ファイルがタグとバイト単位・SHA-256 で一致した。Codex はスキルと 7 個の MCP ツールを認識し、統計と日本語検索が動いた。試験用 wiki は前後で一致し、一時設定は削除した。詳しい結果は `docs/research/wiki-playwright-release-0.30.0-2026-11-17/` にある。完了条件は [[リリースの確かめ方]]、導入の結果は [[リリースごとの導入の確かめの記録]] にも残した。

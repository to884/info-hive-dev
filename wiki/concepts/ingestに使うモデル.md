# /wiki:ingest に使うモデル

`/wiki:ingest` で Web ページを取り込むときは、Claude Sonnet 5.5 を使う。グローバルの指示（`C:\Users\toshiki\.claude\CLAUDE.md`）にもそう書いてある。2026-11-13 に Haiku 5.5 と Opus 5.5 とで比べ、Sonnet のまま使うことに決めた（[[ingestのモデルの比較-2026-11-13]]）。

## モデルが raw に与える影響

Web ページの取り込みでは、`wiki_fetch.py` が取得と Markdown への変換をし、モデルが雑音の削除、訳、画像の補足を受け持つ。raw は取り込んだあとに書き換えない原本なので、ここでの誤りは取り直すまで残る。要約ページの引用も raw から取る。PDF とテキストのソースは原本をそのまま置くので、raw にはモデルの差が出ない。

## Sonnet 5.5 にした理由

- 重大な誤訳がなく、目隠しの評価の忠実さは Opus と 0〜0.4 点の差だった。
- 時間は Opus の 1/7〜1/2 で済む。
- Haiku は、コードブロックの中身を変える、リンクを落とすなど、raw の規則を破る。速さも Sonnet と変わらない。

## 受け入れた弱点

Sonnet で取り込んだ raw には、次のような誤りが入りうる。気づいたら、raw を直さずに取り直して別版にする。

- 原文にない内容を、自分の知識で補うことがある（比較では、ページの HTML にない `<>` を補った）。
- 図の数値を読み違えることがある（照らし合わせた 9 枚中 1 枚）。
- 雑音を残すことがある（タグのリンク、重複した題名）。

## 見直す条件

- 図の多い英語のページで、補足の読み違いが目立つようになったら、英語のページだけ Opus を使う案を考え直す。
- 新しいモデルが出たら、同じ 4 ページで比べ直せる。スクリプトは `docs/agent-runs/2026-11-13-wiki-ingest-model-comparison/scripts/` にある。

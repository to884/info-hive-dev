# リリースごとの導入の確かめの記録

プラグインのリリースのあとに、マーケットプレイスから使い捨ての設定で入れて確かめた記録を、版の順に並べる。確かめの手順そのもの（使い捨ての設定、入ったファイルの場所、文字列と SHA-256 での照合、タグが遅れた版の扱い）は [[リリースの確かめ方]] にある。ここには、版ごとに、何を何件確かめ、何が一致し、ほかに何を動かしたかを書く。

- 0.9.2 でも、空の設定ディレクトリで同じように確かめた（[[グラフの抽出の修正-0.9.2]]）。
- wiki 0.14.0 では、前の版のタグからそのタグまでに変わったファイル（`git diff --name-only v0.13.0 v0.14.0` の 12）の SHA-256 を、すべてタグの中身と比べた。入った `wiki_help.py` を動かし、出したリンク先の GitHub のページが開くこと（200）も確かめた。リンク先はタグを打つまでないので、この確かめはタグのあとにしかできない（[[helpの個別のヘルプとリリース-wiki-0.14.0]]）。
- wiki 0.18.0 では、変わった 14 のファイルがすべてタグの中身と一致した。入った `wiki_browse.py` で使い捨ての Wiki を書き出し、新しい資産（`fluent2.css`、`theme.js`、`data/search.js`）が出ることを確かめた（[[browseの探しやすさとFluent2のリリース-wiki-0.18.0]]）。
- wiki 0.19.0 では、変わった 4 つのファイルがすべてタグの中身と一致した。入ったスクリプトで使い捨ての Wiki を書き出し、記事のページに新しい class が出ることを確かめた（[[browseの記事のページのFluent2のリリース-wiki-0.19.0]]）。
- wiki 0.19.2 では、v0.19.0 から v0.19.2 までに変わった 5 つのファイルがすべてタグの中身と一致した。0.19.1 で変わった 2 つは 0.19.2 で変わっていないので、0.19.1 の中身もこれで確かめたことになる。入った `wiki_evolve.py` で使い捨ての wiki に `capture` を実行し、ファイルが LF で、返した `sha256` がファイルの値と一致することを確かめた（[[captureの記録の改行の直しとリリース-wiki-0.19.2]]）。
- wiki 0.19.3 では、v0.19.2 から v0.19.3 までに変わった 4 つのファイルがすべてタグの中身と一致した。入った `wiki_browse.py` で Wiki を書き出し、ページにアイコンの宣言が出ることを確かめた（[[browseを5つのブラウザで確かめた記録とリリース-wiki-0.19.3]]）。
- wiki 0.20.0 では、v0.19.5 から v0.20.0 までに変わった 7 つのファイルがすべてタグの中身と一致した。変更は手順の文書だけだったので、動かす確かめは、リリースの前に worktree のプラグインを `claude --plugin-dir` で読み込み、3 問を問い合わせて行った（[[queryの確からしさとリリース-wiki-0.20.0]]）。
- wiki 0.21.0 では、v0.20.0 から v0.21.0 までに変わった 6 つのファイルがすべてタグの中身と一致した。依存として一緒に入る rag（main）の共通ファイル `rag_pdf_layer.py` が、入った wiki の `wiki_pdf_layer.py` と同じことも確かめた。入った `wiki_pdf.py` を公開の PDF で動かし、判定の一覧と、続きがあるときの終了コード 3 を確かめた（[[pdfの文字の層とリリース-wiki-0.21.0]]）。
- wiki 0.21.1 では、v0.21.0 から v0.21.1 までに変わった 7 つのファイルがすべてタグの中身と一致した。変更は手順の文書だけで、動かす確かめは、リリースの前に Sonnet 5.5 で 11 問を 3 回ずつ流して行った（[[queryの確からしさの決め方の分離とリリース-wiki-0.21.1]]）。
- wiki 0.21.2 では、v0.21.1 から v0.21.2 までに変わった 5 つのファイルがすべてタグの中身と一致した。変更は手順の文書だけで、動かす確かめは、リリースの前に Sonnet 5.5 で 5 問を 3 回ずつと、記録のページを含まない wiki で 1 問を 3 回流して行った（[[queryの検索の説明への外の語の漏れの直しとリリース-wiki-0.21.2]]）。
- wiki 0.24.0 では、v0.23.2 から v0.24.0 までに変わった 10 個のファイルがすべてタグの中身と一致した。変更は回答の名前を「確からしさ」から「確信度」に変えただけで、決まった 1 行の字句が変わるので minor を上げた（[[queryの回答の確信度への名前の変更とリリース-wiki-0.24.0]]）。
- wiki 0.26.0 では、v0.25.2 から v0.26.0 までに変わった 11 のファイルがすべてタグの中身と一致した。入った `wiki_browse.py` で使い捨ての Wiki を書き出し、svg が `<img>` で出ることを確かめた。0.27.0 では、変わった 17 のファイルが一致し、入ったサーバーで mermaid の図が描かれることを確かめた。to884/info-hive-wiki#71 も 0.26.0 を名乗っていたが、未マージだったので、先に main に入れたほうが版を取った（[[browseの図の描画とリリース-wiki-0.26.0-0.27.0]]）。

- wiki 0.29.0 は、Claude Code で変更 16 ファイル、Codex で重要な 7 ファイルがタグと一致した。Codex の公開カタログの `source: "github"` は認識されず、Git URL 形式へ直してから、キャッシュのない設定で導入、スキル、7 個の MCP ツール、統計と日本語検索を確認した。両ホストの通常の設定は変えず、推論も呼んでいない（[[codexのプラグインと会話の取り込みのリリース-wiki-0.29.0]]）。

- wiki 0.30.0 は、Claude Code と Codex の隔離設定で公開カタログから導入し、変更した全 15 ファイルがタグと一致した。導入先のヘルプ、Codex のスキルと 7 個の MCP ツール、統計と日本語検索、試験用 wiki が変わらないことを確認した。一時設定は削除した（[[playwrightの取り込みとログイン状態の利用-wiki-0.30.0]]）。

- wiki 0.31.0 は、Claude Code の変更28ファイル、Codex の重要な7ファイル、スキル単体の全164ファイルがタグと一致した。Codex の7個の MCP ツール、統計、日本語検索と、wiki が読み取りで変わらないことも確認した。最初の一時ファイルのロックによる後片付けの失敗は、期限付きの再試行を加えた再実行で解消した（[[wikiの記事リンクの拒否とリリース-wiki-0.31.0]]）。

- wiki 0.31.1 は、Claude Code と Codex の両方で公開カタログから導入でき、変更した全 11 ファイルがタグと一致した。導入先の検査器で英語のままの keep を拒否し、日本語訳を完了できた。Codex の 7 個の MCP ツール、統計、日本語検索と、読む前後で wiki が変わらないことも確認した。一時設定は削除した（[[翻訳を省略した取り込みの完了の防止-wiki-0.31.1]]）。


- wiki 0.32.0 は、Claude Code と Codex の使い捨ての設定で公開カタログから導入し、全25変更ファイルがタグと一致した。各導入先で概要の保存、h1直後への表示、SVGの配信データ、元記事の不変、記事更新後のstaleと折りたたみを確認した。Codexの別の公開導入でも2スキル・7 MCPツール、統計、日本語検索とwiki不変を確かめた。モデルの推論を試すものではない。親子の全CI成功後に子を先にマージし、注釈付きタグとリリースを公開した（[[ページの概要の生成と表示-wiki-0.32.0]]）。

- wiki 0.33.0 は、Claude CodeとCodexの隔離設定で公開カタログから導入し、全17変更ファイルがタグと一致した。Claude Codeの候補2件・sonnet/lowの指示・既出抑制・無効時の無出力、Codexの2スキル・7 MCPツール・統計・日本語の語彙検索とwiki不変を確認した。スキル単体も全170ファイルがタグと一致し、3通りの一時設定を削除した。埋め込み検索とモデルの推論を完了させる試験ではない（[[プロンプトの候補とモデル選定-wiki-0.33.0]]）。

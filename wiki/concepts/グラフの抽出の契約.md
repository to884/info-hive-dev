# グラフの抽出の契約

browse（閲覧）の関係表は、グラフの抽出の `build_nodes()` と `build_edges()` を、写しから作ったページにそのまま当てはめて作る。そのため、グラフの抽出には、関係を別のページに紛れ込ませない性質が要る。この性質を「グラフの抽出に求める契約」と呼び、wiki 0.9.2 で満たした（[[グラフの抽出の修正-0.9.2]]）。

正本は browse の計画（`docs/plans/wiki-browse-stage1-2026-11-09.md` の 3「グラフの抽出に求める契約」、ブランチ `feature/wiki-browse-stage1` のコミット d4391da と cb30278）である。2026-11-11 の時点では、このブランチはまだ main に入っていない。

## 契約

1. エッジの主語は、そのエッジを書いたページのノードである。スラッグから引き直さない。
2. エッジは `page` を持ち、ページの違う同じ内容の関係を 1 本にまとめない。
3. 型付きの関係の目的語は、ノード ID として引く。1 つのページのノードに当たればそのノードを、当たらなければ文字列の目的語をエッジにする。目的語をページへの参照として解かない。
4. `sources:` の値は、`resolve_link()` と同じ規則でページに解決する。当たるページが 1 つならそのページ、2 つ以上なら曖昧、0 なら未解決とし、曖昧と未解決はエッジを作らずに診断に挙げる。
5. 別のページが同じ `graph.node_id` を持つときは、黙って捨てずに診断に挙げる。そのノード ID を目的語にした関係は、曖昧としてエッジを作らない。
6. `sources:` の値のうち、1 つのページに解決するものからは、必ず `sourced_from` ができる。
7. `graph.relationships` の項目 1 つから、必ず 1 本のエッジができる。`status` や `valid_to` だけが違う 2 件も、両方残す（cb30278 で追加）。
8. `sources:` の値は、wiki の lint の `unresolved_sources` と同じ `wiki_pages` の関数で分け、「未解決」と「source でない」の値の集合を lint と一致させる（cb30278 で追加）。

## 実装での解釈

browse のセッションと確かめて、次のように決めた。どれも browse の設計と食い違わない。

- 契約の 6 の「必ず」は、`type: source` のページ自身の `sources:` には当てはめない（もとからの仕様）。曖昧と未解決の診断は、ソースのページでも挙げる。
- 1 つのページに解決する値は、source でないページを指していても `sourced_from` を作る。wiki の lint が `not_source` として挙げる。
- 本文の wikilink と `sources:` が、ノード ID を共有するページに当たったときは、その共有のノードへのエッジにする。曖昧として捨てるのは、ノード ID で引く型付きの関係の目的語だけである。browse は、同じ `node_id` のページへの入ってくる関係を出さず、`ambiguous_relations` を挙げる。
- 契約の 7 の例外として、エッジの ID の参照か未知の欄だけが違う 2 件は、並べ替えると ID が入れ替わる（[[エッジの識別子]]）。browse はエッジの ID を保存しないので、影響はない。

## 実装の形

- `build_nodes(pages, ontology, diagnostics=None)` は `(nodes, page_node_ids, aliases)` を返す。`page_node_ids` は、ページのキー（ディスク上の相対パス）からノード ID を引く。同じノード ID のページは、ノードを 1 つ共有する。
- `build_edges(pages, page_node_ids, diagnostics=None)` が返すエッジの `page` は、NFC の相対パスである。
- 診断の種類は `duplicate_node_id`、`ambiguous_object`、`ambiguous_source`、`unresolved_source`、`order_dependent_edge_ids` である。グラフの lint は、これらを `duplicate_node_ids`、`ambiguous_object_refs`、`ambiguous_sources`、`unresolved_sources`、`order_dependent_edge_ids` として挙げる。
- ページへの参照を解く規則は `wiki_pages.py` に置いた（`link_candidates`、`build_page_index`、`classify_source_ref`）。lint、検索、グラフの抽出が同じ規則を使う。

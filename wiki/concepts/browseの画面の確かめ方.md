# browse の画面を実際のブラウザで確かめる手順

閲覧（`/wiki:browse`）の画面の変更を、作者の wiki と実際のブラウザで確かめるときの手順と注意である。wiki 0.12.0 のスコープ表示で使った（[[browseのスコープ表示とリリース-wiki-0.12.0]]）。自動の試験は親リポジトリの `tests/wiki/test_browse*.py` と `tests/wiki/browse/` にあり、ここに書くのは、色や配置のように人の目で見る確かめである。

## 作者のサーバーを使い回さない

`serve` は、同じ wiki（同じ `wiki_key`）のサーバーが動いていれば、それを使い回す。作者が前の版で開いているサーバーがあると、新しい版のスクリプトで起動しても、前の版の画面が出る。

- `INFO_HIVE_DATA_DIR` を使い捨ての場所にして起動する。サーバーの状態のディレクトリ（`<data_dir>/browse/<wiki_key>.server`）が別になるので、作者のサーバーを止めずに、新しいサーバーが起動する。
- 起動の出力の `reused` が `false` であることを確かめる。
- 起動と停止は同じ種類のシェルで行い、停止にも同じ `INFO_HIVE_DATA_DIR` を渡す（`wiki_browse.py stop <WIKI_ROOT>`）。Claude Code では PowerShell と Bash のサンドボックスが違うので、0.12.0 では両方とも PowerShell で行った。
- スコープなど、`/wiki:browse` の手順 0 が決めて渡す引数は、手順 0 と同じ規則で決めて渡す。

## 配色

Claude のブラウザペインでは、`resize_window` の `colorScheme` で `prefers-color-scheme` を切り替えられる。

- ローカルのファイル（`file://` の静的版）の画面には効かず、いつも明るい配色になる。暗い配色は、サーバー（`http://127.0.0.1:<ポート>/...`）の画面で確かめる。
- ペインは、アプリの配色に合わせて切り替えを戻すことがある。0.12.0 では、明るい配色を指定したあと、ページを移ると暗い配色に戻っていた。確かめるたびに、ページの中で `matchMedia('(prefers-color-scheme: dark)').matches` を読み、指定した配色になっていることを確かめる。

## 何を見るか

| 見るもの | 確かめ方 | 0.12.0 で見たこと |
| --- | --- | --- |
| 表示の位置 | `#_nav` の最初の要素 | `app.js` がナビゲーションを足したあとも、`#_scope` が先頭にある |
| 文字と題名 | `#_scope` の文字、`document.title` | 「プロジェクトの wiki」と「索引 · プロジェクト」。個別のページは「（ページの題名） · プロジェクト」 |
| 色 | `getComputedStyle` の `color` と `backgroundColor`、拡大した画面 | 下の表 |
| 個別のページ | 索引から 1 つ開く | 索引と同じに出る |
| エラー | コンソールのエラー | なし |

> 何を見るかの表 補足: 画面の見た目は拡大した画面で確かめ、文字と色はスクリプトで読む。画面の写しだけでは、配色の取り違えに気づきにくい。

0.12.0 で確かめた色は次のとおりである。

| wiki | 配色 | 文字色 | 地の色 |
| --- | --- | --- | --- |
| プロジェクト（`info-hive-dev/wiki`） | 明るい | `#116329` | `#dafbe1` |
| プロジェクト | 暗い | `#aff5b4` | `#0f3d1a` |
| ユーザースコープ（`~/info-hive/W0_Wiki`） | 明るい | `#0550ae` | `#ddf4ff` |
| ユーザースコープ | 暗い | `#a5d6ff` | `#0c2d6b` |

## 配色の切り替え（Fluent 2 のあと）

Fluent 2 にしたあとの画面（[[browseのデザインシステム]]）は、`<html>` の `data-theme`（`auto`、`light`、`dark`）で配色が決まる。`auto` のときだけ OS の配色に従う。

- 確かめるたびに、`document.documentElement.getAttribute("data-theme")` と、`auto` のときは `matchMedia('(prefers-color-scheme: dark)').matches` を読む。
- サイドバーの「配色」で選んだ値は、サーバーでは cookie、`file://` では localStorage に残る。前の確かめで選んだ値が残っていると、OS の配色を変えても画面が変わらない。「OS に合わせる」に戻してから確かめる。
- 0.12.0 のスコープの色の表は、Fluent 2 の実装（F1）で色が変わったら書き直す。

## 片付け

確かめたら、起動したサーバーを `stop` で止め、出力の `stopped` が `true` であることを確かめる。作者が開いているサーバーには触れない。

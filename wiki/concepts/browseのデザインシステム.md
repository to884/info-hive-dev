# browse のデザインシステム（Fluent 2）

`/wiki:browse` の画面は、Fluent 2 の Web 版のデザインを React を使わずに再現した CSS（スキル `fluent2-html-replica` の `fluent2.css`）で描く。2026年11月14日に作者が決めた（ADR-0021、設計は `docs/plans/wiki-browse-fluent2-2026-11-14.md`）。info-hive-wiki 0.18.0 で、探しやすさと一緒に実装した（F1）。記事のページの部品（本文、メタ欄、関係表、被リンク、診断）は、0.19.0 で当てた（F2）。

## 決まりの要点

- **同梱する。** `fluent2.css` は書き換えずに、全体をプラグインの `browse_assets/` に写す。出どころ、基準の版、SHA-256 は `browse_assets/README.md` にある。プラグインはスキルの場所を読まない。
- **`fluent2.js` は使わない。** 要素の `style` に書き込み、閲覧の画面の約束（`[style]` が 0 件）に反する。要るふるまいは `app.js` が受け持つ。
- **配色を選べる。** `<html data-theme="auto">` を既定にし、ライトとダークを選べる。選んだ値は、http ではポートを区別しない cookie に、`file://` では localStorage に置く。サーバーは起動ごとにポートが変わり、localStorage はポートごとに分かれるためである。0.25.0 からは、Fluent 2 のサイトの形の「テーマ」のトグルで切り替え、OS と同じ見た目に戻すと auto を保存する（[[browseのタグの段とTreeのリリース-wiki-0.25.0]]）。
- **左のペインは Tree で描く（0.25.0 から）。** Nav は入れ子を 1 段までとし、深い階層には Tree を使う。記事のページも Index のページも、グループの名前と件数のバッジだけを描く。見た目は Fluent 2 のサイトの左のペインに合わせ、ホバーと今の項目は、地と文字を組で brand のトークン（`colorBrandBackground2` 系と `colorBrandForeground2` 系）にする。組の比は 4.5:1 以上を試験で守る（設計は `docs/plans/wiki-browse-tree-2026-11-16.md`）。
- **ライセンスの表示を出力に付ける。** `fluent2.css` の先頭のコメントは Fluent UI の表示だけを持つ。`fluent2-html-replica` 自身の MIT の表示は、出力に必ず入る `style.css` の先頭のコメントに写す。

## レビューで分かったこと

設計は Sol の敵対的レビューを 3 回受け、1 回目と 2 回目は分類 A の反例で却下された。崩れた前提は次のとおりで、どれも Fluent の部品を当てるときに繰り返し起きうる。

- **止まっている状態の配色が通っても、操作中は通るとは限らない。** 暗い配色で、brand のリンクの色（`colorBrandForegroundLink`）と、ホバーの地（`colorSubtleBackgroundHover`）の組は 4.18:1 で、4.5:1 を割る。
- **地が変わらない場所を、場所の名前で数え上げてはならない。** Fluent の `fui-TableRow` は、操作できない表でもホバーで地を変える。規則は「地を状態で変えてよいのは操作できる要素だけ」「自分か祖先の地が変わる要素は brand のリンクの色を使わない」の 2 つにした。
- **親の折り返しは、部品の中の `white-space: nowrap` を解かない。** Tag、Badge、Button、Nav の項目に利用者の文字を入れるときは、`nowrap` を外す。
- **試験は場所を数え上げず、地が変わりうるすべての入れ物にポインターを置き、押したままの状態でも測る。** 押下の色は、ホバーの色と別に 4.5:1 を割ることがある（木の「一覧」のリンクで 4.36:1）。

## 実装の段で分かったこと

- **読めない入力の約束と、番号の ID はぶつかる。** 索引のファイルのグループの番号に、読めないファイルも数えると、読めない `index.md` のある Wiki と、それを取り除いた Wiki で ID がずれる。番号は、グループを作るファイルだけで数える。
- **ネイティブの選択は、いちばん長い選択肢の幅になる。** 200 文字のタグがあると、タグの選択で横にはみ出す。
- **行の順を 2 か所に持たない。** 並べ替えを DOM にだけ当て、Enter で読み込んだときの配列の先頭を開いていた。順は DOM だけが持つ。
- **配色の試験は、測れなかった部品を落とす。** 測る要素がないと、測らずに通る。ホバーは、色の切り替わりが終わってから測る。測れた部品は配色ごとに数える。片方の配色だけで消えた部品を、もう片方で測れたことにしない（F2）。
- **押下のリンクの色は使わない。** `colorBrandForegroundLinkPressed` は、暗い配色で地との比が 3.85:1 になる。押している間もホバーの色のままにする（F2）。
- **「地を変えない」は、比とは別に確かめる。** 地を変えても 4.5:1 を保つ組み合わせがある。読むだけの行のすべてで、ポインターと押下の前後の地を比べる（F2）。
- **狭い表のセルで `word-break: normal` にすると、日本語の語が途中で折れる。** 関係表を最小幅の 48em に収めると、「ソース/の例」のように折れた。語を折らない表は `keep-all` にし（日本語も空白と句読点で折り返す）、長い値は表の入れ物の中で送る（F2）。
- **見えない要素の位置は、はみ出しではない。** 畳んだ検索欄の消去ボタンは、幅 0 で `overflow: hidden` の入れ物の外に位置を持つ。はみ出しを数える試験は、祖先が切り取る要素を除く（F2）。

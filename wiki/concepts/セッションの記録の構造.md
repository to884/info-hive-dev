# Claude Code のセッションの記録（JSONL）の構造

Claude Code のセッションの記録（`<設定のディレクトリ>/projects/<プロジェクト>/<セッション ID>.jsonl`）から会話を抜き出すときに頼れる性質と、頼れない性質である。2026-11-14 に、検証環境の 1 つのプロジェクトの 61〜67 ファイル（Claude Code 2.1.309〜2.1.321）の構造を、会話の文を読まずに集計した（[[セッションの取り込みの設計-2026-11-14]]）。記録の形式は公開された仕様ではなく、12 日間で 5 つの版が現れたので、版が変われば確かめ直す。

## 頼れる性質

- 記録の種類は 21 ある。`uuid` を持つのは `user`、`assistant`、`attachment`、`system` の 4 種類だけで、ほかの 17 種類（`custom-title`、`last-prompt`、`queue-operation`、`api-request` など）は持たない。会話のつながり（`parentUuid`）に入るのは、`uuid` を持つ記録だけである。
- 人の発言は、`origin.kind` が `human` の `user` の記録にある。ただし、本文の先頭にハーネスの `<system-reminder>` が入ることがある（52 件。どれも本文の先頭）。
- Claude が作業している間に人が打った発言は、`attachment` の `queued_command`（`attachment.origin.kind` が `human`）として届き、あとに `user` の記録として現れない。`prompt` が文字列でないものもある。
- アシスタントの記録は、内容のブロック 1 つにつき 1 件である。1 つの応答が最大で 22 件に分かれていた。思考（`thinking`）のブロックも残る。
- アシスタントの本文の返答の宛先は、`parentUuid` をアシスタントと透過の記録（ツールの結果、文脈の差し込みの `attachment`、一部の `system`）を通ってたどれる。3,491 件のうち、たどれないものは 0 件だった。宛先は、人 1,481、作業の通知 674、キューに入った入力 545、`isMeta` 334 などだった。
- `parentUuid` の枝分かれ（2,743 か所）は、どれも並列のツールの呼び出しによるもので、巻き戻しは見つからなかった。
- 会話を圧縮しても、圧縮の前の記録は消えない。圧縮の要約は `isCompactSummary` の付いた `user` の記録として足される。
- サブエージェントの記録は、本体と別の `<セッション ID>/subagents/agent-*.jsonl` にある。

## 頼れない性質

- `promptSource` は話者の判定に使えない。デスクトップアプリの人の発言 632 件のうち 607 件が `sdk` だった。
- `origin` のないファイルは古い形式ではなかった。7 件とも `claude -p` のセッションで、人の発言の記録がない。
- `isMeta` は、スキルの本文の読み込みと、ほかのセッションからの伝言の両方に付く（`origin` なし 145、伝言 110）。
- ファイル名の ID と、最初の記録の `sessionId` が違うファイルがある（2 つの ID の記録を含む）。
- `attachment` の種類で除くと決めると、キューに入った入力への返答が前のターンに混ざる。除くものを並べる方式は、新しい種類の記録を通してしまう。
- 記録は `cleanupPeriodDays` の日数を過ぎると消える。

## 抜き出すときの決まり

ADR-0020 は、許可リストで残すものを決め、話者を記録ごとの属性で、返答の宛先を `parentUuid` で決める。`uuid` のない知らない記録は読み飛ばす。決まりの全体は `docs/plans/wiki-session-ingest-2026-11-14.md` の 4 節と 5 節にある。

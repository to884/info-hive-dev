- [[タクソノミー・オントロジー・知識グラフ・セマンティックレイヤーの分担]]: 4つの形が持つもの・答えられる質問の違いと、定義を複数の層に書くと食い違う点
- [[オントロジーの記述例]]: 種類・関係の定義と、出典付きの個別の関係を記述するYAMLの例
- [[オントロジー候補の生成と採用の分離]]: LLMによる証拠からの概念提案と、既存概念との照合・検証・見送りを分担する構成
- [[スキーマの導出と事実の抽出の分離]]: 共通の型・関係を先に決める設計と、myKGの属性展開・再抽出の調査
- [[プロジェクト用オントロジーの設計案]]: 構成要素・版・変更・問題・評価を追跡する2026-11-18時点の未適用の設計案
- [[図ごとの描画の隔離]]: 図を1枠ずつ描画し、サーバー版では埋め込み・`opener` 経由で図の代わりにコードを表示。修正後は5ブラウザーで30ケースが通過
- [[描画の性能測定の条件]]: 時間とメモリ、監視・処理履歴、準備待ちとGC、未統制の差を分ける測定条件

- [[実体を単位にするオントロジー]]: 記事・実体・根拠の区別、多対多の対応と同一性、現行ingestとextractの範囲
- [[オントロジーの見直しと移行]]: 定義と既存記録の再編、部分移行と通常取り込み、問い合わせと参照の受け入れ条件

- [[既存リンクからのグラフ検索]]: 明示的なリンクを解析して文書をたどる方式と、本文による意味の確認が必要な範囲、myKGの原文照合の事例

- [[グラフの抽出の契約]]: browse の関係表がグラフの抽出に頼る 8 つの性質と、実装での解釈
- [[エッジの識別子]]: グラフのエッジの ID に入れる値と入れない値、その理由
- [[グラフのlintの期待値]]: グラフの lint の期待値を取り直す条件と、info-hive-wiki の CI を手元で流すこと
- [[pdfのヘッダーの条件]]: rag が PDF を確かめる 2 つの段階、ヘッダーの境界と書き方、rag の版による違い
- [[リリースの確かめ方]]: リリースの完了の条件、タグとリリースの形、使い捨ての設定での導入の確かめ方、マージの順番
- [[リリースごとの導入の確かめの記録]]: 0.9.2 から 0.38.1 までの、版ごとの導入の確かめ（確かめた件数、一致、動かしたこと）
- [[git-bashのパス変換]]: Git Bash が `git show <リビジョン>:<パス>` の引数を書き換える形と、`MSYS_NO_PATHCONV=1` での避け方
- [[officeのcomでの書き出し]]: Word の COM で文書を開いて PDF に書き出すときの引数、PowerShell の版、時間の上限（仮説の段階）
- [[powershellのパイプの打ち切り]]: `Select-Object -First` が上流のスクリプトを止め、最後のファイルの書き込みが起きないこと（仮説の段階）
- [[pythonの書き戻しの改行]]: Windows の Python の `write_text` と標準出力が LF を CRLF に変えることと、避け方と気づき方
- [[browseの画面の確かめ方]]: browse の画面を、作者のサーバーを使い回さずに、2 つの配色と 5 つのブラウザで確かめる手順、図の隔離と性能測定の条件
- [[browseの静的画像表示とメモリ]]: 同じタブで配色の切り替えと記事の往復を分けて測り、保持メモリの内訳、SVG／PNG 比較の原標本、再集計の手順、再測定結果、Pele SVG／PNG の表示・性能比較、図種・CSS の互換性とラベルの検証
- [[browseのデザインシステム]]: browse の画面を Fluent 2 の再現の CSS で描く決まりと、レビューで崩れた配色と折り返しの前提
- [[frontmatterのリストの値]]: パーサーがリストの欄を文字のまま、1 つの文字の欄（`title`、`type`、`updated` など）を配列で返す形と、そろえる関数の違い、残っている欠陥
- [[初期化されたwikiの判定]]: ルートの `SCHEMA.md` で初期化された wiki を見分ける規則、判定する場所と例外、試験の素材の決まり
- [[ingestに使うモデル]]: /wiki:ingest の raw の段は Sonnet 5.5 で行う決定と、その理由、受け入れた弱点。0.15.0 からはエージェント wiki:web-raw が行う
- [[claude-effort]]: Claude API で応答に使うトークン量を調整する設定。モデル別の既定値、出力上限、会話途中の変更
- [[claude-thinking]]: Claude API の推論モードと表示、手動予算と適応型への移行、トークンの計上、推論ブロックの返送
- [[コマンドの引数の渡し方]]: コマンドが利用者の引数をスクリプトに渡すとき、シェルに届く文字を限る決まりと、対話のセッションでの展開
- [[コマンドの出力のリンク]]: コマンドの出力に載せる文書のリンクを GitHub の版のタグにした理由と、書き換えを独立した読み方で確かめる作り
- [[記事作成の5区分]]: 記事作成を発見、構造化、体系化、執筆、維持に分け、きっかけごとに使う手法と使わない手法を決める整理
- [[セッションの記録の構造]]: Claude Code のセッションの記録（JSONL）から会話を抜き出すときに頼れる性質と頼れない性質
- [[editとwriteの書き込みの競合]]: Claude Code の Edit と Write を同時の書き込みと並べた結果と、読み取り専用のファイルの守り
- [[抽出の品質の測り方]]: 抽出の方式を比べるときに、数値の境目、表の列、読み順を見誤らない指標の作り方と、判定を採点した中身に結び付ける方法、MinerUの比較条件と表の値の照合
- [[pdfminerの本文の並びの揺れ]]: pdfminer.six が距離の同じテキストボックスの組の順を `id()` で決め、プロセスごとに行の並びが変わることと、決まった順にする直し方
- [[windowsのファイルの共有と削除待ち]]: Windows で置き換えと削除の途中のファイルを開くと失敗する 3 つの原因（共有の指定、削除待ち）と、試験で途中の状態を作る方法
- [[エージェントに守らせる決まりの書き方]]: 読まれていないのか読んで破ったのかを分ける、判断を求める禁止より字句で決まる決まり、否定の例を避ける、漏れの測り方、オントロジー候補の見送りと採用判定
- [[敵対的レビューで設計を直す進め方]]: 状態を推さない、直しの仕組みから次の指摘が出る、重大を発生の度合いで分けて止める、という 2 つの設計で確かめたこと
- [[動的ワークフロー]]: エージェントの割り当て・並列実行・検証をスクリプトで組む手法。Claude Code と Managed Agents の比較、`/wiki-dream` の定期ジョブ（毎日正午、日本時間。登録時は午前3時）と手動試行（会話2件・差分1件、定刻での起動は試行時点で未確認）
- [[エージェントのメモリの階層]]: トランスクリプト、メモリノート、メモリ表現（wiki）、注入コンテキストの 4 層と、層の間を整理するドリーミングの役目
- [[2つのwikiの分離の確かめ方]]: 2 つの wiki が実体を分け合わないことを、読み手が自分の開くものの識別子で確かめる方法と、崩れた比べ方
- [[wikiの検索時間の測り方]]: 検索、候補通知、公開版の根拠取得、回答完了までの計測区間と試験条件の照合手順
